5. Candidate rule (not promoted): a grammar change in the gate reaches every disposition literal in the gate's test module; grep the module for the old form before writing new tests.
6. [memory:failure] The disposition regex's greedy reason (split at the last `; evidence=`) was chosen for reasons that contain `;`, and it lets a second delimiter smuggle an empty reason through (Bot round 3, thread 4248934816). 7. [memory:decision] Three rounds of pasted-command matching for S6 (bare directory, unbound query, `echo grep`) were one class, which hit S1 (`search-command-scan`). A gate cannot tell a pasted command from a run one by its text, so amendment 1 recomputes the search and compares its result set with a fixed-template line. When a check reads pasted evidence text, ask first whether the gate can recompute the fact instead.
8. [memory:decision] A merge gate's parser belongs in the standard library. The YAML front matter needed PyYAML, which neither the gate's `python3` nor CI's bare `uv run python` has. The uv subprocess that replaced it failed for real once the uv cache was pruned (thread 4250238721), and the operator chose a JSON block read with `json.loads` (plan 013 A′). Two standard-library defaults need refusing there: duplicate keys (`object_pairs_hook`) and NaN or Infinity (`parse_constant`).
9. [memory:failure] Prettier formats a `---` block in a tracked `.md` as YAML front matter, and its default `trailingComma: "all"` turns a multi-line JSON object into invalid JSON. A directory `.prettierrc` with `trailingComma: "none"` keeps the output valid; `.orchestration/` is prettier-ignored, so real records are untouched.
