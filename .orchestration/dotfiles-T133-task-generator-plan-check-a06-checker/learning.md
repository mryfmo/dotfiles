Path.as_posix removes a directory marker, so scope intent must be preserved explicitly after original-path resolution. Real-CLI scripts/ and scripts/** controls exposed and now cover the same escaping descendant.

Metadata grammar cannot classify actual enumerated filenames: a valid POSIX filename may contain a backslash even though task operands reject it. PurePosixPath ancestry of the already resolved key classifies applied directories without a second resolution.

Negative assertions must require actual finding lines. A bare C6 token matched an ordinary warning and let one mutant survive; the finding-line prefix kills it. Native NFC/NFD names alias on this host, requiring an explicitly skipped native two-file case plus executed modeled distinct-file and same-target controls.
