# Learning triage: dotfiles-T133-verdict-audit-pool-a01

These are candidates only; nothing is promoted.

1. [memory:decision] A merge-deciding script's every read must go through a guard that turns a failure into hold: under `set -euo pipefail` with an ERR trap, `want="$(sed … "${rec}" | tail -n 1)"` on a missing record exited 2 (internal error) instead of holding, and `$(git merge-base …)` inside a here-string fed an empty numstat to condition 5, which then passed vacuously. The fixture suite, built on a complete green set, never removed the record or the head; the live `--shadow` run on the PR itself found the first in one call. Run a new verdict-style script once on a real, incomplete input before calling it fail-closed.
2. [memory:decision] macOS ships no `flock(1)` (only `/usr/bin/lockf` and `/usr/bin/shlock`) and Linux no `lockf(1)`; a lock both platforms honour is Python's `fcntl.flock` (as dispatch.sh already uses), run under `python -I`.
3. [memory:decision] A line cap that counts data files gets decided before the code, not after: the class vocabulary (140 lines) and the schemas (62) were known at the first `wc -l`, and asking for the D-cap-F2 form then (PONG 04:37Z, Amendment 1 at 04:41Z) cost one round trip while the code went on.
4. [memory:decision] Rewriting a header's description to "improve" it doubles the diff (every rewritten line is one deleted and one added): keeping the original lines verbatim and appending the new sentences took orch-audit.sh's diff from 137 to 113 changed lines.
5. [memory:failure] The repository's shfmt runs with flags (`--indent 4 --space-redirects`), so `.editorconfig` is ignored and case arms sit at the `case` keyword's level; write them that way or run `shfmt -w` with the Makefile's flags before the first commit.
6. [memory:failure] Escaped braces (`{{`) belong only in the f-string's own literal text. A plain string interpolated into an f-string keeps them doubled, so a fake `uv` written that way had `{{ echo …; exit 1; }}`. Bash read `{{` as a command name, which made `|| {{ …` bind to the first command only, and the `exit 1` after it ran on every call. The first run of the revise test failed on the green path, which is how it was found. Run a new fake once on its green path before reading its red result.
