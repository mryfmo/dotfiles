# T46 learning triage

## Reusable learning

- Backward compatibility for newly defaulted config keys is best pinned by loading a partial old-style JSON file, not merely inspecting `DEFAULT_CONFIG`.
- CompactionDB manifest paths are relative to the vendor package root; regeneration and `shasum -c` must run from that directory.
- Release validation scans ignored environments too, so bytecode caches under a local `.venv` can fail release cleanliness even when the source tree is otherwise clean.

## Triage

These are task-local operational findings. No rule candidate was promoted; the durable schema decision is marked in the report and the config behavior is pinned by tests.
