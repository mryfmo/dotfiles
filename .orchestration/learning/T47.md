# T47 learning triage

## Reusable learning

- Fixed headings under a hard packet limit require reserving heading and empty-body space before allocating evidence; truncating the assembled packet can silently delete later checklist sections.
- A write/edit artifact trail can be rebuilt deterministically from `event_files` by reading newest-first and aggregating in insertion order; no storage schema or LLM is needed.
- Project-scoped explicit memories lose the originating session ID after promotion, but `memory_candidates` retains it, so Goal can identify the newest explicit decision without weakening project-memory isolation.
- `make clean` immediately before release validation avoids ignored pycache directories causing false release-tree failures.
