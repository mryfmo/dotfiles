# T48 Learning

1. The vendored CompactionDB CLI derives its project database from the process working directory, so a notify receiver must run it with `cwd` set to the payload's resolved project directory. Merely selecting the project-local script path is insufficient.
2. Generated Codex profile paths must retain `{{ .chezmoi.homeDir }}` in source state; hard-coded local home paths fail agent-asset validation.
3. Avoiding `Path.expanduser()` keeps the receiver within the requirement not to consult environment-derived home configuration. `Path.resolve()` is sufficient for Codex's absolute `cwd` payload and the current-directory fallback.

Apply these findings to future Codex notification receivers and generated profile commands.
