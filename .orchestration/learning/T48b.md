# T48b learning triage

## Reusable learning

- Provenance supplied by a trusted local adapter should be validated both at the CLI boundary and again when reading its durable envelope; this catches later tampering without weakening the normal hook path.
- Optional envelope metadata can preserve byte-identical defaults by omitting the key entirely and selecting the legacy spool filename only when the key is absent.
- `process_payload` already centralizes normalization, redaction, spooling, and drain behavior, so an optional keyword is smaller and safer than duplicating the ingest path in the CLI.

## Triage

The source-token contract is documented and pinned by focused tests. No separate project rule candidate was promoted.
