# T48c Learning

1. Chezmoi `modify_` files are executable transforms, not templates whose stdout is rendered again. Template syntax embedded in their output must therefore be resolved by the transform itself.
2. Keep machine-portable path placeholders in the shared manifest and perform environment-specific expansion at the latest responsible point: apply time in the generated modify script.
3. Conditional helper emission preserves byte identity for profiles that do not use the placeholder while keeping the runtime behavior centralized in the generator.

Apply these findings to future generated chezmoi modify scripts that carry portable path placeholders.
