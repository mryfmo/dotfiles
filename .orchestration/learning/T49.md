# T49 Learning

1. Read-only query commands must branch before the CLI's opportunistic `drain_spool`; otherwise a logically read-only operation can settle spool records and mutate the database.
2. T47 already exposes the exact artifact derivation as importable `_modified_files`; reusing it is the smallest way to guarantee probe/recovery byte equality and avoid query drift.
3. Project memories are intentionally cross-session, while session memories and raw events require exact-session filtering. Isolation tests must distinguish those visibility rules rather than treating all cross-session data as contamination.
4. Subcommand-local `--json` can coexist with the existing global option by using `default=argparse.SUPPRESS`, preserving both `--json probe ...` and `probe ... --json` forms.

Apply these findings to T50's read-only recall path and future recovery-derived CLI features.
