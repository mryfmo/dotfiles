# T50 Learning

1. FTS5 `bm25()` is lower-is-better and commonly negative; negate it before the shared higher-is-better min-max normalization.
2. Semantic fallback must be decided before invoking the external adapter: require semantic enablement and stored vectors for the configured model, then catch adapter unavailability and retain lexical-only behavior.
3. A deterministic closure can avoid global resorting: traverse fused parents in score order, emit eligible closure rows immediately, and skip a closure row when its own base score is greater or equal. Earlier parents always have greater or equal inherited scores, so seen-row dedup retains the higher score.
4. Event IDs are globally adjacent, so the adjacency closure must also require the parent's session ID even when no CLI session filter is supplied.
5. Subcommand-local `--json` with `argparse.SUPPRESS` preserves the existing global JSON form and supports the requested trailing option form.

Apply these findings to future FTS ranking, optional semantic fusion, and read-only retrieval commands.
