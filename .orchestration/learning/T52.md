# T52 Learning

1. Understand-Anything auto-update must apply the canonical ignore filter before structural classification; in this update it removed 40 `vendor/` files and prevented an unnecessary full rebuild.
2. The fingerprint store is an envelope with metadata plus a `files` map. Count and patch `fingerprints.files`, not top-level JSON keys.
3. Auto-update normally assumes a clean post-commit worktree. In a shared worker checkout, verify target paths against HEAD before analysis so accepted but unrelated working changes are not accidentally graphed.
4. `meta.analyzedFiles` represents unique analyzed file paths. The graph can contain more file-level nodes when a single path contributes multiple typed nodes, such as Makefile targets.
5. Partial updates should validate semantic scope: unchanged nodes/edges, layers, and tour must remain identical outside the re-analyzed file paths.

Apply these findings to future `.ua` incremental refreshes and validation templates.
