# T53 Learning

1. The `2.0.0+dotfiles.4` recovery limits live under `config["recovery"]`, not `config["capture"]`: `max_chars=12000` and `files_budget_chars=2000`.
2. Generated Claude command hooks split the executable and script: `command` is the pinned Python interpreter, while the project-relative hook path is in `args`.
3. Opt-in validation must distinguish committable `.gitkeep` placeholders from ignored runtime state. `git check-ignore -v` against representative future paths proves the rule even when spool/health outputs do not yet exist.
4. When `.claude/settings.json` is absent, merge preservation is vacuous; record that baseline explicitly and separately prove `.claude/settings.local.json` remained untouched.

Apply these findings to future CompactionDB opt-in validation and installer acceptance checks.
