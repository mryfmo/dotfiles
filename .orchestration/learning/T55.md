# T55 Learning

1. Managed Claude and CompactionDB hook files share the same nested JSON event/group/hook shape; Codex TOML decodes to that same nested shape for event arrays, while `hooks.state` must be ignored because it is a mapping rather than an event list.
2. Hook command identity must include `args`, not only the executable. CompactionDB intentionally has two SessionStart hooks whose executable is `python3` but whose scripts differ.
3. Existing `render_template_text()` is sufficient tolerance because remaining `{{ .chezmoi.homeDir }}` placeholders occur inside quoted JSON/TOML strings; static validation does not need to invoke chezmoi.
4. Flattening event groups in declaration order lets one category enforce duplicate invocations, first-handler policy, conservative synchronous timeout totals, and pinned relative SessionStart order.

Apply these findings to future managed hook inventory and composition-policy checks.
