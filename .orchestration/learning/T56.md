# T56 Learning

1. Claude's public plugin cache exposes marketplace/plugin/version directory boundaries suitable for approximate version-change detection without reading harness internals.
2. `~/.agents/skills` contains live agmsg `db`, `run`, and `teams` subtrees. A general mtime scanner must exclude these in addition to CompactionDB state/spool/health and SQLite paths or every message can create a false restart warning.
3. The manifest-to-Claude generator already copies `claude.hooks.session_start` verbatim, so adding a hook requires only one manifest append plus regeneration; generator logic should stay unchanged.
4. Setting `HOME` around `uv run` can change mise trust/config resolution before the target process starts. Fake-HOME CLI tests should resolve the uv interpreter first, then set HOME only for the product subprocess.
5. A monotonic deadline plus an entry cap bounds ordinary traversal, while `signal.setitimer` enforces the five-second process wall on supported macOS/Linux runtimes.

Apply these findings to future public-filesystem health probes, fake-HOME validation, and managed SessionStart hooks.
