# T57 Learning

1. The updater has 11 unique install-step function names even though `ensure_mise_npm_agent_cli` is invoked for two CLI arguments; the manifest granularity must follow the function-name contract, not call count.
2. A same-directory mode-0600 temporary file plus `mv` gives the required atomic reader-visible boundary while a public best-effort wrapper can preserve install success with one warning.
3. `jq -cn --args '$ARGS.positional'` safely converts Bash arrays containing spaces into JSON arrays without eval or a new dependency.
4. Changing HOME around a mise shim can trigger config trust failures before a fake-HOME test reaches the product. Resolve the real executable first or place a direct executable ahead of the shim.
5. Keeping all JSON logic in a sourced library lets the updater diff remain pure additions: source wiring plus one terminal call per step.

Apply these findings to T58 reverse mapping, T59 repair, and future fake-HOME lifecycle tests.
