# T61a Learning

1. A chezmoi `{{ include }}` wrapper changes the runtime identity of an included script: `BASH_SOURCE[0]` points at a generated `/tmp` file, not the repository source.
2. Splitting an included script into a library requires the wrapper to inline that library first; a function-existence guard then preserves the same main script for both inlined and direct execution.
3. A concatenation test catches this deployment shape cheaply without running `chezmoi apply`: library + main, `bash -n`, source, then one fake-HOME function call.
4. ShellCheck SC2016 is correct to suppress narrowly when a single-quoted jq program intentionally contains jq variables.
5. Text-based call-count tests should match invocation syntax (`manifest_record "`) rather than any occurrence followed by whitespace, because declaration/guard references are not calls.

Apply these findings whenever a chezmoi wrapper includes a shell entrypoint that gains sibling files: test the rendered single-file form as well as direct repository sourcing.
