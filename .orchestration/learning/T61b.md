# T61b Learning

1. A wholesale-replacement manifest needs invocation identity in the object key whenever one installer function has multiple independent targets; recording commands inside the value cannot prevent sibling overwrite.
2. Consumer dispatch should split the key once, whitelist the base function, and map allowed identities explicitly. This is both smaller and safer than inferring identity from free-form recorded commands.
3. Optional absence and present corruption are different states. Integrity must be checked before every dependent scan, with one actionable ERROR and no misleading partial results after corruption.
4. jq `--arg` object lookup/deletion already treats colon-bearing keys as opaque strings, so the remover and manifest library needed no suffix parser.
5. A compact fake-HOME suite can prove the entire contract: double record, scoped repair, scoped removal, corruption error, and unchanged valid behavior.

Apply these findings to future parameterized asset steps: make identity part of the authoritative key and validate optional manifests before treating their contents as evidence.
