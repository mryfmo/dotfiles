# T66 Learning

Pi v0.84.2 sets `hasUI` for RPC as well as TUI, so permission confirmation must check both `ctx.mode === "tui"` and `ctx.hasUI` when RPC must deny. A compact stdin JSON decision protocol also cleanly separates the normal `ask` result from process/config/logging failures while keeping command/path content out of argv.

Apply this to future Pi security extensions by treating mode—not `hasUI` alone—as the interactivity boundary, keeping process protocols canonical and fail-closed, and making locally available compilers optional while retaining a native syntax gate.
