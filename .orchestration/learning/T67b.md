# T67b learning triage

## Signals

- Provider auth availability is a two-lane decision: a documented environment
  key or an exact provider entry in Pi's subscription `auth.json` storage.
- An environment mapping table cannot represent subscription-only providers;
  treating a mapping miss as an authentication miss creates false SKIPs.
- Presence checks must return only status. Missing, malformed, or unrelated
  auth storage is unavailable input and must never expose credential values.

## Disposition

- Failure fact: recorded in CompactionDB as project failure UUID
  `850e8e89-e4f0-4d83-a315-109c9e5e412b`.
- Implementation: exact-provider subscription presence now unlocks the existing
  JSON/RPC/extension lane; fake fixtures pin PASS, safe SKIP, non-disclosure,
  request shape, and trailing-event tolerance.
- Rule/skill promotion: not proposed. This is a Pi checker-specific invariant
  captured in its tests and repository learn index.
