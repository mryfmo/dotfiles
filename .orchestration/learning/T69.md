# T69 learning triage

## Signals

- Pi's completion event deliberately omits tool args. Tool-granular adapters
  must correlate start/end by toolCallId in memory, then delete the entry.
- Hook compatibility includes canonical tool-name casing; event names alone do
  not preserve downstream summary and file-operation classification.
- Never-block capture is easiest to review when every handler uses one wrapper,
  subprocess input is bounded/minimized, and the only failure output is fixed.
- Session-start opt-in caching avoids per-tool filesystem checks while still
  following session replacement/reload.

## Disposition

- Decision recorded in CompactionDB as project memory UUID
  `67753213-22b9-49f9-beea-5fb63e2d5f29`.
- Reusable repository learn added and indexed for future Pi lifecycle adapters.
- No rule/skill promotion proposed; pinned types, direct tests, and asset hash
  provide the narrow maintenance surface.
