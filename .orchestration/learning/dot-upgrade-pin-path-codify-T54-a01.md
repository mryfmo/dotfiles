# Learning: dot-upgrade-pin-path-codify-T54-a01

1. **Hook output beats rule text for directives that must not be skipped.** SessionStart hook stdout enters the session context, which is why the Monitor and seat-claim lines were followed while rule text was skipped. The regime directive now uses the same channel. Status: applied, and unit-tested for the managed pane, the pane-less summary and a skipped pane.
2. **A pin assertion that copies the pin breaks main on every bump.** When the generator `--check` already holds the pin byte-exact, a test should assert the property the pin exists for (here the v2026.9.12 arm64 floor), not the literal. Status: applied to the two mise checks. The `cargo:eza` 0.23.5 literal in the same test has the same shape but is not part of this task; it is a candidate for a later sweep.
3. **The PostToolUse formatter reformats whole Python files.** An Edit to `tests/unit/test_herdr_agents.py` reflowed about 1,400 unrelated lines. Edit large test modules through Bash, or check `git diff --stat` after every Edit. Status: validated once; a candidate for the worker playbook. Not promoted.
4. **A test helper name can be shadowed silently.** `HerdrAgentsTest` already defines `git()`, and a later definition in the class wins without warning. Grep `def <name>(` before adding helpers to a 5k-line test class. Status: validated.
5. **Round 1: `git log --name-only` lists no files for a merge commit.** A path policy on a push range must compare trees (`git diff --name-only <old> <new>`), or a merge's own resolution escapes it. Status: validated by an evil-merge test.
6. **Round 1: a check that cannot run must refuse.** An empty result from a failed enumeration looked like "nothing outside", so the push was logged as allowed. Capture the command's own exit status, and treat failure as refusal. Status: validated by a test that deletes the base tree object.
7. **Round 1: a stable stub keeps hook logic updatable without overwriting user edits.** When a generated hook may be edited locally, ship a constant stub that execs the managed launcher. "Differs from the stub" then means "leave it and warn", and logic updates land with the launcher. Status: applied.
8. **Round 2: a hook that execs a managed tool must survive version skew.** Installers can run from the source tree before the tool on PATH is updated (`make upgrade` bootstraps without `chezmoi apply`). Probe the tool for the capability (`--help` advertising the mode) both at install time and in the hook itself. A stale tool must degrade to the narrow safe behaviour (refuse main only), never to running another mode. Status: validated by old-launcher tests and the demo.
9. **Round 2: under `pipefail`, `cmd | grep -q` can read as failure.** `grep -q` exits at the first match and the writer may take SIGPIPE, so the pipeline fails even though the pattern matched. Capture the output (`[[ "$(cmd)" == *pat* ]]`) instead. Status: applied.
10. **Round 2: "content unchanged" is not "hook healthy".** git skips a non-executable hook silently, so an idempotence check must also check the mode bit. Status: validated by a test.
