# dotfiles-T70-make-update-unattended-a01 — learning triage

1. **chezmoi `run_onchange_` scripts that exit 0 on a skip are never retried.** chezmoi re-runs them only when the rendered content changes, so a non-fatal "pending" exit makes `make update` an invalid remedy. The remedy must name the standalone script, or the template must render the pending state into its content. Candidate rule: any installer under `install/**` wrapped by `run_onchange_` that skips non-fatally prints a standalone remedy. Status: candidate, not promoted.
2. **`mise self-update VERSION` wants the bare version.** At v2026.9.13, `src/cli/self_update.rs:693` formats the release tag as `format!("v{v}")` on the non-Windows path, so `v2026.9.13` would become `vv2026.9.13`. Strip the manifest pin's `v`. Applies to any future pinned `mise self-update`.
3. **A test with a minimal PATH breaks when production code gains a helper dependency.** `test_upgrade_skips_ccr_notice_when_gh_is_unavailable` stubs PATH to six commands; `asset_manifest_pin` needs `grep`. When adding a helper call, grep the tests for `env["PATH"] = str(repo / "bin")`.
4. **Moving the success message into the function avoids a set -e trap.** With `set -Eeuo pipefail`, a guard that returns non-zero aborts the script, while one that returns 0 lets `main` print a false "Loaded". Moving the success line into `install_profile` keeps the pending path at exit 0 with no misleading output.
5. Process: the Claude auto-mode classifier blocks Claude workers from editing Claude's own permission manifest (T62 `[Self-Modification]`). Route `claude.permissions` changes to Codex workers. This is already acted on by the orchestrator.
