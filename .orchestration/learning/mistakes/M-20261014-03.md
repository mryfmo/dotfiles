# M-20261014-03

- **Evidence:** two Python edits used `re.search(r"… output: \|-\n(?:      .*\n)+", s, re.S)` to find a premise's output block; under `re.S` the `.` in `      .*\n` crosses lines, so the block swallowed every later premise, and the file dropped from seven premises to one. The checker still printed `OK` (it reads the front matter that remained) and the brief check passed; only the claim count showed the loss.
- **Detection and why not earlier:** the first regex of that shape had been used minutes before on a block followed by a short tail and looked right; the count was checked by habit, not by rule.
- **Root cause:** a greedy multi-line pattern with DOTALL applied to an indented block in a YAML front matter; no post-edit invariant on the number of premises or rows.
- **Should have been:** line-based edits (split, walk, rejoin) for blocks; a post-edit assertion that the premise count and the row count did not shrink; the pair-confirmed copy kept beside the file, which is what made the rebuild a two-minute job.
- **Corrections:** C-37.
