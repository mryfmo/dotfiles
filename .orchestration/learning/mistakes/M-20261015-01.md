# M-20261015-01

- **Evidence:** each `herdr-agents --remove-worker <worktree>` (worker-e with `--force`, the three others without) printed `status=needs-force … note=no-live-lock-recorded`, then `despawn: could not confirm '<name>' was torn down via its placement record (herdr:…:w5:p8|p9|pA|pD) — the terminal driver did not report the pane closed … Reason: runtime_error The record is KEPT`, `status=error … note=force-teardown-unconfirmed`, and `herdr-agents: despawn of <name> did not complete; re-run with --force.` Nothing changed: five placement records, four identities (`identities.sh`), four worktrees, worker-e's six untracked files. `herdr workspace list` names one workspace (wA, label `dotfiles`, one pane) and `herdr agent list` one agent (wA:p1, the orchestrator): the w5 panes are confirmed gone by herdr's own reply. The herdr driver's `terminal_despawn` (`drivers/terminals/herdr/ops.sh:675-677`) runs `herdr pane close <id>` and on any failure prints `runtime_error` and returns 13; it has no confirmed-gone code, unlike `terminal_peek` (12).
- **Detection and why not earlier:** the Stop checklist's `--remove-worker` step did not run at the 14:15Z boundary because the operator's restart (plan 020 step 5.6) ended that session first; the boundary check counts identities per worktree, not liveness, so the dead seats read as seated until `team.sh` was run in this session (06:41 JST).
- **Root cause:** despawn's confirm-before-drop rule (#625) needs the terminal driver to tell "pane gone" from an ordinary failure, and the herdr driver's despawn cannot; `--remove-worker` stops at the despawn and never reaches `delivery.sh set off`, `leave.sh` or the record, so a seat whose workspace vanished has no sanctioned teardown path.
- **Should have been:** a stale-seat path in the launcher: confirm absence from `herdr workspace list` and `herdr agent list`, then turn delivery off, leave, and rename the placement record; and the Stop checklist run before any restart, or the restart deferred until the checklist's `--remove-worker` lines are done.
