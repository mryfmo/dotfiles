# M-20261023-01 — pilot steps were handed to the operator without reading the tool's documentation or dry-running them

- When: 2026-10-23 00:2xZ to 00:5xZ JST morning (plan 025 leg 1, bridge half: steps B1, B3, B3b; the operator's line 「公式ドキュメントを精査したうえで内容を提示しているのか　その場しのぎの安易な手段を無鉄砲にくりかえしているだけなのではないのか」).
- What: the orchestrator wrote the bridge handout from `omp --help` text and a few source greps, had the operator run `omp install pi-claude-bridge@0.9.3` (failed: missing shim export), then `omp --profile pilot-bridge models claude-bridge` (failed: plugin store is per profile), then `-e <package dir>` (failed: cause still unverified), inventing a new theory after each failure instead of reading `docs/extension-loading.md`, `docs/user-facing-packages.md` and the loader source first. Three failures of one class before stopping, against the S1 three-repeat rule and the re-plan rule.
- Root cause: no rule bound a pilot handout row to (a) a citation of the doc or source line that defines the command's semantics and (b) an orchestrator-side dry run (scratch `HOME`) or an explicit reason the step is operator-only. The orchestrator also used `omp models <provider>` as the instrument for "did the extension load", although that command prints no extension load errors (`src/extensibility/extensions/loader.ts:431-457` return the error to the caller; `src/commands/models.ts` does not print it), so every negative result was ambiguous.
- Mechanism: every row of a pilot handout carries two extra columns, `source` (doc or `file:line` that defines the command's behaviour) and `dry-run` (the scratch-HOME command the orchestrator ran and its pasted output, or `operator-only: <reason>` such as a browser login or Keychain access); a row without both is not sent. Under the pstack orchestrate run (D-024-131) this lives in the unit brief's VERIFY field and in `preferences.md` line 5. An instrument that cannot show the failure it is meant to detect is refused (here: use the extensions listing or the session log, not `omp models`).
- Cost: three operator rounds (about 25 minutes of the operator's attention), one wrong disposition in plan v14 (R12R-10, to be revised), and the operator's trust.
