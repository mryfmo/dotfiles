# U178 the DeepSeek harness updater is one install transaction: the versioned tree is built whole under a name of its own, published by one link, recorded, and only then are the older trees pruned; every producer read refuses on a failed or empty answer

GOAL
U172 (PR 652, merged as cd64232a) landed `update_deepseek_harness` and paid three audit rounds (`verdicts/U172-d17fec7e.md`, `verdicts/U172-87e4d652.md`, `verdicts/U172-0c9e7a14.md`); each round found new failure modes of the same hand-written install transitions, and the decisions row of 2026-11-04T09:50:08Z opened this unit as the mechanism change instead of a fourth fix round (standing order 36). The round-3 verdict left four filed defects and one residual owned here (`dispositions.tsv` row 2026-11-04T09:50:08Z, `scripts/update-agent-assets.sh:1979`, the readlink read without a failure-injection test): the wrapper write truncates the live launcher before the step succeeds (:2003); a retry after a failed `manifest_record` deletes the last good `.previous` tree before a record succeeds (:1985); a zero-byte receipt is read as an empty receipt and the step reports an install while the receipt stays empty (:1928); a failed `cd "${HOME}/.dsh"` becomes `expected=""` and a WARN with exit 0 (:1913). The cause is one design: the step moves trees and rewrites files in place, in sequence, so every late failure needs its own undo path and every undo path is a new state the next audit can break. After this unit the step has one transaction: the versioned tree is built whole in its final place under a unique name, the wrapper is replaced by a rename, `current` is pointed at the new tree by one link call, the record is written, and the older trees go only after the record succeeded; before the link nothing the host runs has changed, and after it a failure puts `current` back where it was and leaves every older tree alone. Every producer the step reads (two `pwd -P`, the receipt, three `jq`, `shasum`, `readlink`, three `mktemp`) refuses the step on a failed or empty answer, and each refusal has a test that injects that failure.
