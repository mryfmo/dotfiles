4. The levers and their checks (each: `set -euo pipefail`, arguments validated before any network call, one `gh` call, the receipt printed as one line, exit 2 on refusal):
   - `pr-thread-reply.sh <pr> <comment-id> --body-file <file>`: `<pr>` and `<comment-id>` are decimal; the comment belongs to that PR (`gh api repos/<owner>/<repo>/pulls/<pr>/comments/<id>` returns it); the body file is under `$TMPDIR` or the store; runs `gh api -X POST repos/<owner>/<repo>/pulls/<pr>/comments/<id>/replies -F body=@<file>`; owner and repo come from `gh repo view --json nameWithOwner`, never from arguments.
   - `pr-thread-resolve.sh <pr> <comment-id>`: finds the thread whose first comment has that id (GraphQL `reviewThreads`), refuses when none or already resolved, runs `resolveReviewThread`.
   - `pr-update-branch.sh <pr>`: refuses when the PR is not open or its base is not `main`; runs `gh pr update-branch <pr>`; prints the old and new head.
   - `pr-close.sh --from-table <table.md> [--only <pr>]`: parses the clean-up table's "Open pull requests" rows whose `default` cell starts with `close:`; refuses a PR whose head branch is shared by another open PR (#396 and #412 share `tools/anthropic-auth-route-structured`; closing one with `--delete-branch` would close the other, so the lever never passes `--delete-branch`); for each PR runs `gh pr close <pr> --comment <the row's default text>`; prints one line per PR; with `--only` closes that one row.
   - `pr-body-edit.sh --body-file <file>`: worker side; resolves the PR of the current branch (`gh pr view --json number,headRefName`), refuses when the branch differs from `git branch --show-current` or the PR is not open, runs `gh pr edit <n> --body-file <file>`.
