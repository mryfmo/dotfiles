DATA SHAPE

Its steps, every one on the held descriptor `dfd = os.open(agent_dir, O_RDONLY | O_DIRECTORY | O_NOFOLLOW)`: `fstat(dfd)` is a directory of the uid, mode without group or other write; the existing `config.yml` is read through `os.open("config.yml", O_RDONLY | O_NOFOLLOW | O_NONBLOCK, dir_fd=dfd)` (ENOENT is absence; ELOOP, a non-regular `fstat` or another uid refuses naming it) and compared to the rendering (equal bytes: exit 0, nothing written); the temporary is `os.open(tmp, O_WRONLY | O_CREAT | O_EXCL | O_NOFOLLOW, 0o600, dir_fd=dfd)` with a random name (`secrets.token_hex`), so a planted regular file, link, FIFO or directory at the name is EEXIST and refuses without blocking; `fstat` of the new descriptor is a regular file of the uid with one link; `fchmod(0o600)`, write, `fsync`; `os.rename(tmp, "config.yml", src_dir_fd=dfd, dst_dir_fd=dfd)` (a link at the destination is replaced as a link, a directory is EISDIR and refuses); on any refusal `os.unlink(tmp, dir_fd=dfd)` with its own status read and reported. Exit 0 placed or kept (one line on stdout: `placed` or `kept`), exit 2 refused (one line on stderr naming the step and the errno), exit 1 a usage error. The helper imports `os`, `sys`, `stat`, `secrets`, `errno` only, runs under `python3 -I -S`, takes no path from the environment.
