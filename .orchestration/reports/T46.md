## Existing schema and convention

The original recovery section used `max_chars: 8500`, `recent_events: 12`, `recent_prompts: 4`, `recent_files: 12`, `recent_failures: 5`, and `include_project_memories: true`. `max_chars` uses `_require_int(..., minimum=1000)`; each `recent_*` count uses `_require_int(..., minimum=0)`. Recursive default merging preserves unknown keys, while invalid validated types raise `ValueError`.

The new name `files_budget_chars` is the exact integration-plan key. It combines the existing plural `files` noun from `recent_files` with the character-budget unit used by `max_chars`. Its validation uses the sibling `_require_int` style with a non-negative minimum suitable for a section sub-budget.

No config-specific test module existed, so `tests/test_config.py` was created. Its four tests cover missing-key defaults, explicit overrides, invalid type behavior, and preserved unknown keys.
