Agent asset installs now leave an atomic reverse-map prerequisite at `~/.agents/.installed-manifest.json` without changing the existing install command order or output.

## Layout and interface

- Added `scripts/lib/asset-manifest.sh` rather than embedding write logic in the updater. This keeps `scripts/update-agent-assets.sh` limited to one source statement and recording calls, and makes failure/atomicity testing independent of real installs.
- The interface is `manifest_record <step> <kind> <source_version> <absolute-path>... [-- <command>...]`.
- `jq` performs array construction and keyed replacement. This adds no dependency: `home/dot_local/bin/common/executable_herdr-agents` already has `require_command jq` hard gates.
- Each write creates a same-directory temporary file, sets mode `0600`, renders the complete JSON, and renames it atomically. Re-recording replaces only `.steps[step]`, preserving every other step.
- Invalid inputs, JSON failures, permission failures, and rename failures are swallowed by the public wrapper, which returns success and prints exactly one stderr warning.
