# T66d report: leading-tilde send lane normalization

Status: ready for review

## Result

The Pi result-delivery lane now treats a trimmed leading `~/` send.sh path as
equivalent to its exact absolute `$HOME/` path.

- Only the first `~` in a leading `~/` is replaced for prefix comparison.
- `~user/` and mid-string tildes are not normalized.
- The unchanged `PI_SEND_META` regex evaluates the original trimmed command,
  so a tilde-form `;` injection remains ask.
- Absolute send.sh, all other Pi lanes, and Claude/Codex golden bytes are
  unchanged.
