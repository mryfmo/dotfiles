# T67b report: checker subscription-auth lane

Status: ready for review

## Result

Closed the live checker gap for subscription-auth providers such as
`openai-codex`. When a selected provider has no documented single-key mapping,
`pi-model-access-check` now checks the fixed `~/.pi/agent/auth.json` path
read-only, accepts only a valid top-level JSON object containing the exact
provider key, and runs the existing JSON, RPC, and extension steps when that
entry exists. Missing, unreadable, malformed, non-object, or non-matching data
produces a safe SKIP that names both credential lanes. No credential value is
printed, copied, passed through argv, or forwarded by the checker.

The documented environment-key path and its existing missing-key message are
unchanged. The fake Pi now requires the live-confirmed RPC request object
`{"id":"t67-check","type":"prompt","message":"Reply with exactly OK"}`
and emits `agent_settled` after `agent_end`, proving the checker completes on
`agent_end` and tolerates the later event.

Appended the required one-line coverage note to the living T67 operator result
form without changing its recorded results.
