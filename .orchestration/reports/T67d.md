# T67d report: reasoning-model checker robustness

Status: ready for review

## Result

The checker now selects the last assistant message containing `type=text`
content in both JSON and RPC streams. A preceding thinking-only assistant
message is ignored, so the exact `OK` assertion applies to the final visible
reply.

RPC parsing continues until `agent_end`, EOF, or the existing safety deadline;
an answer mismatch no longer terminates event processing. Completion requires
the correlated successful prompt response plus `agent_end`, while answer
equality and explicit extension-load confirmation are reported independently.

The fake Pi fixture now reproduces the live reasoning sequence with two
message-start/end pairs and covers JSON and RPC mismatches after complete event
streams. The existing single-message case remains green.
