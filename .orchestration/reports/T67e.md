# T67e report: error-turn diagnostics

Status: ready for review

## Result

The JSON and RPC lanes now classify a final assistant message with
`stopReason=error` or an `errorMessage` field as a provider/API failure. Each
lane reports only the first 160 characters of `errorMessage`; non-error
content mismatches retain their existing message.

The implementation reuses the existing message loops and adds one parser exit
status. RPC still requires correlated prompt success plus `agent_end`, and
extension confirmation remains independent of the lane result.
