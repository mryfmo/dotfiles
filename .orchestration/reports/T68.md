# T68 report: Pi RPC bridge + agmsg integration

Status: ready for review

## Result

Added `agmsg-pi-worker`, a guarded Bash bridge that verifies or joins an exact
`pi-*` agmsg identity, holds one persistent `pi --mode rpc` child in the
requested project cwd, and delivers raw AGMSG-TASK bodies as correlated prompt
requests. The project must canonicalize under an explicit non-root scratch
root. The bridge checks the existing agmsg inbox at startup and after each
correlated `agent_end`, requires the matching successful RPC response before
completing a turn, and tolerates a later `agent_settled` event.

The bridge owns transport and liveness only. It appends the fixed instruction
exactly once and has no AGMSG-RESULT construction or send path. Pi remains
responsible for reading the task file and sending its own RESULT through
`send.sh`. PING receives a bridge-level alive PONG; child EOF or death sends a
blocked PONG to the last task peer and exits nonzero.

The agmsg registration whitelist now accepts `pi`. Bridge-only environment
controls on `check-inbox.sh` select the exact identity/team and force a check at
the two specified turn boundaries; callers that leave these variables unset
retain the original path. `whoami.sh` documents the new legal type.

## Deliberate skip

No `model_profiles.pi` entry was added. Provider/model values await the
operator lane, and adding an incomplete profile would expand generator and
validator work beyond T68's optional trivially-additive allowance. The bridge
already accepts `--provider` and `--model`.

## Extension loading contract

Pi v0.84.1's pinned extension documentation lists
`~/.pi/agent/extensions/*.ts` as a global auto-discovery location. The bridge
preflights `~/.pi/agent/extensions/permgate.ts` and also passes that exact path
with `--extension`. Operational startup relies on the explicit flag's fatal
load behavior; global discovery independently covers the same deployed file.
The fake transcript verifies the exact argv. No real Pi was run.

Pinned source:
https://github.com/earendil-works/pi/blob/v0.84.1/packages/coding-agent/docs/extensions.md#extension-locations
