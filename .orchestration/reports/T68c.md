# T68c report: PR #134 security and compliance fixes

Status: ready for review

## Result

Both CompactionDB receivers now treat a project's `.claude/contextdb`
directory only as an opt-in marker. They execute the trusted installed CLI at
`$HOME/.agents/compactiondb/.claude/hooks/contextdb_cli.py`, require it to
exist, and pass the project as explicit `--project-root` data while retaining
the project cwd. A malicious project-local `.claude/hooks/contextdb_cli.py` is
never executed; absent opt-in or installed runtime is a silent no-op.

The Pi `agmsg_send` tool rejects model-owned `team` and `to` identifiers unless
they match `^[a-z0-9][a-z0-9_-]{0,63}$`. The shared legacy `send.sh` transport
now quotes all four SQLite values with one fixed helper, so quote-bearing
legacy identifiers and bodies round-trip exactly without SQL injection. The
T68-touched shell documentation is now English shdoc-compatible.

Both Pi extension integrity hashes were updated after formatting. No behavior
outside the three requested findings changed.
