# T70 report: Pi session evidence extractor

Status: ready for review

## Result

Added `pi-session-evidence <session.jsonl> [--json]` as a standard-library
Python executable, matching the repository's existing managed Python command
convention.

The command reads the input only, refuses files beyond 50 MiB, counts malformed
physical lines without aborting, and prints one warning line to stderr. It
reconstructs the active path from the last valid appended entry through its
`parentId` ancestors, then reports:

- bounded compaction summaries plus `tokensBefore`, `readFiles`, and
  `modifiedFiles`;
- ordered model changes;
- assistant-message input/output/cache-read/cache-write and cost totals;
- active-path entry counts and total/active/leaves branch statistics.

Default output is acceptance-oriented text. `--json` emits the complete stable
object on stdout, keeping malformed-line warnings on stderr so the JSON remains
machine-readable.
