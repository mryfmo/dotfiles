    G16 operator handout: host cleanup¶

    The installers in this repository change only what they manage. The rows below change a host outside that scope (old tool versions, stray binaries, retired worktrees, credential rows), so the operator runs them by hand. Agents never run them (standing order 30). Every row says how it was dry-run read-only, and when: the facts are from 2026-10-25 against origin/main c63415e5. Run the dry-run column again just before the command; if its output differs from the one below, stop and re-check.

    Hosts: mac is the operator's macOS machine, spark is the Ubuntu client spark-9e8d.

    Credentials and logins¶

    # host command source finding dry-run (read-only)
    1 mac In an interactive omp session run /logout openai-codex, once for the default profile and once under omp --profile audit; then rm -r ~/.omp/profiles/pilot-bridge/ F143 (handed over by U66) operator-only: /logout is an interactive TUI command on a credential row. ls -ld ~/.omp/profiles/pilot-bridge printed drwx------ … pilot-bridge (present).
    2 mac mkdir -p ~/.agents/backups/codex-rules && mv ~/.codex/rules/default.rules.pre-apply-20261015 ~/.agents/backups/codex-rules/ F172 (handed over by U70) ls ~/.codex/rules/ printed default.rules and default.rules.pre-apply-20261015.
    3 mac provision-machine-key, then the two gh ssh-key add ~/.ssh/id_ed25519.pub --type authentication / --type signing commands it prints (or setup-gh, which runs them under a one-off login), then chezmoi apply so the git config renders signing again F060 (home/dot_config/git/config.tmpl:1-26) operator-only: creates a key and a GitHub credential row. git config --get user.signingkey printed ~/.ssh/id_ed25519.pub; ls ~/.ssh/*.pub printed No such file or directory.
