    home/dot_local/bin/common/executable_hcom-seat¶

    Plan 025 W5b (U7), the minimal form before X. A seat is one omp process that hcom omp starts in a herdr pane (hcom omp --help: hcom [N] omp [args...], --tag <name>, --dir <path>, --terminal <preset>; hcom gives the seat HCOM_LAUNCHED=1, HCOM_TAG and HCOM_DIR). For <role> the launch line is hcom omp --tag <name> --dir <dir> --terminal herdr --go -- --profile <role> --config ~/.agents/omp/policies/<role>.yml --config ~/.agents/omp/profiles/<role>.yml --append-system-prompt ~/.agents/omp/rules/<role>.md -e <ext>...; hcom drops the -- and forwards what follows to omp verbatim (hcom 0.7.30 and 0.7.31, measured 2026-10-23 and 2026-10-24; extract_launch_flags, src/commands/launch.rs:572-581 at v0.7.30). --go is hcom's launch gate: inside an AI tool, hcom without it prints == LAUNCH PREVIEW == / Add --go to proceed. and starts nothing (launch.rs:48,388-389, measured on the real host 2026-10-23), and extract_launch_flags consumes it only before the -- (launch.rs:650-652). The profile equals the role. A named profile reads its own ~/.omp/profiles/<role>/agent/config.yml (pi-utils src/dirs.ts:312-315, U10), so the manifest's modelRoles.default and skills.customDirectories reach the seat only through the second overlay, rendered per role (U14); the first overlay owns the approval mode (U6). Both are required. The seat's standing rules, rendered per role from the manifest's standing_rules (U75), ride --append-system-prompt: the overlays disable the native provider (U66), so no profile context file loads, and the explicit flag also wins over any project APPEND_SYSTEM.md. The rules file is required and must be non-empty, since omp reads a missing path as literal text. The extensions default to the pi-claude-bridge, which the role's model route needs, plus the openai-siwc when it is present; --ext replaces that list. The roles are orchestrator and worker; every audit is one fresh omp-run.sh --role audit run, never a seat (regime-cutover U57, U58). The stop gate's directory ~/.agents/omp/hooks is loaded on every launch, whatever --ext says, and the launch line ends with --hcom-team <HCOM_TEAM>: hcom passes HCOM_DIR into the pane but not HCOM_TEAM, so the flag, which the gate registers, carries exactly the team this launch was given, an explicit one included (regime-cutover U33c; omp refuses the flag when no loaded extension registers it, so a launch without the gate fails instead of running unguarded). Every directory, a default, --ext or the gate's, must resolve to an entry of claude.levers.extensions in the manifest the self-check reads (regime-cutover U31), else the launch is refused. The orchestrator sits in the repository this command runs in; every other role gets the worktree <seats-root>/<name>, which is created detached from origin/main (HEAD in a repository without it) when absent and reused when it is a worktree of this repository (any other directory at that path is refused). HCOM_DIR, HCOM_TEAM and the seats root come from the environment or --seats-root when set, else from the checkout through the sourced regime-env helper (regime-cutover U33: ~/.local/state/hcom/<slug>, <slug>, ~/.local/state/omp-seats/<slug>), and are exported to the seat. The seat's omp runs under OS containment (regime-cutover U85): Anthropic's sandbox-runtime srt (sandbox-exec on macOS, bubblewrap on Linux) with per-seat settings, through an omp shim at <seats-root>/.sandbox/<name>/bin/omp that is put first on PATH, so hcom pins it as the pane's tool; the shim runs a canary under the settings and refuses to start omp unless a write into the sandbox directory and reads of the settings and ~/.ssh fail inside (seat_sandbox_write below). srt and omp run by their physical argv (pin_exec), and so do hcom (exec'd by it) and herdr (through wrappers in the shim directory); none of their files may be or lie under a write root of any seat. Every input path (HOME, --seats-root, HCOM_DIR, REGIME_SEATS_ROOT, CLAUDE_CONFIG_DIR) and every path written into the srt settings must be clean: absolute, components of [A-Za-z0-9._@+-] only, no '.' or '..' component and no trailing '/', since srt reads a settings path as a pattern. The settings are written by the shell (no JSON tool) and read back by /usr/bin/plutil on macOS, /usr/bin/jq on Linux. No caller PATH entry runs anything: the first statement sets PATH to the system directories, the complete protected set is built by (device, inode) identity before mise or any other tool runs, and the tools beyond them (git, hcom, herdr, omp, srt, node, bun, claude, jq; bwrap, socat and rg on Linux) are resolved through mise which under env -i from /, else command -v on the caller's PATH, checked (absolute, no control character, an executable regular file, no shim, neither it nor a directory above it with the identity of a seat write root) and linked into ~/.local/state/hcom-seat/tools; PATH is then that directory and the system directories, for hcom-seat, hcom, the shim and srt (whose Linux settings name bwrap, socat and rg). Inside the sandbox omp gets that PATH followed by the caller's absolute entries. Every executable is checked with its interpreter chain, and hcom-seat, the shim and the wrappers run under #!/bin/bash. The git state host git reads for this repository's worktrees (config, config.worktree, info, hooks, commondir, gitdir, the worktree's .git file) is denied to every seat, and a launch over such state holding a key host git would act on is refused (git_state_check) before the first git command; every git command hcom-seat runs has hooks, fsmonitor and worktree config off. Every program's seats root is read-denied but the seat's own paths. No seat launches a seat: the orchestrator's sandbox, like the worker's, has no herdr socket and no write to the seats root, and a launch from inside a seat is refused; seats are started from a terminal outside every seat (the operator or the coordinator, as gate G7 was). Every input is checked before anything is created or started: an unknown role, a launch inside a seat, a name or team outside ^[a-z0-9][a-z0-9_-]{0,63}$, a store regime-env refuses, an absent policy or profile overlay or extension directory, a cwd outside a git checkout, a required tool that is missing, a shim or a file that is or lies under a seat write root, or no sandbox-exec (macOS) or bubblewrap, socat and ripgrep (Linux) is exit 2 with the reason. A seat directory that holds .omp is refused too, after the worktree exists and before hcom starts (U66: omp applies the cwd's .omp/config.yml at start, which no setting turns off). --dry-run prints the launch line, and the derived environment and sandbox on stderr, and creates and starts nothing but the private tool links. Otherwise hcom's own exit status is returned (hcom omp --help: 0 ready, 1 launch failed, 2 still launching or blocked on user attention).

# @description Refuse to run unless this file's sha256 equals its pin in the manifest beside it (regime-cutover U31):
#   `~/.agents/agent-config.yaml` for the installed copy under ~/.local/bin/common, which a sandboxed session cannot
#   write, else the checkout's home/dot_agents/agent-config.yaml. Every read is checked; a failure exits 2 naming the
#   file. The pin is the `claude.levers.sha256.<name>` line, which `scripts/generate-agent-configs.py` refreshes.
# @set LEVER_MANIFEST The manifest the pin came from.
# @set LEVER_DIR The physical directory of this file, where the sourced regime-env helper sits (U33).
lever_self_check() {
    local src dir self name pin digest home
    # The directory is split from the path in the shell, so no external producer (dirname) can fail unseen.
    src=${BASH_SOURCE[0]}
    case ${src} in
    */*) dir=${src%/*} ;;
    *) dir=. ;;
    esac
    [[ -n ${dir} ]] || dir=/
    dir=$(cd "${dir}" && pwd -P) || {
        echo "${src##*/}: refused: cannot resolve the script directory of ${src}" >&2
        exit 2
    }
    self=${dir}/${BASH_SOURCE[0]##*/}
    # shellcheck disable=SC2034 # read by the levers that source regime-env from this directory
    LEVER_DIR=${dir}
    name=${self##*/}
    home=$(cd "${HOME}" 2> /dev/null && pwd -P) || home=''
    if [[ -n ${home} && ${dir} == "${home}/.local/bin/common" ]]; then # lint-comparisons: allow both sides are pwd -P forms
        LEVER_MANIFEST=${HOME}/.agents/agent-config.yaml
    else
        LEVER_MANIFEST=${dir}/../../home/dot_agents/agent-config.yaml
    fi
    [[ -r ${LEVER_MANIFEST} ]] || {
        echo "${name}: refused: manifest unreadable: ${LEVER_MANIFEST}" >&2
        exit 2
    }
    pin=$(sed -n -E "s/^      ${name//./\\.}: ([0-9a-f]{64})\$/\\1/p" "${LEVER_MANIFEST}") || {
        echo "${name}: refused: cannot read ${LEVER_MANIFEST}" >&2
        exit 2
    }
    [[ ${pin} =~ ^[0-9a-f]{64}$ ]] || {
        echo "${name}: refused: no single sha256 pin for ${name} in ${LEVER_MANIFEST}" >&2
        exit 2
    }
    if command -v sha256sum > /dev/null; then
        digest=$(sha256sum < "${self}") || digest=''
    else
        digest=$(shasum -a 256 < "${self}") || digest=''
    fi
    digest=${digest%% *}
    [[ ${digest} =~ ^[0-9a-f]{64}$ ]] || {
        echo "${name}: refused: cannot hash ${self}" >&2
        exit 2
    }
    [[ ${digest} == "${pin}" ]] || {
        echo "${name}: refused: sha256 ${digest} of ${self} differs from the pin in ${LEVER_MANIFEST}" >&2
        exit 2
    }
}
lever_self_check

# @description Succeed when `$1` is a clean absolute path that srt cannot read as a pattern: `/` followed by
#   components of `[A-Za-z0-9._@+-]` only (no glob metacharacter `*?[]{}`, no whitespace, no quote or backslash), none
#   of them empty, `.` or `..`, and no trailing `/`. srt 0.0.81 turns a settings path into a Seatbelt regex or a glob,
#   so `/private/tmp/hcom*` would grant its siblings; a clean path names exactly itself.
# @arg $1 string The path.
# @exitcode 1 The path is not clean.
clean_path() {
    [[ $1 =~ ^(/[A-Za-z0-9._@+-]+)+$ ]] || return 1
    [[ /$1/ != */./* && /$1/ != */../* ]] # lint-comparisons: allow a component test on one path, no path compare
}

# @description Refuse (exit 2) unless `$2` is a clean absolute path (clean_path).
# @arg $1 string What the path is, for the refusal.
# @arg $2 string The path.
require_clean_path() {
    clean_path "$2" ||
        refuse "$1 '$2' is not a clean absolute path: every component must be [A-Za-z0-9._@+-] and neither '.' nor '..', with no trailing '/'"
}

# @description Print a JSON array of the arguments, each a clean path (clean_path), so no JSON escaping is needed and
#   no settings tool runs. An argument that is not clean is a refusal.
# @arg $1 string What the list is, for the refusal.

json_paths() {

}

# @description Print the `filesystem.allowWrite` entries of the seat settings file `$2`, one per line: by
#   `/usr/bin/plutil` on macOS (`-extract … raw -expect array` prints the count, `-expect string` each entry; macOS
#   12 and later, plutil(1)), by `/usr/bin/jq` on Linux (from install/ubuntu/common/dependencies.sh). Each entry must
#   be a clean path.
# @arg $1 string The system name (`uname -s`).
# @arg $2 string The settings file.
# @exitcode 1 The file cannot be read, has no such array, or holds an entry that is not a clean path.
allow_write_list() {
    local n i entry line
    case $1 in
    Darwin)
        n=$(/usr/bin/plutil -extract filesystem.allowWrite raw -expect array -o - "$2") || return 1
        [[ ${n} =~ ^[0-9]+$ ]] || return 1
        for ((i = 0; i < n; i++)); do
            # -n prints no newline of plutil's own, and the 'x' keeps an entry's trailing newlines from the command
            # substitution, so "/tmp/root\n" reaches clean_path whole and is refused.
            entry=$(/usr/bin/plutil -extract "filesystem.allowWrite.${i}" raw -expect string -n -o - "$2" && printf x) ||
                return 1
            entry=${entry%x}
            clean_path "${entry}" || return 1
            printf '%s\n' "${entry}"
        done
        ;;
    *)
        [[ -x /usr/bin/jq ]] || return 1
        # Every entry must be a string without a newline, or the line-per-entry output below would drop or split it.
        /usr/bin/jq -e '.filesystem.allowWrite | type == "array" and all(.[]; type == "string" and (test("\n") | not))' \
            "$2" > /dev/null || return 1
        n=$(/usr/bin/jq -e '.filesystem.allowWrite | length' "$2") || return 1
        # No -e here: an empty array prints nothing, which -e would report as a failure; so jq's status is checked
        # unconditionally, and an empty read with a nonzero n fails the count check below.
        entry=$(/usr/bin/jq -r '.filesystem.allowWrite[]' "$2") || return 1
        i=0
        while IFS= read -r line; do
            [[ -n ${line} ]] || continue
            clean_path "${line}" || return 1
            printf '%s\n' "${line}"
            i=$((i + 1))
        done <<< "${entry}"
        ((i == n)) || return 1
        ;;
    esac
}

# @description Set `ancestors` to the absolute path `$1` and every directory above it, up to `/` (regime-cutover
#   U85). Every ancestor walk of hcom-seat goes through this: a relative path (a `#!sh` interpreter line) would never
#   reach `/`, so it is refused before the walk, and the walk itself stops at `/` and refuses after 4096 steps.
# @arg $1 string An absolute path.
# @set ancestors The paths, `$1` first.
ancestors_of() {
    local p=$1 n=0
    [[ ${p} == /* && ${p} != *[[:cntrl:]]* ]] || # lint-comparisons: allow an absolute-path and content test
        refuse "'${p}' is not an absolute path free of control characters"
    ancestors=()
    while :; do
        ancestors+=("${p}")
        [[ ${p} != / ]] || return 0 # lint-comparisons: allow the walk ends at the root, no path compare
        n=$((n + 1))
        ((n <= 4096)) || refuse "the path ${1} has more than 4096 components"
        p=${p%/*}
        [[ -n ${p} ]] || p=/
    done
}

# @description Print the physical form of the absolute path `$1`: every symlink followed (at most 40 hops in all,
#   one budget for the whole resolution) and the directory in its `pwd -P` form. A path that does not exist yet is
#   its nearest existing ancestor's physical form with the rest appended, so a write root a launch has not created
#   yet still compares with what it will be. Iterative (regime-cutover U85): a dangling link that names a path
#   under itself (`.state/<name> -> <name>/child`) spends the one budget and fails instead of recursing. Only shell
#   builtins and `/usr/bin/readlink` run.
# @arg $1 string An absolute path.
# @stdout The physical path.
# @exitcode 1 Not absolute, a control character in it or in a link, more than 40 links, or a directory that cannot
#   be resolved.
physical_path() {
    local p=$1 tail='' link dir n=0
    [[ ${p} == /* && ${p} != *[[:cntrl:]]* ]] || return 1 # lint-comparisons: allow an absolute-path and content test
    while :; do
        # p is absolute, so each step shortens it and the walk ends at `/`, which exists.
        while [[ ! -e ${p} && ! -L ${p} ]]; do
            tail=/${p##*/}${tail}
            p=${p%/*}
            [[ -n ${p} ]] || p=/
        done
        [[ -L ${p} ]] || break
        n=$((n + 1))
        ((n <= 40)) || return 1
        # The '.' keeps a target's own trailing newlines from the command substitution.
        link=$(/usr/bin/readlink "${p}" && printf .) || return 1
        link=${link%.}
        link=${link%$'\n'}
        [[ -n ${link} && ${link} != *[[:cntrl:]]* ]] || return 1
        case ${link} in
        /*) p=${link} ;;
        *) p=${p%/*}/${link} ;;
        esac
    done
    if [[ ${p} == / ]]; then # lint-comparisons: allow the root itself, whose `cd //` form pwd prints as `//`
        printf '%s\n' "${tail:-/}"
    elif [[ -d ${p} ]]; then
        dir=$(cd "${p}/" && pwd -P) || return 1
        printf '%s%s\n' "${dir%/}" "${tail}"
    else
        dir=$(cd "${p%/*}/" && pwd -P) || return 1
        printf '%s/%s%s\n' "${dir%/}" "${p##*/}" "${tail}"
    fi
}

# @description Print the physical file `$1` names (physical_path); it must be a regular executable file.
# @arg $1 string An absolute path.
# @stdout The physical path.
# @exitcode 1 physical_path failed, or the result is not a regular executable file.
physical_file() {
    local p
    p=$(physical_path "$1") || return 1
    [[ -f ${p} && -x ${p} ]] || return 1
    printf '%s\n' "${p}"
}

# @description Refuse (exit 2) when the physical path `$2`, or any directory above it, has the identity of a
#   protected write root (`root_ids`).
# @arg $1 string A label for the refusal.
# @arg $2 string A physical path.
refuse_if_seat_writable() {
    local ids id i named probe=()
    # The physical file and every directory above it, up to /, each compared by (device, inode): a case alias on a
    # case-insensitive file system or a hardlink of a writable file has the identity of what it aliases.
    ancestors_of "$2"
    probe=("${ancestors[@]}")
    ids=$(/usr/bin/stat "${stat_args[@]}" -- "${probe[@]}") || refuse "cannot read the identity of $1 $2 or a directory above it"
    i=0
    while IFS= read -r id; do
        if [[ ${root_ids} == *$'\n'"${id}"$'\n'* ]]; then # lint-comparisons: allow compares (device, inode) identities, not paths
            named=$(root_named "${id}") || named=${id}
            refuse "$1 $2 is or lies under the seat write root ${named} (${probe[i]} has its identity ${id})"
        fi
        i=$((i + 1))
    done <<< "${ids}"
}

# @description Print the write root whose identity is `$1`.
# @arg $1 string A `<device>:<inode>` identity.
root_named() {
    local i
    for ((i = 0; i < ${#root_id_list[@]}; i++)); do
        [[ ${root_id_list[i]} != "$1" ]] || { # lint-comparisons: allow compares (device, inode) identities, not paths
            printf '%s\n' "${root_path_list[i]}"
            return 0
        }
    done
}

# @description Add the (device, inode) identity of every argument that exists, file or directory, every link
#   followed, to the protected set (`root_ids`, `root_id_list`, `root_path_list`). A path that does not exist holds
#   no executable; one that exists and cannot be read is a refusal.
# @arg $@ string Absolute paths.
add_roots() {
    local present=() path ids id i=0 named
    for path in "$@"; do
        [[ ${path} == /* && ${path} != *[[:cntrl:]]* ]] || refuse "the seat write root '${path}' is not an absolute path" # lint-comparisons: allow an absolute-path and content test
        [[ -e ${path} || -L ${path} ]] || continue
        present+=("${path}")
    done
    ((${#present[@]})) || return 0
    ids=$(/usr/bin/stat "${stat_args[@]}" -- "${present[@]}") || refuse "cannot read the identity of a seat write root among: ${present[*]}"
    while IFS= read -r id; do
        [[ ${id} =~ ^[0-9]+:[0-9]+$ ]] || refuse "unexpected identity '${id}' of ${present[i]}"
        root_ids+=${id}$'\n'
        root_id_list+=("${id}")
        named=$(physical_path "${present[i]}") || refuse "cannot resolve the seat write root ${present[i]}"
        root_path_list+=("${named}")
        i=$((i + 1))
    done <<< "${ids}"
}

# @description Succeed when a tool is a shim, as scripts/orchestrator/ci-rerun.sh decides it (U61): its physical file
#   is named mise in any letter case or is the mise binary, or the directory it was found in or resolves to is named
#   shims in any letter case. A mise shim picks its version from the cwd's config files, which a seat writes.
# @arg $1 string The path the tool was found at.
# @arg $2 string Its physical path.
is_shim() {
    local d
    [[ ${2##*/} == [Mm][Ii][Ss][Ee] ]] && return 0 # lint-comparisons: allow a file-name test, not a comparison of two paths
    [[ -n ${mise_real} && $2 -ef ${mise_real} ]] && return 0

        [[ ${d}/ == */[Ss][Hh][Ii][Mm][Ss]/* ]] && return 0 # lint-comparisons: allow a directory-name test, not a comparison of two paths
    done
    return 1
}

# @description Print the first executable `$1` on PATH, which hcom-seat has set: the system directories, then the
#   private tool directory before them once it is filled.
# @arg $1 string The command name.
# @stdout The path, symlinks not yet followed.
# @exitcode 1 None found.
find_on_path() {
    local path_dir path_dirs=()
    IFS=: read -r -a path_dirs <<< "${PATH}"
    for path_dir in "${path_dirs[@]}"; do
        [[ -n ${path_dir} && -x ${path_dir}/$1 && ! -d ${path_dir}/$1 ]] || continue
        printf '%s\n' "${path_dir}/$1"
        return 0
    done
    return 1
}

# @description Print the value of the git pointer file `$1` (a `.git` file, `commondir`, `gitdir`) read whole
#   (regime-cutover U85). git consumes the complete content less its trailing newlines, so only a single line is a
#   value: content that cannot be read, is empty, or holds any control character once one final newline is dropped (a
#   second line, a carriage return) fails, and the caller refuses. Pointer files are read this way only where git
#   cannot be asked yet (before the git state is checked); everywhere after, git answers (git_paths_of). A NUL
#   byte, or a byte count other than the file's size, fails too.
# @arg $1 string The file.
# @stdout The value.
# @exitcode 1 It cannot be read, is empty, or is not a single line free of control characters.
pointer_value() {
    local LC_ALL=C content size
    # Bash drops NUL bytes from a command substitution, so they are made \001 (a control character, refused) in the
    # same pass, and the bytes read must number the file's size: what is checked is what git reads.
    content=$({ /bin/cat -- "$1" | /usr/bin/tr '\000' '\001'; } && printf .) || return 1
    content=${content%.}
    size=$(/usr/bin/wc -c < "$1") || return 1
    size=${size//[[:space:]]/}
    [[ ${size} =~ ^[0-9]+$ ]] && ((${#content} == size)) || return 1
    content=${content%$'\n'}
    [[ -n ${content} && ${content} != *[[:cntrl:]]* ]] || return 1
    printf '%s\n' "${content}"
}

# @description Resolve `$2` to the argv that runs it with no lookup left: its physical file, preceded by the physical
#   interpreter when it is a `#!` script (`#!/abs/interp` or `#!/usr/bin/env <name>`, no arguments; an interpreter
#   that is itself a script is refused). No part may be, or lie under, a write root of any seat (`root_ids`), since
#   a seat that could rewrite a file the launch runs would run uncontained on the next launch. A failure exits 2
#   naming `$1`.
# @arg $1 string A label for the refusal.
# @arg $2 string The executable's path.
# @set pinned The argv.
# @set pinned_spelled The interpreter as the `#!` line spells it (what the kernel follows), or empty.
pin_exec() {
    local label=$1 file first magic interp name extra interp_path
    pinned_spelled=''
    # The spelling the kernel will follow, every link hop, is held to the identity check too: a link in a write root
    # that points outside it passes the physical check today and can be retargeted before the next exec.
    refuse_if_link_chain_writable "${label}" "$2"
    file=$(physical_file "$2") || refuse "cannot resolve ${label} to a physical executable file: $2"
    refuse_if_seat_writable "${label}" "${file}"
    [[ -r ${file} ]] || refuse "cannot read ${label}: ${file}"
    # Each read's status is checked (pipefail covers head; /usr/bin/od on macOS exits 0 on a read error, so it only
    # formats): a failed read is refused, never taken for a file without an interpreter line.
    magic=$(/usr/bin/head -c 2 -- "${file}" | /usr/bin/od -An -tx1) || refuse "cannot read ${label}: ${file}"
    first=''
    if [[ ${magic//[[:space:]]/} == 2321 ]]; then # lint-comparisons: allow the hex bytes of `#!`, no path compare
        first=$(/usr/bin/head -n 1 -- "${file}") || refuse "cannot read the interpreter line of ${label}: ${file}"
    fi
    pinned=("${file}")
    case ${first} in
    '#!'*)
        extra=''
        read -r interp name extra <<< "${first#??}"
        pinned_spelled=${interp}
        if [[ ${interp} == /usr/bin/env ]]; then # lint-comparisons: allow the literal interpreter line, no path compare
            [[ -n ${name} && -z ${extra} && ${name} != -* ]] ||
                refuse "${label}: unsupported interpreter line '${first}' in ${file}"
            interp_path=$(find_on_path "${name}") || refuse "${label}: interpreter ${name} not found on PATH"
        else
            [[ -z ${name} ]] || refuse "${label}: unsupported interpreter line '${first}' in ${file}"
            # The kernel would not run a relative interpreter as written; it is refused before any walk over it.
            [[ ${interp} == /* ]] || # lint-comparisons: allow an absolute-path test
                refuse "${label}: interpreter line '${first}' in ${file} names no absolute path"
            interp_path=${interp}
        fi
        refuse_if_link_chain_writable "the interpreter of ${label}" "${interp_path}"
        interp=$(physical_file "${interp_path}") || refuse "cannot resolve the interpreter of ${label}: ${interp_path}"
        refuse_if_seat_writable "${label}" "${interp}"
        [[ -r ${interp} ]] || refuse "cannot read the interpreter of ${label}: ${interp}"
        magic=$(/usr/bin/head -c 2 -- "${interp}" | /usr/bin/od -An -tx1) || refuse "cannot read the interpreter of ${label}: ${interp}"
        [[ ${magic//[[:space:]]/} != 2321 ]] || refuse "${label}: its interpreter ${interp} is itself a script" # lint-comparisons: allow the hex bytes of `#!`, no path compare
        pinned=("${interp}" "${file}")
        ;;
    esac
}

# @description Refuse (exit 2) an optional tool whose `#!` line spells its interpreter outside the trusted system
#   directories (regime-cutover U85, a best-effort reduction of the G17 residual, README "Boundary"): the directory
#   the line names, followed physically, must be or lie under `/bin`, `/usr/bin`, `/sbin`, `/usr/sbin` or
#   `~/.local/share/mise/installs`, by (device, inode) identity (`trusted_ids`), however the spelling reaches it, so
#   a directory alias into a seat write root (`alias -> $HCOM_DIR/subdir`) is refused. A binary passes.
# @arg $1 string The tool's name, for the refusal.
trusted_interpreter_check() {
    local dir ids id
    [[ -n ${pinned_spelled} ]] || return 0
    dir=${pinned_spelled%/*}
    dir=$(physical_path "${dir:-/}") || refuse "cannot resolve the interpreter directory of $1: ${pinned_spelled}"
    ancestors_of "${dir}"
    ids=$(/usr/bin/stat "${stat_args[@]}" -- "${ancestors[@]}") || refuse "cannot read the identity of ${dir}"
    while IFS= read -r id; do
        [[ ${trusted_ids} != *$'\n'"${id}"$'\n'* ]] || return 0 # lint-comparisons: allow compares (device, inode) identities, not paths
    done <<< "${ids}"
    refuse "$1: its interpreter ${pinned_spelled} lies outside /bin, /usr/bin, /sbin, /usr/sbin and ~/.local/share/mise/installs (${dir})"
}

# @description Refuse (exit 2) when any hop of the symlink chain `$2` (the spelling itself, then each link target in
#   turn) is, or lies under, a protected write root (refuse_if_seat_writable on each hop as spelled, which compares
#   the hop's target and every directory above the spelling), so the path the kernel follows at exec time cannot be retargeted by a seat.
# @arg $1 string A label for the refusal.
# @arg $2 string An absolute path.
refuse_if_link_chain_writable() {
    local p=$2 link n=0
    [[ ${p} == /* ]] || refuse "$1 ${p} is not an absolute path" # lint-comparisons: allow an absolute-path test
    while :; do
        # The hop as spelled: stat follows it to its target, and every directory above the spelling is compared too.
        refuse_if_seat_writable "$1" "${p}"
        [[ -L ${p} ]] || return 0
        n=$((n + 1))
        ((n <= 40)) || refuse "$1 ${2}: too many symbolic links"
        link=$(/usr/bin/readlink "${p}") || refuse "cannot read the link $1 ${p}"
        case ${link} in
        /*) p=${link} ;;
        *) p=${p%/*}/${link} ;;
        esac
    done
}

# @description Collect the git state host git reads for the worktrees of this repository into `git_state`, make sure
#   each file exists, and refuse (exit 2) a launch over state a seat may have written. The set: the common `config`,
#   `config.worktree`, `info/` and `hooks/`; for every linked worktree `worktrees/<n>/config.worktree`, `info/`,
#   `commondir` and `gitdir`; and the seat worktree's own `.git` file. None may be a symbolic link. Every
#   `config.worktree` may hold only the keys `git sparse-checkout` writes (`core.sparseCheckout`,
#   `core.sparseCheckoutCone`): anything else (`core.fsmonitor`, `core.hooksPath`, `filter.*`, `diff.*.textconv`,
#   `include.*`, `includeIf.*`, `extensions.*` among them) is a refusal, read with `git config --no-includes`, which
#   runs nothing the file names. Every `commondir` must lead to this common directory, and the seat worktree's
#   `.git` file into its `worktrees/`. An absent `config.worktree` is created empty and an absent `info/` or `hooks/`
#   empty, which git reads as no setting.
#   It runs before the first host git command (with the seat directory empty) and again before each git command in
#   the seat directory and when the settings are written.
# @arg $1 string The physical git common directory.
# @arg $2 string The physical seat directory, or empty.
# @set git_state The paths, for the seat's write denies.
git_state_check() {
    local common_real=$1 dir_real=$2 wt f names name line target
    git_state=("${common_real}/config" "${common_real}/config.worktree" "${common_real}/info" "${common_real}/hooks")
    for wt in "${common_real}"/worktrees/*/; do
        [[ -d ${wt} ]] || continue
        wt=${wt%/}
        git_state+=("${wt}/config.worktree" "${wt}/info")
        for f in commondir gitdir; do
            if [[ -e ${wt}/${f} || -L ${wt}/${f} ]]; then git_state+=("${wt}/${f}"); fi
        done
        if [[ -e ${wt}/commondir ]]; then
            # Read here before any git may run (the first call precedes the first git command); git has no query for
            # another worktree's commondir. One line or a refusal: git would consume every line.
            line=$(pointer_value "${wt}/commondir") ||
                refuse "cannot read ${wt}/commondir as one line free of control characters"
            case ${line} in # lint-comparisons: allow a relative operand is made absolute, no path compare
            /*) target=${line} ;;
            *) target=${wt}/${line} ;;
            esac
            [[ ${target} -ef ${common_real} ]] || refuse "${wt}/commondir leads to ${line}, not to ${common_real}"
        fi
    done
    if [[ -n ${dir_real} && -f ${dir_real}/.git ]]; then git_state+=("${dir_real}/.git"); fi
    for f in "${git_state[@]}"; do
        [[ ! -L ${f} ]] || refuse "the git state ${f} is a symbolic link"
        # A dry run validates and creates nothing: an absent file holds no setting, and the real launch creates it.
        ((! dry_run)) || continue
        case ${f##*/} in
        info | hooks) [[ -d ${f} ]] || /bin/mkdir -p "${f}" || refuse "cannot create ${f}" ;;
        config.worktree) [[ -f ${f} ]] || : >> "${f}" || refuse "cannot create ${f}" ;;
        esac
    done
    for f in "${git_state[@]}"; do
        [[ ${f##*/} == config.worktree && -e ${f} ]] || continue
        # From /, so no repository around the cwd is discovered or read; git() adds the overrides.
        names=$(cd / && git config --file "${f}" --no-includes --name-only --list) ||
            refuse "cannot read the git config ${f}"
        while IFS= read -r name; do
            case ${name} in
            '' | core.sparsecheckout | core.sparsecheckoutcone) ;;
            *) refuse "the git config ${f} sets ${name}, which host git would act on; a seat may have written it" ;;
            esac
        done <<< "${names}"
    done
    # The seat worktree's `.git` file is git's to read (relative forms, `--relative-paths`, included): once the
    # state it reads has passed, git names the git directory and common directory it resolves there.
    if [[ -n ${dir_real} && -f ${dir_real}/.git ]]; then
        git_paths_of 2 -C "${dir_real}" rev-parse --path-format=absolute --git-dir --git-common-dir
        [[ ${git_paths[0]%/*} -ef ${common_real}/worktrees && ${git_paths[1]} -ef ${common_real} ]] ||
            refuse "${dir_real}/.git leads to ${git_paths[0]}, outside ${common_real}/worktrees"
    fi
}

# @description Run host git (git, the checked argv) with `$2...` and read its whole answer into `git_paths`
#   (regime-cutover U85): exactly `$1` newline-terminated lines, each an absolute path free of control characters. A
#   failing git, an unterminated line, another count (a path holding a newline splits into more), a relative path or
#   a control character refuses (exit 2).
# @arg $1 int The number of paths.
# @arg $@ string git's arguments after it.
# @set git_paths The paths.
git_paths_of() {
    local count=$1 out line
    shift
    out=$(git "$@" && printf .) || refuse "git $* failed"
    out=${out%.}
    git_paths=()
    while [[ -n ${out} ]]; do
        [[ ${out} == *$'\n'* ]] || refuse "git $* printed an unterminated line"
        line=${out%%$'\n'*}
        out=${out#*$'\n'}
        [[ ${line} == /* && ${line} != *[[:cntrl:]]* ]] || # lint-comparisons: allow an absolute-path and content test
            refuse "git $* printed '${line}', not an absolute path free of control characters"
        git_paths+=("${line}")
    done
    ((${#git_paths[@]} == count)) || refuse "git $* printed ${#git_paths[@]} paths, not ${count}"
}

# @description Print the deepest existing path at or above the physical path `$1` (`$1` itself when it exists).
# @arg $1 string A physical path.
deepest_existing() {
    local p=$1
    # Absolute, so each step shortens it and the walk ends at `/`, which exists.
    [[ ${p} == /* ]] || return 1 # lint-comparisons: allow an absolute-path test
    while [[ ! -e ${p} && ! -L ${p} ]]; do
        p=${p%/*}
        [[ -n ${p} ]] || p=/
    done
    printf '%s\n' "${p}"
}

# @description Decide whether `$2` is `$1` or lies under it (regime-cutover U85), by (device, inode) identity for
#   everything that exists, so a case alias on a case-insensitive volume is the path it aliases. When `$1` exists:
#   yes iff `$2`'s deepest existing ancestor (`$2` itself when it exists) or a directory above it has `$1`'s identity.
#   When `$1` does not exist, an existing `$2` cannot lie under it (no). When neither exists, everything from `$1`
#   down is absent, so `$2` can lie under `$1` only if both have the same deepest existing ancestor (identity); below
#   it nothing exists, so no link or alias can intervene, and the clean remaining components decide: yes iff `$1`'s
#   remainder is `$2`'s or a prefix of it on a component boundary (`a/b` is no prefix of `a/bc`). The remainders are
#   compared ASCII case-folded (clean paths are ASCII), since on a case-insensitive volume two spellings that differ
#   by case become one directory once made; on a case-sensitive one that refuses names differing only by case.
# @arg $1 string A physical, clean path.
# @arg $2 string A physical, clean path.
# @exitcode 0 `$2` is `$1` or lies under it.
# @exitcode 1 It does not.
within() {
    # Every helper's status is checked where it is called: within runs inside `||` lists, where `set -e` does not apply.
    local outer_id p ids probe=() a1 a2 rest
    if [[ ! -e $1 ]]; then
        [[ ! -e $2 ]] || return 1
        a1=$(deepest_existing "$1") || refuse "cannot find an existing directory above $1"
        a2=$(deepest_existing "$2") || refuse "cannot find an existing directory above $2"
        ids=$(/usr/bin/stat "${stat_args[@]}" -- "${a1}" "${a2}") || refuse "cannot read the identity of ${a1} or ${a2}"
        [[ ${ids%%$'\n'*} == "${ids#*$'\n'}" ]] || return 1 # lint-comparisons: allow compares (device, inode) identities, not paths
        # The absent remainders below the one ancestor, each starting with `/`, folded to lower case on one line each.
        rest=$(printf '%s/\n%s/\n' "${1#"${a1%/}"}" "${2#"${a2%/}"}" | LC_ALL=C /usr/bin/tr '[:upper:]' '[:lower:]') ||
            refuse "cannot compare the absent parts of $1 and $2"
        [[ ${rest#*$'\n'} == "${rest%%$'\n'*}"* ]] # lint-comparisons: allow absent components below one ancestor of the same identity, compared on component boundaries
        return
    fi
    outer_id=$(/usr/bin/stat "${stat_args[@]}" -- "$1") || refuse "cannot read the identity of $1"
    p=$(deepest_existing "$2") || refuse "cannot find an existing directory above $2"
    ancestors_of "${p}"
    probe=("${ancestors[@]}")
    ids=$(/usr/bin/stat "${stat_args[@]}" -- "${probe[@]}") || refuse "cannot read the identity of $2 or a directory above it"
    [[ $'\n'${ids}$'\n' == *$'\n'"${outer_id}"$'\n'* ]] # lint-comparisons: allow compares (device, inode) identities, not paths
}

# @description Set `worktree_paths` to the worktrees git records for this repository, main worktree first, and
#   `main_bare` to 1 when that record is a bare repository (regime-cutover U85). `git worktree list --porcelain -z`
#   is read whole: NUL-terminated fields, each turned into one line (a newline inside a field becomes \001, a control
#   character, refused in a path); every path must be absolute and free of control characters.
# @set worktree_paths The worktree paths, as git prints them.
# @set main_bare 1 for a bare main record, else 0.
worktree_records() {
    local listing line record=0
    listing=$({ git -C "${repo}" worktree list --porcelain -z | /usr/bin/tr '\0\n' '\n\001'; } && printf .) ||
        refuse "git cannot list the worktrees of ${repo}"

    worktree_paths=()
    main_bare=0
    while IFS= read -r line; do
        case ${line} in
        '') record=$((record + 1)) ;;
        'worktree '*)
            line=${line#worktree }
            [[ ${line} == /* && ${line} != *[[:cntrl:]]* ]] || # lint-comparisons: allow an absolute-path and content test
                refuse "git names the worktree '${line}', not an absolute path free of control characters"
            worktree_paths+=("${line}")
            ;;
        bare) if ((record == 0)); then main_bare=1; fi ;;
        esac
    done <<< "${listing}"

}

# @description Print the srt write roots of one seat, one per line in physical form: the list the seat's settings
#   carry as `allowWrite` (seat_sandbox_write writes exactly this list), followed by the paths srt 0.0.81 makes
#   writable without a listing (`srt_tmp_roots`: `/tmp/claude`, and `/private/tmp/claude` on macOS; `~/.npm/_logs`,

# @arg $1 string The role.

# @description Refuse (exit 2) unless a seat's own slots under the seats root are what the overlap check's exemption
#   takes them for (regime-cutover U85): `<seats-root>/.state`, `<seats-root>/.state/<name>` and, for a worker,
#   `<seats-root>/<name>` are each no symbolic link, a directory when they exist, and, when they exist, their physical
#   parent has the identity of the physical seats root (resp. `.state`) and their physical basename is the name they
#   are spelled with. A `.state/<name> -> ..` or `<name> -> /` would otherwise resolve the slot to a wider root that
#   the exemption skips. It runs before anything resolves those paths (lstat first, then physical_path), so a slot
#   that is a link is refused before any link is followed. Missing slots are created later, one component at a time
#   (seat_sandbox_write).
# @arg $1 string The role.
# @arg $2 string The seat name.
own_slots_check() {
    local slot parent real seats_phys slots=("${seats_root}/.state" "${seats_root}/.state/$2")
    [[ $1 == orchestrator ]] || slots+=("${seats_root}/$2")
    seats_phys=$(physical_path "${seats_root}") || refuse "cannot resolve the seats root ${seats_root}"
    for slot in "${slots[@]}"; do
        [[ ! -L ${slot} ]] || refuse "the seat slot ${slot} is a symbolic link; a seat's own slots must be real directories"
        [[ -e ${slot} ]] || continue
        [[ -d ${slot} ]] || refuse "the seat slot ${slot} is not a directory"
        real=$(physical_path "${slot}") || refuse "cannot resolve the seat slot ${slot}"
        parent=${slot%/*}
        [[ ${real%/*} -ef ${parent} && ${parent} -ef ${seats_phys}${parent#"${seats_root}"} ]] ||
            refuse "the seat slot ${slot} does not sit in ${parent}"
        [[ ${real##*/} == "${slot##*/}" ]] || refuse "the seat slot ${slot} resolves to ${real}" # lint-comparisons: allow a basename test, the parent by identity
    done
}

# @description Refuse (exit 2) unless the final `allowWrite` list of one seat keeps clear of every protected path
#   (regime-cutover U85), one invariant instead of a list of cases: for every granted root R and every protected
#   path P, R must not be or contain P, and R must not lie inside P. The protected paths are defined once: the main
#   checkout, the seats root, its `.sandbox`, every other seat directory under the seats root and every other
#   worktree of this repository; the seat's own directory (same identity) is not protected for it. Exempt by
#   construction, not by comparing text: the seat's own slots under the seats root (the first two roots: a worker's
#   `<seats-root>/<name>`, and `<seats-root>/.state/<name>`) against the seats root and its `.sandbox`, and the git
#   common directory named `.git` whose parent is the main checkout (identity). Containment is decided by identity
#   for everything that exists, and below one shared deepest existing ancestor by the absent components (within). Every
#   path must be clean (clean_path) before anything is created, so this runs in a dry run too.
# @arg $1 string The role.
# @arg $2 string The seat directory, physical.
# @arg $@ string The seat's allowWrite roots after them, physical, its own slots first (seat_write_roots).
seat_overlap_check() {
    local own_role=$1 own_dir=$2 r p i k status line target seats_phys labels=() protected=()
    shift 2
    seats_phys=$(physical_path "${seats_root}") || refuse "cannot resolve the seats root ${seats_root}"
    labels+=("the main checkout" "the seats root" "the seats' sandbox directory")
    protected+=("${checkout}" "${seats_phys}" "${seats_phys}/.sandbox")
    for p in "${seats_phys}"/*/; do
        [[ -d ${p} ]] || continue
        target=$(physical_path "${p%/}") || refuse "cannot resolve the seat directory ${p%/}"
        labels+=("the seat directory")
        protected+=("${target}")
    done
    # Every linked worktree, as git names it (relative `gitdir` files included); the first record is the main
    # worktree, protected above as the main checkout.
    worktree_records
    for line in "${worktree_paths[@]:1}"; do
        target=$(physical_path "${line}") || refuse "cannot resolve the worktree ${line}"
        labels+=("the worktree")
        protected+=("${target}")
    done
    for p in "${protected[@]}"; do
        require_clean_path 'a protected seat path' "${p}"
    done
    k=0
    for r in "$@"; do
        k=$((k + 1))
        require_clean_path "a write root of the ${own_role} seat" "${r}"
        for ((i = 0; i < ${#protected[@]}; i++)); do
            p=${protected[i]}
            # The seat's own directory is its to write.
            if [[ -e ${p} && ${p} -ef ${own_dir} ]]; then continue; fi
            # Its own slots under the seats root sit there by construction, as siblings of `.sandbox`: the state
            # directory of every seat, and a worker's directory (the orchestrator's is the launch checkout, checked).
            # own_slots_check has proved, before this runs, that they are what they claim (no link, right parent).
            if [[ (${k} == 2 || (${k} == 1 && ${own_role} != orchestrator)) && (${i} == 1 || ${i} == 2) ]]; then continue; fi
            status=0
            within "${r}" "${p}" || status=$?
            ((status != 0)) ||
                refuse "the ${own_role} seat's write root ${r} contains ${labels[i]} ${p}; seat write roots must not overlap (choose another --seats-root, HCOM_DIR or git directory)"
            status=0
            within "${p}" "${r}" || status=$?
            if ((status == 0)); then
                # The main checkout's own `.git`, by identity of the common directory and its parent.
                if ((i == 0)) && [[ -e ${r} && ${r} -ef ${common} && -d ${checkout}/.git && ! -L ${checkout}/.git && ${checkout}/.git -ef ${r} ]]; then continue; fi
                refuse "the ${own_role} seat's write root ${r} lies inside ${labels[i]} ${p}; seat write roots must not overlap (choose another --seats-root, HCOM_DIR or git directory)"
            fi
        done
    done
}

# @description Write the seat's srt settings and its `omp` shim under `<seats-root>/.sandbox/<name>` (regime-cutover
#   U85), afresh on every launch, after the seat directory exists. The settings name what the seat may write (its
#   directory, the repository's git common directory, the program's hcom store, its own omp profile and the omp
#   session leases, the Claude Code state the bridge child writes, a per-seat cache root; the same for both roles, so
#   no seat writes the seats root or reaches the herdr socket, and none can start a seat), what it may not change
#   inside those roots (git config and hooks, the hcom store's launch scripts and configuration, agent configuration
#   that runs outside the seat), what it may not read (SSH, GPG, cloud and codex credentials, the chezmoi sources,
#   `~/Workspace` but its own repository, other omp profiles, other hcom stores, every seat's sandbox directory, and
#   for a worker the other seats) and the hosts it may reach. The shim runs a canary under those settings first, a
#   write into the sandbox directory and reads of the settings file and `~/.ssh`, and refuses (exit 2) unless all
#   three fail inside; only then does it run omp under srt, both by the physical argv `pin_exec` checked.
# @noargs
seat_sandbox_write() {
    local h claude dir_real common_real hcom_real seats_real sandbox_real
    local root path settings shim json base sandbox_state origin_url push_url srt_q omp_q
    local write_json deny_write_json deny_read_json allow_read_json
    local write=() deny_write=() deny_read=() allow_read=()
    # srt on Linux grants writes only to paths that exist, so omp's own state directories are made first. The seat's
    # slots under the seats root were proved free of links (own_slots_check); they are made one component at a time,
    # and each is checked again to be a real directory.
    (umask 077 && mkdir -p "${seats_root}" "${HOME}/.omp/profiles/${role}" "${HOME}/.omp/run") ||
        refuse "cannot create the seats root ${seats_root} or omp's state directories"
    for path in "${seats_root}/.state" "${seats_root}/.state/${name}" "${seats_root}/.sandbox" "${sandbox}" \
        "${sandbox}/bin"; do
        if [[ ! -e ${path} && ! -L ${path} ]]; then
            (umask 077 && /bin/mkdir "${path}") || refuse "cannot create ${path}"
        fi
        [[ -d ${path} && ! -L ${path} ]] || refuse "${path} is not a real directory"
    done
    h=$(physical_path "${HOME}") || refuse "cannot resolve HOME ${HOME}"
    claude=${CLAUDE_CONFIG_DIR:-${h}/.claude}
    dir_real=$(cd "${dir}" && pwd -P) || refuse "cannot resolve the seat directory ${dir}"
    common_real=$(cd "${common}" && pwd -P) || refuse "cannot resolve the git common directory ${common}"
    hcom_real=$(cd "${HCOM_DIR}" && pwd -P) || refuse "cannot resolve the hcom store ${HCOM_DIR}"
    seats_real=$(cd "${seats_root}" && pwd -P) || refuse "cannot resolve the seats root ${seats_root}"
    sandbox_real=$(cd "${sandbox}" && pwd -P) || refuse "cannot resolve the seat sandbox directory ${sandbox}"
    sandbox_state=${seats_real}/.state/${name}
    # Exactly the list the protected set was built from (seat_write_roots), so the check and the sandbox cannot drift.
    write=("${seat_write[@]}")
    deny_write=("${seats_real}/.sandbox")
    for base in "${dir_real}" "${checkout}"; do
        deny_write+=("${base}/.claude/settings.json" "${base}/.claude/settings.local.json" "${base}/.claude/hooks"
            "${base}/.omp" "${base}/.codex" "${base}/.envrc" "${base}/.mcp.json")
    done
    # The git state host git reads for any worktree of this repository (regime-cutover U85): a seat that could write
    # it could make a later host git command run a program of its choosing (`core.fsmonitor`, `core.hooksPath`,
    # filter and textconv drivers, includes). git_state_check refuses a launch over such state and creates the files
    # that are absent, so each deny below names an existing path (srt on Linux binds only existing paths).
    git_state_check "${common_real}" "${dir_real}"
    deny_write+=("${git_state[@]}")
    # A worktree created after this launch gets its files denied on macOS by pattern; on Linux srt takes literal
    # write denies only, and the next launch's git_state_check covers it.
    # The patterns are the one place a settings entry is not a clean path: a clean prefix and a fixed suffix.
    deny_write_patterns=''
    if [[ ${os} == Darwin ]]; then
        require_clean_path 'the git common directory' "${common_real}"
        for path in config.worktree info commondir gitdir; do
            deny_write_patterns+=",\"${common_real}/worktrees/*/${path}\""
        done
    fi
    for path in config.toml env config.env .tmp/launch scripts integrations shell_env.json; do
        deny_write+=("${hcom_real}/${path}")
    done
    for path in settings.json settings.local.json hooks plugins commands agents skills CLAUDE.md; do
        deny_write+=("${claude}/${path}")
    done
    deny_read=("${h}/.ssh" "${h}/.gnupg" "${h}/.aws" "${h}/.netrc" "${h}/.docker" "${h}/.kube" "${h}/.config/gcloud"
        "${h}/.codex" "${h}/.omp/agent" "${h}/.omp/profiles" "${h}/.hcom" "${h}/.local/state/hcom"
        "${h}/.local/share/chezmoi" "${h}/.local/share/chezmoi-private" "${h}/.config/chezmoi"
        "${h}/.config/chezmoi-private" "${h}/Workspace" "${seats_real}/.sandbox")
    # Every program's seats root is unreadable but this seat's own paths: the whole ~/.local/state/omp-seats tree
    # and every configured seats root. srt keeps a deeper deny under an allow (measured, 0.0.81), so each
    # `.sandbox` stays unreadable inside an allowed root.
    deny_read+=("${h}/.local/state/omp-seats" "${seats_real}")
    if [[ -n ${REGIME_SEATS_ROOT:-} ]]; then
        root=$(physical_path "${REGIME_SEATS_ROOT}") || refuse "cannot resolve the seats root ${REGIME_SEATS_ROOT}"
        deny_read+=("${root}")
    fi
    allow_read=("${dir_real}" "${common_real}" "${hcom_real}" "${h}/.omp/profiles/${role}" "${sandbox_state}")
    # The main checkout is unreadable to a worker wherever it lives, but for its git directory (the worktree's objects
    # and refs) and the coordinator's records (briefs, verdict files), read by absolute path.
    if [[ ${role} != orchestrator ]]; then deny_read+=("${checkout}"); fi
    allow_read+=("${checkout}/.orchestration/orchestrate")
    # The orchestrator reads the worker clones of its own program, which it reviews; a worker reads no other seat.
    if [[ ${role} == orchestrator ]]; then allow_read+=("${seats_real}"); fi
    settings=${sandbox_real}/srt-settings.json
    write_json=$(json_paths 'a seat write root' "${write[@]}") || exit 2
    deny_write_json=$(json_paths 'a seat write deny' "${deny_write[@]}") || exit 2
    deny_write_json=${deny_write_json%]}${deny_write_patterns}]
    deny_read_json=$(json_paths 'a seat read deny' "${deny_read[@]}") || exit 2
    allow_read_json=$(json_paths 'a seat read root' "${allow_read[@]}") || exit 2
    # No unix socket for any seat: the herdr socket would let a seat open a pane outside every sandbox. No local
    # binding either: srt 0.0.81 grants it as bind and inbound on `*:*` (every interface); the one listener a seat
    # runs, the hcom plugin's notify server, falls back to polling every 5 s when its bind fails (hcom.ts
    # `startNotifyServer`, `FALLBACK_PENDING_POLL_MS`). The settings are written by the shell from clean paths only
    # (json_paths), so no JSON tool runs and none is needed on macOS.
    domains='"github.com","api.github.com","uploads.github.com","codeload.github.com","objects.githubusercontent.com"'
    domains+=',"raw.githubusercontent.com","release-assets.githubusercontent.com","pypi.org","files.pythonhosted.org"'
    domains+=',"api.anthropic.com","claude.ai","platform.claude.com","console.anthropic.com"'
    domains+=',"chatgpt.com","auth.openai.com","api.openai.com"'
    json="{\"network\":{\"allowedDomains\":[${domains}],\"deniedDomains\":[],\"allowUnixSockets\":[]"
    json+=",\"allowMachLookup\":[\"com.apple.trustd.agent\"],\"allowLocalBinding\":false}"
    json+=",\"filesystem\":{\"denyRead\":${deny_read_json},\"allowRead\":${allow_read_json}"
    json+=",\"allowWrite\":${write_json},\"denyWrite\":${deny_write_json}},\"allowPty\":true${linux_tools}}"
    if ! printf '%s\n' "${json}" > "${settings}.tmp" || ! mv -f "${settings}.tmp" "${settings}"; then
        refuse "cannot write ${settings}"
    fi
    # ~/.ssh is unreadable inside, so the seat pushes over HTTPS through the gh credential helper: an explicit
    # pushurl wins over a global `url.<ssh>.pushInsteadOf` rewrite. An origin that is neither HTTPS nor
    # git@github.com gets no override, and an SSH push from the seat fails.
    origin_url=$(git -C "${repo}" config --get remote.origin.url) || {
        (($? == 1)) || refuse "cannot read remote.origin.url in ${repo}"
        origin_url=''
    }
    case ${origin_url} in # lint-comparisons: allow a URL scheme prefix is the classification, no path compare
    https://*) push_url=${origin_url} ;;
    git@github.com:*) push_url=https://github.com/${origin_url#git@github.com:} ;;
    *) push_url='' ;;
    esac
    shim=${sandbox_real}/bin/omp
    {
        echo '#!/bin/bash'
        echo "# Generated by hcom-seat for the ${role} seat ${name} (regime-cutover U85); rewritten on every launch."
        echo '# A canary proves the sandbox holds before omp starts; there is no uncontained fallback.'
        echo 'set -u'
        printf -v srt_q '%q ' "${srt_cmd[@]}"
        printf -v omp_q '%q ' "${omp_cmd[@]}"
        echo "srt_cmd=(${srt_q}) omp_cmd=(${omp_q})"
        printf 'settings=%q canary=%q state=%q push_url=%q sandbox=%q\n' "${settings}" "${sandbox_real}/canary" \
            "${sandbox_state}" "${push_url}" "${sandbox_real}"
        # Outside the sandbox the shim and srt look up only in the private tool directory and the system directories;
        # inside it omp gets the seat's working PATH, applied by /usr/bin/env under srt.
        printf 'outer_path=%q seat_path=%q\n' "${sandbox_real}/bin:${PATH}" "${seat_path}"
        cat << 'SHIM'
export PATH=${outer_path}
/bin/rm -f "${canary}" || { echo "hcom-seat shim: cannot clear ${canary}" >&2; exit 2; }
# `true`, not `:`: a failed redirection on a special builtin ends a POSIX shell (dash, Ubuntu's /bin/sh).
probe=$("${srt_cmd[@]}" --settings "${settings}" -- /bin/sh -c 'if true 2> /dev/null > "$1"; then w=write-open; else w=write-denied; fi
if cat "$2" > /dev/null 2>&1; then r=read-open; else r=read-denied; fi
if ls "$3" > /dev/null 2>&1; then s=ssh-open; else s=ssh-denied; fi
echo "$w $r $s"' canary "${canary}" "${settings}" "${HOME}/.ssh") || {
    echo "hcom-seat shim: the sandbox canary did not run under ${srt_cmd[*]}; omp not started" >&2
    exit 2
}
if [[ ${probe} != 'write-denied read-denied ssh-denied' || -e ${canary} ]]; then
    echo "hcom-seat shim: the sandbox does not hold (canary: ${probe}); omp not started" >&2
    exit 2
fi
export UV_CACHE_DIR=${state}/uv-cache
# omp's Bedrock discovery stats ~/.aws/{credentials,config} unless these name the files, and an EPERM from the read
# deny ends omp at start (measured, omp 18.11.3 and 18.12.6); /dev/null reads as no AWS profile.
export AWS_SHARED_CREDENTIALS_FILE=/dev/null AWS_CONFIG_FILE=/dev/null
unset SSH_AUTH_SOCK
# Seat commits and tags are unsigned (standing order 29): the signing key under ~/.ssh is unreadable inside, so a
# host config with commit.gpgsign or tag.gpgsign true would fail every commit. GIT_CONFIG_* outranks every file.
export GIT_CONFIG_COUNT=2 GIT_CONFIG_KEY_0=commit.gpgsign GIT_CONFIG_VALUE_0=false \
    GIT_CONFIG_KEY_1=tag.gpgsign GIT_CONFIG_VALUE_1=false
if [[ -n ${push_url} ]]; then
    export GIT_CONFIG_COUNT=3 GIT_CONFIG_KEY_2=remote.origin.pushurl GIT_CONFIG_VALUE_2=${push_url}
fi
# hcom-seat refuses to launch a seat where this is set.
export HCOM_SEAT_SANDBOX=${sandbox}
exec "${srt_cmd[@]}" --settings "${settings}" -- /usr/bin/env PATH="${seat_path}" "${omp_cmd[@]}" --no-extensions "$@"
SHIM
    } > "${shim}.tmp" || refuse "cannot write ${shim}.tmp"
    if ! chmod 700 "${shim}.tmp" || ! mv -f "${shim}.tmp" "${shim}"; then
        refuse "cannot install ${shim}"
    fi
    # hcom resolves `hcom` (for the runner script) and `herdr` (the terminal preset) from PATH; both find these
    # wrappers first, each of which runs exactly the physical argv pin_exec checked.
    seat_wrapper_write hcom "${hcom_cmd[@]}"
    seat_wrapper_write herdr "${herdr_cmd[@]}"
}

# @description Write `<sandbox>/bin/$1`, a wrapper that execs the given physical argv with its own arguments.
# @arg $1 string The command name.
# @arg $@ string The physical argv after the name.
seat_wrapper_write() {
    local tool=$1 argv_q
    shift

# @description Make sure the hcom store `HCOM_DIR` is a real directory before anything else is created (regime-cutover
#   U85): it is already clean (require_clean_path) and clear of every protected root by the identity of its deepest
#   existing ancestor (seat_overlap_check, a write root of every seat). An existing store must be a directory and no
#   symbolic link. A missing one is made 0700 one component at a time below its deepest existing ancestor, which must
#   be a real directory, not a symbolic link; each made component is checked again. A dry run creates nothing and
#   says what it would make.
# @arg $1 int 1 for a dry run.
hcom_store_ensure() {
    local top=${HCOM_DIR} rest=() path part
    if [[ -e ${HCOM_DIR} || -L ${HCOM_DIR} ]]; then
        [[ -d ${HCOM_DIR} && ! -L ${HCOM_DIR} ]] || refuse "the hcom store ${HCOM_DIR} is not a real directory"
        return 0
    fi
    while [[ ! -e ${top} && ! -L ${top} ]]; do
        # bash 3.2 reads an empty array as unset under `set -u`, so the expansion is guarded.
        rest=("${top##*/}" ${rest[@]+"${rest[@]}"})
        top=${top%/*}
        [[ -n ${top} ]] || top=/
    done
    [[ -d ${top} && ! -L ${top} ]] ||
        refuse "the hcom store ${HCOM_DIR} would be made under ${top}, which is not a real directory (a symbolic link or a file)"
    if (($1)); then
        echo "hcom-seat: the hcom store ${HCOM_DIR} does not exist; a launch creates it (0700)" >&2
        return 0
    fi
    path=${top%/}
    for part in "${rest[@]}"; do
        path=${path}/${part}
        (umask 077 && /bin/mkdir "${path}") || refuse "cannot create the hcom store ${path}"
        [[ -d ${path} && ! -L ${path} ]] || refuse "${path} is not a real directory"
    done
}
