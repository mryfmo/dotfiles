    home/dot_local/bin/common/executable_hcom-seat¶

    Plan 025 W5b (U7), the minimal form before X. A seat is one omp process that hcom omp starts in a herdr pane (hcom omp --help: hcom [N] omp [args...], --tag <name>, --dir <path>, --terminal <preset>; hcom gives the seat HCOM_LAUNCHED=1, HCOM_TAG and HCOM_DIR). For <role> the launch line is hcom omp --tag <name> --dir <dir> --terminal herdr --go -- --profile <role> --config ~/.agents/omp/policies/<role>.yml --config ~/.agents/omp/profiles/<role>.yml --append-system-prompt ~/.agents/omp/rules/<role>.md -e <ext>...; hcom drops the -- and forwards what follows to omp verbatim (hcom 0.7.30 and 0.7.31, measured 2026-10-23 and 2026-10-24; extract_launch_flags, src/commands/launch.rs:572-581 at v0.7.30). --go is hcom's launch gate: inside an AI tool, hcom without it prints == LAUNCH PREVIEW == / Add --go to proceed. and starts nothing (launch.rs:48,388-389, measured on the real host 2026-10-23), and extract_launch_flags consumes it only before the -- (launch.rs:650-652). The profile equals the role. A named profile reads its own ~/.omp/profiles/<role>/agent/config.yml (pi-utils src/dirs.ts:312-315, U10), so the manifest's modelRoles.default and skills.customDirectories reach the seat only through the second overlay, rendered per role (U14); the first overlay owns the approval mode (U6). Both are required. The seat's standing rules, rendered per role from the manifest's standing_rules (U75), ride --append-system-prompt: the overlays disable the native provider (U66), so no profile context file loads, and the explicit flag also wins over any project APPEND_SYSTEM.md. The rules file is required and must be non-empty, since omp reads a missing path as literal text. The extensions default to the pi-claude-bridge, which the role's model route needs, plus the openai-siwc when it is present; --ext replaces that list. The roles are orchestrator and worker; every audit is one fresh ~/.local/bin/common/pr-audit.sh <n> --records <store> run, never a seat (regime-cutover U57, U58; the omp audit route was retired by U119 round 3). The stop gate's directory ~/.agents/omp/hooks is loaded on every launch, whatever --ext says, and the launch line ends with --hcom-team <HCOM_TEAM>: hcom passes HCOM_DIR into the pane but not HCOM_TEAM, so the flag, which the gate registers, carries exactly the team this launch was given, an explicit one included (regime-cutover U33c; omp refuses the flag when no loaded extension registers it, so a launch without the gate fails instead of running unguarded). Every directory, a default, --ext or the gate's, must resolve to an entry of claude.levers.extensions in the manifest the self-check reads (regime-cutover U31), else the launch is refused. The orchestrator sits in the repository this command runs in; every other role gets the worktree <seats-root>/<name>, which is created detached from origin/main (HEAD in a repository without it) when absent and reused when it is a worktree of this repository (any other directory at that path is refused). HCOM_DIR, HCOM_TEAM and the seats root come from the environment or --seats-root when set, else from the checkout through the sourced regime-env helper (regime-cutover U33: ~/.local/state/hcom/<slug>, <slug>, ~/.local/state/omp-seats/<slug>), and are exported to the seat. The program store's root REGIME_STORE_ROOT (<physical HOME>/.local/state/regime-store/<slug>, regime-env's fixed derivation, U215c; regime-cutover U219, store move 3 of 5, handoff/07-store-move-design.md) is held once (store_root_hold: clean, each component a 0700 directory of this user or absent, resolved physically once into store_root_phys) and, since U219c (verdict U219-985b7c04), four things hold of it: it is made by every role's launch that finds it absent, before its settings file is written (store_root_make, after the judgement, as the credential root is made, because srt's Linux backend skips an absent path); it is printed verbatim into the orchestrator's write roots (row 7, seat_write_roots, never resolved again) and granted for read to both omp roles; it is denied for write to every other row (the worker's, the dsh's and the router's denyWrite, tagged store); and every rendered write grant of every role is judged against it (store_root_judge: a row that is, contains or lies inside the root refuses the launch by name, the orchestrator's own row excepted by position and byte equality). An hcom store HCOM_DIR that is, lies inside or contains it refuses the launch by name before anything is made (store_root_overlap_check, by identity: the hcom store is every seat's write grant, so the records would lie inside it; verdict U215-15c6be1e P1); the dsh and router rows carry no grant of it. The seat's omp runs under OS containment (regime-cutover U85): Anthropic's sandbox-runtime srt (sandbox-exec on macOS, bubblewrap on Linux) with per-seat settings, through an omp shim at <seats-root>/.sandbox/<name>/bin/omp that is put first on PATH, so hcom pins it as the pane's tool; the shim runs a canary under the settings and refuses to start omp unless a write into the sandbox directory and reads of the settings and ~/.ssh fail inside (seat_sandbox_write below). srt and omp run by their physical argv (pin_exec), and so do hcom (exec'd by it) and herdr (through wrappers in the shim directory); none of their files may be or lie under a write root of any seat. Every input path (HOME, --seats-root, HCOM_DIR, REGIME_SEATS_ROOT, CLAUDE_CONFIG_DIR) and every path written into the srt settings must be clean: absolute, components of [A-Za-z0-9._@+-] only, no '.' or '..' component and no trailing '/', since srt reads a settings path as a pattern. The settings are written by the shell (no JSON tool) and read back by /usr/bin/plutil on macOS, /usr/bin/jq on Linux. No caller PATH entry runs anything: the first statement sets PATH to the system directories, the complete protected set is built by (device, inode) identity before mise or any other tool runs, and the tools beyond them (git, hcom, herdr, omp, srt, node, bun, claude, jq; bwrap, socat and rg on Linux) are resolved through mise which under env -i from /, else command -v on the caller's PATH, checked (absolute, no control character, an executable regular file, no shim, neither it nor a directory above it with the identity of a seat write root) and linked into ~/.local/state/hcom-seat/tools; PATH is then that directory and the system directories, for hcom-seat, hcom, the shim and srt (whose Linux settings name bwrap, socat and rg). Inside the sandbox omp gets that PATH followed by the caller's absolute entries. Every executable is checked with its interpreter chain, and hcom-seat, the shim and the wrappers run under #!/bin/bash. The git state host git reads for this repository's worktrees (config, config.worktree, info, hooks, commondir, gitdir, the worktree's .git file) is denied to every seat, and a launch over such state holding a key host git would act on is refused (git_state_check) before the first git command; every git command hcom-seat runs has hooks, fsmonitor and worktree config off. Every program's seats root is read-denied but the seat's own paths. No seat launches a seat: the orchestrator's sandbox, like the worker's, has no herdr socket and no write to the seats root, and a launch from inside a seat is refused; seats are started from a terminal outside every seat (the operator or the coordinator, as gate G7 was). Every input is checked before anything is created or started: an unknown role, a launch inside a seat, a name or team outside ^[a-z0-9][a-z0-9_-]{0,63}$, a store regime-env refuses, an absent policy or profile overlay or extension directory, a cwd outside a git checkout, a required tool that is missing, a shim or a file that is or lies under a seat write root, or no sandbox-exec (macOS) or bubblewrap, socat and ripgrep (Linux) is exit 2 with the reason. A seat directory that holds .omp is refused too, after the worktree exists and before hcom starts (U66: omp applies the cwd's .omp/config.yml at start, which no setting turns off). --dry-run prints the launch line, and the derived environment and sandbox on stderr, and creates and starts nothing but the private tool links. Otherwise hcom's own exit status is returned (hcom omp --help: 0 ready, 1 launch failed, 2 still launching or blocked on user attention). The seat login (regime-cutover U318, U314 alternative A): every seat's bridge child and the dsh role's gateway child run with CLAUDE_CONFIG_DIR=<seats-root>/.state/claude, one directory per seats root holding one interactive claude.ai login that Claude Code itself stores and refreshes (the Keychain item keyed to that directory on macOS, .credentials.json 0600 there otherwise). The directory is the role table's claude_config row for every role: this lever makes it 0700 when absent (a link refuses, own_slots_check), the shim exports it, seat-login-preflight judges claude auth status under it, and the settings grant it for write and deny its settings.json, settings.local.json, rules, hooks, plugins, skills, commands and agents to every seat, so no seat changes what another seat's child, or the operator's login command, would load from it. No token file and no CLAUDE_CODE_OAUTH_TOKEN: the shim clears the name, and no seat reads the operator's ~/.claude. The dsh role (regime-cutover U272, after the four audits of the standalone launcher of PR 687): the DeepSeek harness control host is contained the same way, by this lever, as a role whose differences from the worker are rows of the role table (the case ${role} after the options, seat_write_roots, the read grants in seat_sandbox_write, the command the shim execs, the launch at the end) and nothing else. # @description Refuse to run unless this file's sha256 equals its pin in the manifest beside it (regime-cutover U31):
#   `~/.agents/agent-config.yaml` for the installed copy under ~/.local/bin/common, which a sandboxed session cannot
#   write, else the checkout's home/dot_agents/agent-config.yaml. Every read is checked; a failure exits 2 naming the
#   file. The pin is the `claude.levers.sha256.<name>` line, which `scripts/generate-agent-configs.py` refreshes.
# @set LEVER_MANIFEST The manifest the pin came from.
# @set LEVER_DIR The physical directory of this file, where the sourced regime-env helper sits (U33).
lever_self_check() {
    local src dir self name pin digest home
    # The directory is split from the path in the shell, so no external producer (dirname) can fail unseen.
    src=${BASH_SOURCE[0]}
    case ${src} in
    */*) dir=${src%/*} ;;
    *) dir=. ;;
    esac
    [[ -n ${dir} ]] || dir=/
    dir=$(cd "${dir}" && pwd -P) || {
        echo "${src##*/}: refused: cannot resolve the script directory of ${src}" >&2
        exit 2
    }
    self=${dir}/${BASH_SOURCE[0]##*/}
    # shellcheck disable=SC2034 # read by the levers that source regime-env from this directory
    LEVER_DIR=${dir}
    name=${self##*/}
    home=$(cd "${HOME}" 2> /dev/null && pwd -P) || home=''
    if [[ -n ${home} && ${dir} == "${home}/.local/bin/common" ]]; then # lint-comparisons: allow both sides are pwd -P forms
        LEVER_MANIFEST=${HOME}/.agents/agent-config.yaml
    else
        LEVER_MANIFEST=${dir}/../../home/dot_agents/agent-config.yaml
    fi
    [[ -r ${LEVER_MANIFEST} ]] || {
        echo "${name}: refused: manifest unreadable: ${LEVER_MANIFEST}" >&2
        exit 2
    }
    pin=$(sed -n -E "s/^      ${name//./\\.}: ([0-9a-f]{64})\$/\\1/p" "${LEVER_MANIFEST}") || {
        echo "${name}: refused: cannot read ${LEVER_MANIFEST}" >&2
        exit 2
    }
    [[ ${pin} =~ ^[0-9a-f]{64}$ ]] || {
        echo "${name}: refused: no single sha256 pin for ${name} in ${LEVER_MANIFEST}" >&2
        exit 2
    }
    if command -v sha256sum > /dev/null; then
        digest=$(sha256sum < "${self}") || digest=''
    else
        digest=$(shasum -a 256 < "${self}") || digest=''
    fi
    digest=${digest%% *}
    [[ ${digest} =~ ^[0-9a-f]{64}$ ]] || {
        echo "${name}: refused: cannot hash ${self}" >&2
        exit 2
    }
    [[ ${digest} == "${pin}" ]] || {
        echo "${name}: refused: sha256 ${digest} of ${self} differs from the pin in ${LEVER_MANIFEST}" >&2
        exit 2
    }
}

helper_pin_check() {

# @description Succeed when `$1` is a clean absolute path that srt cannot read as a pattern: `/` followed by
#   components of `[A-Za-z0-9._@+-]` only (no glob metacharacter `*?[]{}`, no whitespace, no quote or backslash), none
#   of them empty, `.` or `..`, and no trailing `/`. srt 0.0.81 turns a settings path into a Seatbelt regex or a glob,
#   so `/private/tmp/hcom*` would grant its siblings; a clean path names exactly itself.
# @arg $1 string The path.
# @exitcode 1 The path is not clean.
clean_path() {
    [[ $1 =~ ^(/[A-Za-z0-9._@+-]+)+$ ]] || return 1
    [[ /$1/ != */./* && /$1/ != */../* ]] # lint-comparisons: allow a component test on one path, no path compare
}

# @description Print the `filesystem.allowWrite` entries of the seat settings file `$2`, one per line: by
#   `/usr/bin/plutil` on macOS (`-extract … raw -expect array` prints the count, `-expect string` each entry; macOS
#   12 and later, plutil(1)), by `/usr/bin/jq` on Linux (from install/ubuntu/common/dependencies.sh). Each entry must
#   be a clean path.
# @arg $1 string The system name (`uname -s`).
# @arg $2 string The settings file.
# @exitcode 1 The file cannot be read, has no such array, or holds an entry that is not a clean path.
allow_write_list() {
    local n i entry line
    case $1 in
    Darwin)
        n=$(/usr/bin/plutil -extract filesystem.allowWrite raw -expect array -o - "$2") || return 1
        [[ ${n} =~ ^[0-9]+$ ]] || return 1
        for ((i = 0; i < n; i++)); do
            # -n prints no newline of plutil's own, and the 'x' keeps an entry's trailing newlines from the command
            # substitution, so "/tmp/root\n" reaches clean_path whole and is refused.
            entry=$(/usr/bin/plutil -extract "filesystem.allowWrite.${i}" raw -expect string -n -o - "$2" && printf x) ||
                return 1
            entry=${entry%x}
            clean_path "${entry}" || return 1
            printf '%s\n' "${entry}"
        done
        ;;
    *)
        [[ -x /usr/bin/jq ]] || return 1
        # Every entry must be a string without a newline, or the line-per-entry output below would drop or split it.
        /usr/bin/jq -e '.filesystem.allowWrite | type == "array" and all(.[]; type == "string" and (test("\n") | not))' \
            "$2" > /dev/null || return 1
        n=$(/usr/bin/jq -e '.filesystem.allowWrite | length' "$2") || return 1
        # No -e here: an empty array prints nothing, which -e would report as a failure; so jq's status is checked
        # unconditionally, and an empty read with a nonzero n fails the count check below.
        entry=$(/usr/bin/jq -r '.filesystem.allowWrite[]' "$2") || return 1
        i=0
        while IFS= read -r line; do
            [[ -n ${line} ]] || continue
            clean_path "${line}" || return 1
            printf '%s\n' "${line}"
            i=$((i + 1))
        done <<< "${entry}"
        ((i == n)) || return 1
        ;;
    esac
}

# @description Set `ancestors` to the absolute path `$1` and every directory above it, up to `/` (regime-cutover
#   U85). Every ancestor walk of hcom-seat goes through this: a relative path (a `#!sh` interpreter line) would never
#   reach `/`, so it is refused before the walk, and the walk itself stops at `/` and refuses after 4096 steps.
# @arg $1 string An absolute path.
# @set ancestors The paths, `$1` first.
ancestors_of() {
    local p=$1 n=0
    [[ ${p} == /* && ${p} != *[[:cntrl:]]* ]] || # lint-comparisons: allow an absolute-path and content test
        refuse "'${p}' is not an absolute path free of control characters"
    ancestors=()
    while :; do
        ancestors+=("${p}")
        [[ ${p} != / ]] || return 0 # lint-comparisons: allow the walk ends at the root, no path compare
        n=$((n + 1))
        ((n <= 4096)) || refuse "the path ${1} has more than 4096 components"
        p=${p%/*}
        [[ -n ${p} ]] || p=/
    done
}

# @description Set `dir_list` to every entry of directory `$1`, dot names included, `.` and `..` excluded, in glob
#   order (regime-cutover U95): `dotglob` and `nullglob` for this one glob, then restored. Every directory whose
#   entries matter (the worktree git directories, a seats root, a `.sandbox`) is listed this way, so no consumer sees
#   a dot-named entry that another misses. Fail-closed, so `nullglob` cannot pass a failed read off as an empty
#   directory: an absent `$1` lists nothing; one that exists must be a real directory, no link, readable and
#   searchable, and `/bin/ls -A` (its status checked) must count exactly the entries the glob saw. Anything else, an
#   unreadable directory or one whose read fails, refuses (exit 2).
# @arg $1 string A directory.
# @set dir_list The entries, as `$1/<name>`.
dir_entries() {
    local de_dot=0 de_null=0 de_p de_listing de_line de_n=0
    dir_list=()
    if [[ ! -e $1 && ! -L $1 ]]; then return 0; fi
    [[ -d $1 && ! -L $1 ]] || refuse "cannot list $1: it is not a real directory (a symbolic link or another file)"
    [[ -r $1 && -x $1 ]] || refuse "cannot list $1: it is not readable"
    if shopt -q dotglob; then de_dot=1; fi
    if shopt -q nullglob; then de_null=1; fi
    shopt -s dotglob nullglob
    for de_p in "$1"/*; do
        case ${de_p##*/} in
        . | ..) ;;
        *) dir_list+=("${de_p}") ;;
        esac
    done
    if ((! de_dot)); then shopt -u dotglob; fi
    if ((! de_null)); then shopt -u nullglob; fi
    de_listing=$(/bin/ls -A -- "$1" && printf .) || refuse "cannot list $1: reading it failed"
    de_listing=${de_listing%.}
    if [[ -n ${de_listing} ]]; then
        while IFS= read -r de_line; do
            [[ -n ${de_line} ]] || refuse "cannot list $1: reading it gave an empty name"
            de_n=$((de_n + 1))
        done <<< "${de_listing%$'\n'}"
    fi
    ((de_n == ${#dir_list[@]})) ||
        refuse "cannot list $1: reading it gave ${de_n} entries, the glob ${#dir_list[@]} (a failed or changing read)"
}

# @description Succeed when `$1`, a path read from a git pointer file (a `.git` file's `gitdir:`, a `commondir`, a
#   `gitdir` back-pointer), is in git's own form (regime-cutover U95): non-empty, no control character, no empty
#   component (`//`), no trailing `/`, no `.` component, and `..` only as the leading components of a relative path
#   (git's relative form, `../..` or `../../.git/worktrees/x`). git writes its pointers so. Anything else refuses at
#   the caller before any type test, since a trailing `/` or `/.` makes `[[ -L … ]]` follow a link and a `..` after
#   a link resolves differently from the text. Builtins only.
# @arg $1 string The path as read.
# @exitcode 1 It is not in git's form.
git_form_path() {
    local rest c lead=1
    [[ -n $1 && $1 != */ && $1 != *//* && $1 != *[[:cntrl:]]* ]] || return 1 # lint-comparisons: allow a form test on one path, no compare
    rest=$1
    if [[ ${rest} == /* ]]; then # lint-comparisons: allow an absolute-path test
        rest=${rest#/}
        lead=0
    fi
    while [[ -n ${rest} ]]; do
        c=${rest%%/*}
        if [[ ${rest} == */* ]]; then rest=${rest#*/}; else rest=''; fi # lint-comparisons: allow splitting one path into components
        case ${c} in
        .) return 1 ;;
        ..) ((lead)) || return 1 ;;
        *) lead=0 ;;
        esac
    done
}

# @description Print the physical form of the absolute path `$1`: every symlink followed (at most 40 hops in all,
#   one budget for the whole resolution) and the directory in its `pwd -P` form. A path that does not exist yet is
#   its nearest existing ancestor's physical form with the rest appended, so a write root a launch has not created
#   yet still compares with what it will be. Iterative (regime-cutover U85): a dangling link that names a path
#   under itself (`.state/<name> -> <name>/child`) spends the one budget and fails instead of recursing. Only shell
#   builtins and `/usr/bin/readlink` run.
# @arg $1 string An absolute path.
# @stdout The physical path.
# @exitcode 1 Not absolute, a control character in it or in a link, more than 40 links, or a directory that cannot
#   be resolved.
physical_path() {
    local p=$1 tail='' link dir n=0
    [[ ${p} == /* && ${p} != *[[:cntrl:]]* ]] || return 1 # lint-comparisons: allow an absolute-path and content test
    while :; do
        # p is absolute, so each step shortens it and the walk ends at `/`, which exists.
        while [[ ! -e ${p} && ! -L ${p} ]]; do
            tail=/${p##*/}${tail}
            p=${p%/*}
            [[ -n ${p} ]] || p=/
        done
        [[ -L ${p} ]] || break
        n=$((n + 1))
        ((n <= 40)) || return 1
        # The '.' keeps a target's own trailing newlines from the command substitution.
        link=$(/usr/bin/readlink "${p}" && printf .) || return 1
        link=${link%.}
        link=${link%$'\n'}
        [[ -n ${link} && ${link} != *[[:cntrl:]]* ]] || return 1
        case ${link} in
        /*) p=${link} ;;
        *) p=${p%/*}/${link} ;;
        esac
    done
    if [[ ${p} == / ]]; then # lint-comparisons: allow the root itself, whose `cd //` form pwd prints as `//`
        printf '%s\n' "${tail:-/}"
    elif [[ -d ${p} ]]; then
        dir=$(cd "${p}/" && pwd -P) || return 1
        printf '%s%s\n' "${dir%/}" "${tail}"
    else
        dir=$(cd "${p%/*}/" && pwd -P) || return 1
        printf '%s/%s%s\n' "${dir%/}" "${p##*/}" "${tail}"
    fi
}

physical_file() {

# @description Refuse (exit 2) when the physical path `$2`, or any directory above it, has the identity of a
#   protected write root (`root_ids`).
# @arg $1 string A label for the refusal.
# @arg $2 string A physical path.
refuse_if_seat_writable() {
    local ids id i named probe=()
    # The physical file and every directory above it, up to /, each compared by (device, inode): a case alias on a
    # case-insensitive file system or a hardlink of a writable file has the identity of what it aliases.
    ancestors_of "$2"
    probe=("${ancestors[@]}")
    ids=$(/usr/bin/stat "${stat_args[@]}" -- "${probe[@]}") || refuse "cannot read the identity of $1 $2 or a directory above it"
    i=0
    while IFS= read -r id; do
        if [[ ${root_ids} == *$'\n'"${id}"$'\n'* ]]; then # lint-comparisons: allow compares (device, inode) identities, not paths
            named=$(root_named "${id}") || named=${id}
            refuse "$1 $2 is or lies under the seat write root ${named} (${probe[i]} has its identity ${id})"
        fi
        i=$((i + 1))
    done <<< "${ids}"
}

# @description Print the write root whose identity is `$1`.
# @arg $1 string A `<device>:<inode>` identity.
root_named() {
    local i
    for ((i = 0; i < ${#root_id_list[@]}; i++)); do
        [[ ${root_id_list[i]} != "$1" ]] || { # lint-comparisons: allow compares (device, inode) identities, not paths
            printf '%s\n' "${root_path_list[i]}"
            return 0
        }
    done
}

# @description Add the (device, inode) identity of every argument that exists, file or directory, every link
#   followed, to the protected set (`root_ids`, `root_id_list`, `root_path_list`). A path that does not exist holds

add_roots() {

        [[ -e ${path} || -L ${path} ]] || continue
        present+=("${path}")
    done

    ids=$(/usr/bin/stat "${stat_args[@]}" -- "${present[@]}") || refuse "cannot read the identity of a seat write root among: ${present[*]}"

}

# @description Print the first executable `$1` on PATH, which hcom-seat has set: the system directories, then the
#   private tool directory before them once it is filled.

find_on_path() {

        [[ -n ${path_dir} && -x ${path_dir}/$1 && ! -d ${path_dir}/$1 ]] || continue

# @description Print the value of the git pointer file `$1` (a `.git` file, `commondir`, `gitdir`) read whole
#   (regime-cutover U85). git consumes the complete content less its trailing newlines, so only a single line is a
#   value: content that cannot be read, is empty, or holds any control character once one final newline is dropped (a
#   second line, a carriage return) fails, and the caller refuses. Pointer files are read this way only where git
#   cannot be asked yet (before the git state is checked); everywhere after, git answers (git_paths_of). A NUL
#   byte, or a byte count other than the file's size, fails too.
# @arg $1 string The file.
# @stdout The value.
# @exitcode 1 It cannot be read, is empty, or is not a single line free of control characters.
pointer_value() {
    local LC_ALL=C content size
    # Bash drops NUL bytes from a command substitution, so they are made \001 (a control character, refused) in the
    # same pass, and the bytes read must number the file's size: what is checked is what git reads.
    content=$({ /bin/cat -- "$1" | /usr/bin/tr '\000' '\001'; } && printf .) || return 1
    content=${content%.}
    size=$(/usr/bin/wc -c < "$1") || return 1
    size=${size//[[:space:]]/}
    [[ ${size} =~ ^[0-9]+$ ]] && ((${#content} == size)) || return 1
    content=${content%$'\n'}
    [[ -n ${content} && ${content} != *[[:cntrl:]]* ]] || return 1
    printf '%s\n' "${content}"
}

# @description Set `size_list` to the byte size of each file `$@`, links followed, in order, from one
#   `/usr/bin/stat` run (regime-cutover U95). Fail-closed: the run's status (xargs passes a failed stat on), every
#   line a bare number, and exactly one line per file; anything else refuses (exit 2) before a size is used.
# @arg $@ string Files.
# @set size_list The sizes.
sizes_of() {
    local out line
    size_list=()
    (($#)) || return 0
    out=$(printf '%s\0' "$@" | /usr/bin/xargs -0 /usr/bin/stat "${size_args[@]}" --) || refuse 'cannot read the size of the git state files'
    while IFS= read -r line; do
        [[ ${line} =~ ^[0-9]+$ ]] || refuse "cannot read the size of a git state file ('${line}')"
        size_list+=("${line}")
    done <<< "${out}"
    ((${#size_list[@]} == $#)) || refuse "cannot read the size of every git state file (${#size_list[@]} of $#)"
}

# @description Set `pointer_list` to the value of each git pointer file `$@`, with the rule of pointer_value
#   (regime-cutover U95): all are read in one pass (`cat | tr`, NUL bytes made \001 there) and cut at the sizes one
#   `stat` gave (sizes_of). The pass counts only when its pipeline succeeded (the `.` sentinel follows its status)
#   and the bytes read number the sizes' sum, checked before any value is cut, so a failed or short read is never
#   used. A file that is empty, or not a single line free of control characters once one final newline is dropped,
#   refuses (exit 2).
# @arg $@ string Pointer files.
# @set pointer_list The values.
pointer_values() {
    local LC_ALL=C all value off=0 total=0 i=0 files=("$@")
    pointer_list=()
    (($#)) || return 0
    sizes_of "$@"
    all=$({ printf '%s\0' "$@" | /usr/bin/xargs -0 /bin/cat -- | /usr/bin/tr '\000' '\001'; } && printf .) ||
        refuse 'cannot read the git pointer files'
    all=${all%.}
    for ((i = 0; i < $#; i++)); do total=$((total + size_list[i])); done
    ((total == ${#all})) || refuse "cannot read the git pointer files whole (${#all} of ${total} bytes)"
    for ((i = 0; i < $#; i++)); do
        value=${all:off:size_list[i]}
        off=$((off + size_list[i]))
        value=${value%$'\n'}
        [[ -n ${value} && ${value} != *[[:cntrl:]]* ]] ||
            refuse "cannot read ${files[i]} as one line free of control characters${pointer_hint:-}"
        pointer_list+=("${value}")
    done
}

# @description Resolve `$2` to the argv that runs it with no lookup left: its physical file, preceded by the physical
#   interpreter when it is a `#!` script (`#!/abs/interp` or `#!/usr/bin/env <name>`, no arguments; an interpreter
#   that is itself a script is refused). No part may be, or lie under, a write root of any seat (`root_ids`), since
#   a seat that could rewrite a file the launch runs would run uncontained on the next launch. A failure exits 2
#   naming `$1`.
# @arg $1 string A label for the refusal.
# @arg $2 string The executable's path.
# @set pinned The argv.
# @set pinned_spelled The interpreter as the `#!` line spells it (what the kernel follows), or empty.
pin_exec() {
    local label=$1 file first magic interp name extra interp_path
    pinned_spelled=''
    # The spelling the kernel will follow, every link hop, is held to the identity check too: a link in a write root
    # that points outside it passes the physical check today and can be retargeted before the next exec.
    refuse_if_link_chain_writable "${label}" "$2"
    file=$(physical_file "$2") || refuse "cannot resolve ${label} to a physical executable file: $2"
    refuse_if_seat_writable "${label}" "${file}"
    [[ -r ${file} ]] || refuse "cannot read ${label}: ${file}"
    # Each read's status is checked (pipefail covers head; /usr/bin/od on macOS exits 0 on a read error, so it only
    # formats): a failed read is refused, never taken for a file without an interpreter line.
    magic=$(/usr/bin/head -c 2 -- "${file}" | /usr/bin/od -An -tx1) || refuse "cannot read ${label}: ${file}"
    first=''
    if [[ ${magic//[[:space:]]/} == 2321 ]]; then # lint-comparisons: allow the hex bytes of `#!`, no path compare
        first=$(/usr/bin/head -n 1 -- "${file}") || refuse "cannot read the interpreter line of ${label}: ${file}"
    fi
    pinned=("${file}")
    case ${first} in
    '#!'*)
        extra=''
        read -r interp name extra <<< "${first#??}"
        pinned_spelled=${interp}
        if [[ ${interp} == /usr/bin/env ]]; then # lint-comparisons: allow the literal interpreter line, no path compare
            [[ -n ${name} && -z ${extra} && ${name} != -* ]] ||
                refuse "${label}: unsupported interpreter line '${first}' in ${file}"
            interp_path=$(find_on_path "${name}") || refuse "${label}: interpreter ${name} not found on PATH"
        else
            [[ -z ${name} ]] || refuse "${label}: unsupported interpreter line '${first}' in ${file}"
            # The kernel would not run a relative interpreter as written; it is refused before any walk over it.
            [[ ${interp} == /* ]] || # lint-comparisons: allow an absolute-path test
                refuse "${label}: interpreter line '${first}' in ${file} names no absolute path"
            interp_path=${interp}
        fi
        refuse_if_link_chain_writable "the interpreter of ${label}" "${interp_path}"
        interp=$(physical_file "${interp_path}") || refuse "cannot resolve the interpreter of ${label}: ${interp_path}"
        refuse_if_seat_writable "${label}" "${interp}"
        [[ -r ${interp} ]] || refuse "cannot read the interpreter of ${label}: ${interp}"
        magic=$(/usr/bin/head -c 2 -- "${interp}" | /usr/bin/od -An -tx1) || refuse "cannot read the interpreter of ${label}: ${interp}"
        [[ ${magic//[[:space:]]/} != 2321 ]] || refuse "${label}: its interpreter ${interp} is itself a script" # lint-comparisons: allow the hex bytes of `#!`, no path compare
        pinned=("${interp}" "${file}")
        ;;
    esac
}

# @description Refuse (exit 2) an optional tool whose `#!` line spells its interpreter outside the trusted system

}

# @description Resolve every extension directory `$@` to its canonical entry of the extension allow-list
#   (regime-cutover U31): `claude.levers.extensions` in the manifest the self-check read, so the installed copy reads
#   it from ~/.agents, outside every sandbox write root. A read failure is a refusal, not an empty list. The caller
#   gets the canonical allow-list entry (`pwd -P` of the listed path), never the caller's spelling: a symlink the
#   caller controls could be swapped between this check and omp resolving the path.
# @arg $@ string Extension directories.
# @set checked The canonical allow-list entries, in the order given.
extensions_canonical() {
    local allowed ext real listed entry entry_real
    allowed=$(awk '
    /^  levers:$/ { levers = 1; next }
    levers && /^  [^ ]/ { levers = 0 }
    levers && /^    extensions:$/ { list = 1; next }
    list && /^      - / { sub(/^      - /, ""); print; next }
    list { list = 0 }
' "${LEVER_MANIFEST}") || refuse "cannot read the extension allow-list in ${LEVER_MANIFEST}"
    [[ -n ${allowed} ]] || refuse "no extension allow-list (claude.levers.extensions) in ${LEVER_MANIFEST}"
    checked=()
    for ext in "$@"; do
        [[ -d ${ext} ]] || refuse "extension directory absent: ${ext}"
        real=$(cd "${ext}" && pwd -P) || refuse "cannot resolve extension directory: ${ext}"
        listed=''
        while IFS= read -r entry; do
            entry=${entry/#\~/${HOME}}
            # An entry that is absent or cannot be resolved lists nothing, so the extension stays refused.
            [[ -d ${entry} ]] || continue
            entry_real=$(cd "${entry}" && pwd -P) || continue
            if [[ ${entry_real} -ef ${real} ]]; then listed=${entry_real}; fi
        done <<< "${allowed}"
        [[ -n ${listed} ]] || refuse "extension directory is not in the allow-list (claude.levers.extensions): ${ext}"
        checked+=("${listed}")
    done
}

# @description Collect the git state host git reads for the worktrees of this repository into `git_state`, make sure
#   each file exists, and refuse (exit 2) a launch over state a seat may have written. The set: the common `config`,
#   `config.worktree`, `info/` and `hooks/`; for every linked worktree `worktrees/<n>/config.worktree`, `info/`,
#   `commondir` and `gitdir`; and the seat worktree's own `.git` file. None may be a symbolic link. Every
#   `config.worktree` may hold only the keys `git sparse-checkout` writes (`core.sparseCheckout`,
#   `core.sparseCheckoutCone`): anything else (`core.fsmonitor`, `core.hooksPath`, `filter.*`, `diff.*.textconv`,
#   `include.*`, `includeIf.*`, `extensions.*` among them) is a refusal, read with `git config --no-includes`, which
#   runs nothing the file names. Every `commondir` must lead to this common directory, and the seat worktree's
#   `.git` file into its `worktrees/`. An absent `config.worktree` is created empty and an absent `info/` or `hooks/`
#   empty, which git reads as no setting.
#   It runs before the first host git command (with the seat directory empty) and again before each git command in
#   the seat directory and when the settings are written.
# @arg $1 string The physical git common directory.
# @arg $2 string The physical seat directory, or empty.
# @set git_state The paths, for the seat's write denies.
# The repair a refusal over a worktree's git files names (regime-cutover U95).
# shellcheck disable=SC2016 # literal backquotes in a message
git_fix_hint='; repair or drop the worktree first (`git worktree move`, `git worktree remove` or `git worktree prune`)'
git_state_check() {
    local common_real=$1 dir_real=$2 wt f names name line target i pointers=() configs=() missing=()
    git_state=("${common_real}/config" "${common_real}/config.worktree" "${common_real}/info" "${common_real}/hooks")
    # Git's own shape for every linked worktree (regime-cutover U95, from git 2.56's source, PR body "Admin directory
    # files"): `worktrees` is a real directory; each admin directory is a real directory holding `commondir`, or git
    # would take the admin directory for its own common directory (setup.c get_common_dir_noenv) and read its
    # `config` and `hooks`, which a seat can write; and it holds none of the names path.c's common_list sends to the
    # common directory (git never writes them into an admin directory; `refs`, `logs` and `info` it does).
    [[ ! -L ${common_real}/worktrees ]] ||
        refuse "the worktree git directories ${common_real}/worktrees are a symbolic link, which host git would follow${git_fix_hint}"
    # One enumeration, dot names included, as git's own readdir_skip_dot_and_dotdot (worktree.c:203): every entry
    # must be a real directory (admin_dirs_match later holds it to the worktrees git lists, one to one).
    dir_entries "${common_real}/worktrees"
    admin_dirs=(${dir_list[@]+"${dir_list[@]}"})
    for wt in ${admin_dirs[@]+"${admin_dirs[@]}"}; do
        [[ -d ${wt} && ! -L ${wt} ]] ||
            refuse "the worktree git directory ${wt} is not a real directory (a symbolic link, file or other entry), which host git would follow or no worktree owns${git_fix_hint}"
        [[ -e ${wt}/commondir || -L ${wt}/commondir ]] ||
            refuse "the worktree git directory ${wt} has no commondir, so git would take it for its own common directory and read its config and hooks${git_fix_hint}"
        for f in branches common hooks lost-found objects remotes worktrees rr-cache svn config gc.pid packed-refs shallow; do
            [[ ! -e ${wt}/${f} && ! -L ${wt}/${f} ]] ||
                refuse "the worktree git directory ${wt} holds ${f}, which git keeps in the common directory and never writes there${git_fix_hint}"
        done
        git_state+=("${wt}/config.worktree" "${wt}/info")
        for f in commondir gitdir; do
            if [[ -e ${wt}/${f} || -L ${wt}/${f} ]]; then git_state+=("${wt}/${f}"); fi
        done
    done
    if [[ -n ${dir_real} && -f ${dir_real}/.git ]]; then git_state+=("${dir_real}/.git"); fi
    # The file type comes first, before any size or content is read (U95): a FIFO reads as size 0 and would block
    # a read or a write, and a device or socket is no file git means. Each entry is absent, or a real directory
    # (`info`, `hooks`), or a regular file, never a symbolic link.
    for f in "${git_state[@]}"; do
        [[ ! -L ${f} ]] || refuse "the git state ${f} is a symbolic link${git_fix_hint}"
        [[ -e ${f} ]] || continue
        case ${f##*/} in
        info | hooks) [[ -d ${f} ]] || refuse "the git state ${f} is not a directory${git_fix_hint}" ;;
        *) [[ -f ${f} ]] || refuse "the git state ${f} is not a regular file (a FIFO, device, socket or directory)${git_fix_hint}" ;;
        esac
        if [[ ${f##*/} == commondir && ${f} == "${common_real}"/worktrees/* ]]; then pointers+=("${f}"); fi # lint-comparisons: allow a fixed file name below the common directory
    done
    # Read here before any git may run (the first call precedes the first git command); git has no query for
    # another worktree's commondir. One line or a refusal: git would consume every line. All in one read (U95).
    pointer_values ${pointers[@]+"${pointers[@]}"}
    for ((i = 0; i < ${#pointers[@]}; i++)); do
        wt=${pointers[i]%/commondir}
        line=${pointer_list[i]}
        git_form_path "${line}" ||
            refuse "${pointers[i]} holds '${line}', not a path in git's own form (no trailing /, no . component, .. only leading a relative path)${git_fix_hint}"
        case ${line} in # lint-comparisons: allow a relative operand is made absolute, no path compare
        /*) target=${line} ;;
        *) target=${wt}/${line} ;;
        esac
        [[ ${target} -ef ${common_real} ]] || refuse "${wt}/commondir leads to ${line}, not to ${common_real}"
    done
    # A dry run validates and creates nothing: an absent file holds no setting, and the real launch creates it. The
    # absent `info/` and `hooks/` directories are made in one `mkdir` (U95), without -p: each parent is a real
    # directory checked above, so an entry that appeared since the check fails the run, which refuses. Each is then
    # checked to be a real directory, no link. An empty `config.worktree` is made by a builtin.
    if ((! dry_run)); then
        for f in "${git_state[@]}"; do
            case ${f##*/} in
            info | hooks) [[ -d ${f} ]] || missing+=("${f}") ;;
            config.worktree) [[ -f ${f} ]] || : >> "${f}" || refuse "cannot create ${f}" ;;
            esac
        done
        if ((${#missing[@]})); then
            /bin/mkdir -- "${missing[@]}" || refuse "cannot create the git state directories (${missing[*]})"
            for f in "${missing[@]}"; do
                [[ -d ${f} && ! -L ${f} ]] || refuse "the git state ${f} is not a real directory after it was created"
            done
        fi
    fi
    for f in "${git_state[@]}"; do
        if [[ ${f##*/} == config.worktree && -e ${f} ]]; then configs+=("${f}"); fi
    done
    # An empty config.worktree (what a launch creates) holds no key, so git reads only the others (U95): one size read.
    # The rest cost one git each: git config validates one --file per run, and joining files would let one file's
    # section run into the next. A sparse checkout's file is the only non-empty one git writes (none on this host).
    sizes_of ${configs[@]+"${configs[@]}"}
    for ((i = 0; i < ${#configs[@]}; i++)); do
        ((size_list[i] > 0)) || continue
        f=${configs[i]}
        # From /, so no repository around the cwd is discovered or read; git() adds the overrides.
        names=$(cd / && git config --file "${f}" --no-includes --name-only --list) ||
            refuse "cannot read the git config ${f}"
        while IFS= read -r name; do
            case ${name} in
            '' | core.sparsecheckout | core.sparsecheckoutcone) ;;
            *) refuse "the git config ${f} sets ${name}, which host git would act on; a seat may have written it" ;;
            esac
        done <<< "${names}"
    done
    # The seat worktree's `.git` file is git's to read (relative forms, `--relative-paths`, included): once the
    # state it reads has passed, git names the git directory and common directory it resolves there.
    if [[ -n ${dir_real} && -f ${dir_real}/.git ]]; then
        git_paths_of 2 -C "${dir_real}" rev-parse --path-format=absolute --git-dir --git-common-dir
        [[ ${git_paths[0]%/*} -ef ${common_real}/worktrees && ${git_paths[1]} -ef ${common_real} ]] ||
            refuse "${dir_real}/.git leads to ${git_paths[0]}, outside ${common_real}/worktrees"
    fi
}

# @description Run host git (git, the checked argv) with `$2...` and read its whole answer into `git_paths`
#   (regime-cutover U85): exactly `$1` newline-terminated lines, each an absolute path free of control characters. A
#   failing git, an unterminated line, another count (a path holding a newline splits into more), a relative path or
#   a control character refuses (exit 2).
# @arg $1 int The number of paths.
# @arg $@ string git's arguments after it.
# @set git_paths The paths.
git_paths_of() {
    local count=$1 out line
    shift
    out=$(git "$@" && printf .) || refuse "git $* failed"
    out=${out%.}
    git_paths=()
    while [[ -n ${out} ]]; do
        [[ ${out} == *$'\n'* ]] || refuse "git $* printed an unterminated line"
        line=${out%%$'\n'*}
        out=${out#*$'\n'}
        [[ ${line} == /* && ${line} != *[[:cntrl:]]* ]] || # lint-comparisons: allow an absolute-path and content test
            refuse "git $* printed '${line}', not an absolute path free of control characters"
        git_paths+=("${line}")
    done
    ((${#git_paths[@]} == count)) || refuse "git $* printed ${#git_paths[@]} paths, not ${count}"
}

#   every launch, so a component another process widened is never granted or denied as if it were the root's.

store_root_mode_check() {

}

store_root_make() {

        [[ -d ${path} && ! -L ${path} && -O ${path} ]] || refuse "the store root component ${path} is not a real directory of this user"
        store_root_mode_check "${path}"
    done
}

# @description Fill the identity table for the physical paths `$@` (regime-cutover U95), which every containment
#   decision of the overlap check reads: per path, whether it exists, the (device, inode) identities of its deepest
#   existing ancestor (the path itself when it exists) and of every directory above it, and the absent remainder below
#   that ancestor, ASCII case-folded by ascii_lower (builtins only). One `/usr/bin/stat` (through xargs, order kept)
#   serves every path, instead of several processes per pair. Fail-closed per record: every input must be a clean path; every identity line must be `<dev>:<ino>`, and
#   their number exactly what the ancestor walks asked for; every folded remainder must have its input's length and
#   the grammar `(/<lower-case component>)*/`; each table must hold one entry per input.
# @set tbl_exists 1 or 0 per path.
# @set tbl_first The identity of the deepest existing ancestor per path.
# @set tbl_chain `\n<id>\n<id>…\n` per path: that ancestor's identity first, then each directory above it.
# @set tbl_rest The absent remainder per path, case-folded, ending in `/` (`/` when the path exists).
identity_table() {
    local p d rest ids line folded chain='' i=0 k=0 all=() counts=()
    tbl_exists=() tbl_first=() tbl_chain=() tbl_rest=()
    for p in "$@"; do
        require_clean_path 'a seat path' "${p}"
        # Absolute, so each step shortens it and the walk ends at `/`, which exists.
        d=${p} rest=''
        while [[ ! -e ${d} && ! -L ${d} ]]; do
            rest=/${d##*/}${rest}
            d=${d%/*}
            [[ -n ${d} ]] || d=/
        done
        if [[ -e ${p} ]]; then tbl_exists+=(1); else tbl_exists+=(0); fi
        ancestors_of "${d}"
        all+=("${ancestors[@]}")
        counts+=("${#ancestors[@]}")
        rest=${rest}/
        ascii_lower "${rest}" folded || refuse "cannot fold the absent part of ${p}"
        [[ ${#folded} == "${#rest}" && ${folded} =~ ^(/[a-z0-9._@+-]+)*/$ ]] ||
            refuse "cannot fold the absent part of ${p} ('${folded}')"
        tbl_rest+=("${folded}")
    done
    (($#)) || return 0
    ids=$(printf '%s\0' "${all[@]}" | /usr/bin/xargs -0 /usr/bin/stat "${stat_args[@]}" --) ||
        refuse "cannot read the identity of a seat path or a directory above it"
    while IFS= read -r line; do
        [[ ${line} =~ ^[0-9]+:[0-9]+$ ]] || refuse "cannot read the identity of a seat path ('${line}')"
        ((i < ${#counts[@]})) || refuse 'more identities than seat paths were read'
        if ((k == 0)); then tbl_first+=("${line}"); fi
        chain+=${line}$'\n'
        k=$((k + 1))
        if ((k == counts[i])); then
            tbl_chain+=($'\n'"${chain}")
            chain='' k=0 i=$((i + 1))
        fi
    done <<< "${ids}"
    ((i == $# && k == 0)) || refuse "cannot read the identity of every seat path (${i} of $#)"
    ((${#tbl_exists[@]} == $# && ${#tbl_first[@]} == $# && ${#tbl_chain[@]} == $# && ${#tbl_rest[@]} == $#)) ||
        refuse 'the identity table does not hold one entry per seat path'
}

# @description Set the variable named `$2` to `$1` with A-Z made a-z (regime-cutover U95), by builtins only (a case
#   table, no `tr` and no locale; bash 3.2 has no `${x,,}`), so no producer's output is read back.
# @arg $1 string ASCII text.
# @arg $2 string The name of the variable to set.
# @exitcode 1 The variable cannot be set.
ascii_lower() {
    # The locals carry a prefix, so the caller's variable `$2` is never one of them (printf -v sets the nearest).
    local LC_ALL=C al_text=$1 al_out='' al_c al_before al_upper=ABCDEFGHIJKLMNOPQRSTUVWXYZ
    local al_lower=abcdefghijklmnopqrstuvwxyz
    [[ $2 != al_* && $2 != LC_ALL ]] || return 1
    while [[ -n ${al_text} ]]; do
        al_c=${al_text:0:1}
        al_text=${al_text:1}
        case ${al_c} in
        [ABCDEFGHIJKLMNOPQRSTUVWXYZ])
            al_before=${al_upper%%"${al_c}"*}
            al_c=${al_lower:${#al_before}:1}
            ;;
        esac
        al_out+=${al_c}
    done
    printf -v "$2" '%s' "${al_out}"
}

# @description Decide from the identity table whether path `$2` is path `$1` or lies under it (regime-cutover U85,
#   U95), by identity for everything that exists, so a case alias on a case-insensitive volume is the path it aliases.
#   When `$1` exists: yes iff `$1`'s identity is in `$2`'s chain (`$2`'s deepest existing ancestor or a directory
#   above it). When `$1` does not exist, an existing `$2` cannot lie under it (no). When neither exists, `$2` can lie
#   under `$1` only if both have the same deepest existing ancestor; below it nothing exists, so no link or alias can
#   intervene, and the absent remainders decide: yes iff `$1`'s is `$2`'s or a prefix of it on a component boundary
#   (`a/b` is no prefix of `a/bc`), compared ASCII case-folded, since on a case-insensitive volume two spellings that
#   differ by case become one directory once made. No process runs.
# @arg $1 int The table index of the outer path.
# @arg $2 int The table index of the inner path.
# @exitcode 0 `$2` is `$1` or lies under it.
# @exitcode 1 It does not.
within_ix() {
    if ((tbl_exists[$1])); then
        [[ ${tbl_chain[$2]} == *$'\n'"${tbl_first[$1]}"$'\n'* ]] # lint-comparisons: allow compares (device, inode) identities, not paths
        return
    fi
    ((! tbl_exists[$2])) || return 1
    [[ ${tbl_first[$1]} == "${tbl_first[$2]}" ]] || return 1 # lint-comparisons: allow compares (device, inode) identities, not paths
    [[ ${tbl_rest[$2]} == "${tbl_rest[$1]}"* ]]              # lint-comparisons: allow absent components below one ancestor of the same identity, compared on component boundaries
}

# @description Refuse (exit 2) when the hcom store `HCOM_DIR` is, lies inside or contains the program store's root
#   (regime-cutover U219; verdict U215-15c6be1e P1 `:127`, held residual on this unit): the hcom store is a write root
#   of every seat (seat_write_roots) and no rendered deny covers a directory under it, so a root at or under it would
#   put the records inside a worker's write grant, and a store under the root would put the bus inside the records.
#   Both paths in their physical form (store_root_hold, physical_path), the decision by identity for what exists and
#   by the absent components below one shared ancestor otherwise (identity_table, within_ix), before the seats root, a
#   slot or a settings file is made, in a dry run too. The refusal names both paths and which contains which. Nothing
#   to judge without a root (outside a checkout, with an explicit HCOM_DIR, where no slug exists).
store_root_overlap_check() {

# @description Set `phys_list` to the physical form of each absolute path `$@`, in order (regime-cutover U95), or
#   refuse (exit 2), in one subshell for all of them, present or absent. In that subshell a path's deepest existing entry is found with builtins (physical_path's
#   walk); it must be a directory, which `cd -P` resolves, and the absent rest is appended, as physical_path does.
#   The inputs are worktree records (git's list and the admin directories' `gitdir`) and seat directories: a path
#   that is, or lies below, a regular file or a dangling link is no directory-backed worktree but a corrupt record,
#   and refuses, naming `git worktree prune` and `git worktree repair` (no per-record fallback). Fail-closed per record: the subshell writes exactly one record per path,
#   `ok<TAB><physical path>` after a `cd -P` whose status was 0, `notdir` for a path not backed by a directory, or
#   `fail` after a failed `cd`, and fails when a record cannot be written. Each record is checked against its
#   grammar and its result assigned to its own index (nothing is printed and read back): only `ok` with a clean
#   path passes. Anything else, a record too many or too few, or an index left without its result refuses.
# @arg $@ string Absolute paths free of control characters.
# @set phys_list The physical paths, one per input.
physical_paths() {
    local out line resolved i=0 args=("$@")
    phys_list=()
    (($#)) || return 0
    out=$(for p in "$@"; do
        rest=''
        while [[ ! -e ${p} && ! -L ${p} ]]; do
            rest=/${p##*/}${rest}
            p=${p%/*}
            [[ -n ${p} ]] || p=/
        done
        if [[ ! -d ${p} ]]; then
            printf 'notdir\n' || exit 1
        elif [[ ${p} == / ]]; then # lint-comparisons: allow the root itself, whose `cd //` form pwd prints as `//`
            printf 'ok\t%s\n' "${rest:-/}" || exit 1
        elif cd -P -- "${p}/" 2> /dev/null; then
            printf 'ok\t%s%s\n' "${PWD%/}" "${rest}" || exit 1
        else
            printf 'fail\n' || exit 1
        fi
    done) || refuse 'cannot resolve the paths (the resolving subshell failed)'
    while IFS= read -r line; do
        ((i < $#)) || refuse 'cannot resolve the paths (more records than paths)'
        case ${line} in
        notdir) refuse "the worktree record ${args[i]} is not backed by a directory: it, or its deepest existing ancestor, is a regular file or a dangling symbolic link, so the record is corrupt; run \`git worktree prune\` if the worktree is gone, or \`git worktree repair\` if it moved" ;;
        ok$'\t'*) resolved=${line#ok$'\t'} ;;
        *) refuse "cannot resolve the path ${args[i]} ('${line}')" ;;
        esac
        clean_path "${resolved}" || refuse "the path ${args[i]} resolves to '${resolved}', not a clean absolute path"
        phys_list[i]=${resolved}
        i=$((i + 1))
    done <<< "${out}"
    ((i == $# && ${#phys_list[@]} == $#)) || refuse "cannot resolve every path (${#phys_list[@]} of $#)"
}

        git_form_path "${pointer_list[i]}" ||
            refuse "${gitdirs[i]} holds '${pointer_list[i]}', not a path in git's own form (no trailing /, no . component, .. only leading a relative path)${git_fix_hint}"
        v=${pointer_list[i]%/.git}
        case ${v} in # lint-comparisons: allow a relative operand is made absolute, no path compare
        /*) derived+=("${v}") ;;
        *) derived+=("${admin_dirs[i]}/${v}") ;;
        esac
    done
    physical_paths "${derived[@]}"
    ((${#phys_list[@]} == n)) || refuse "the worktrees the git directories of $1 record were not all resolved"
    # Listed worktrees at indices 0..n-1, recorded ones at n..2n-1.
    identity_table "${worktree_phys[@]}" "${phys_list[@]}"
    for ((i = 0; i < n; i++)); do listed+=${tbl_first[i]}${tbl_rest[i]}$'\n'; done
    for ((i = 0; i < n; i++)); do
        v=${phys_list[i]}
        key=${tbl_first[n + i]}${tbl_rest[n + i]}
        [[ ${listed} == *$'\n'"${key}"$'\n'* ]] || # lint-comparisons: allow compares (device, inode) identities with case-folded absent rests, not paths
            refuse "the worktree git directory ${admin_dirs[i]} records ${v}, which git does not list as a worktree${git_fix_hint}"
        [[ ${seen} != *$'\n'"${key}"$'\n'* ]] || # lint-comparisons: allow compares (device, inode) identities with case-folded absent rests, not paths
            refuse "the worktree git directory ${admin_dirs[i]} records ${v}, which another worktree git directory records too (the same directory by identity)${git_fix_hint}"
        seen+=${key}$'\n'
    done
}

# @description Render the seat's settings lists (regime-cutover U272e): `write` (the allowWrite roots, exactly
#   seat_write_roots' list, so the protected set and the sandbox cannot drift), `deny_write` with the macOS
#   `deny_write_patterns`, `deny_read` and `allow_read`, with the structural rows tagged where they are rendered
#   (tag_rows). The lists are the one statement of the seat's boundary: seat_sandbox_write writes them into the
#   settings file, and the dsh role judges every grant of them against every deny of them before anything is made
#   (settings_judge, regime-cutover U272f), so a refusal reads what the settings will say and no hand-kept list of
#   inputs or of denied places can lack a member. Every directory is resolved by physical_path, present or
#   absent, so the lists are the same before and after the slots are made. The settings name what the seat may
#   write (its directory, the repository's git common directory, the program's hcom store, its own omp profile and
#   the omp session leases, its own state slot (a per-seat cache root) and the shared Claude Code directory
#   `<seats-root>/.state/claude` (the `CLAUDE_CONFIG_DIR` the shim exports, regime-cutover U318: one login per seats
#   root, stored and refreshed by Claude Code itself); the same for both omp roles,
#   so no seat writes the seats root or reaches the herdr socket, and none can start a seat), what it may not change
#   inside those roots (git config and hooks, the hcom store's launch scripts and configuration, agent configuration
#   that runs outside the seat and the package the checkout's Claude Code hooks import), what it may not write or
#   read of the operator's Claude Code state (`~/.claude`, `~/.claude.json`, a caller's `CLAUDE_CONFIG_DIR`;
#   regime-cutover U190b: srt 0.0.81 grants `~/.claude/debug` of the real HOME on its own, whatever
#   `CLAUDE_CONFIG_DIR` says, so leaving that state out of the roots denies nothing, and the deny is explicit; srt keeps
#   a deeper deny under an allow, measured at U85), and what else it may not read (SSH, GPG, cloud and codex
#   credentials, the chezmoi sources, `~/Workspace` but its own repository, other omp profiles, other hcom stores,
#   every seat's sandbox directory, and for a worker the other seats).
# @set write The allowWrite roots.
# @set deny_write The denyWrite paths; `deny_write_patterns` the macOS patterns appended to them.
# @set deny_read The denyRead paths.
# @set allow_read The allowRead paths.
# @set row_tags The structural tags, each naming one row by list and position (tag_row): `slot` for the seat's own
#   slots (its directory and state slot) and the shared Claude Code directory, the seats-root denies they re-open, the
#   project-file denies under its directory and the configuration denies under the shared directory; `profile` for
#   its own omp profile and the profiles deny it re-opens; `store` for the program store's root (U219c): the
#   orchestrator's held write row 7, the one grant store_root_judge exempts, and the deny row of every other role. The
#   grant tags are the dsh role's and the orchestrator's store row, read by their judges; the deny tags are rendered
#   for every role and change no list.
seat_settings_render() {
    local root path kind project_files=()
    h=$(physical_path "${HOME}") || refuse "cannot resolve HOME ${HOME}"
    dir_real=$(physical_path "${dir}") || refuse "cannot resolve the seat directory ${dir}"
    common_real=$(physical_path "${common}") || refuse "cannot resolve the git common directory ${common}"
    hcom_real=$(physical_path "${HCOM_DIR}") || refuse "cannot resolve the hcom store ${HCOM_DIR}"
    seats_real=$(physical_path "${seats_root}") || refuse "cannot resolve the seats root ${seats_root}"
    sandbox_state=${seats_real}/.state/${name}
    write=("${seat_write[@]}")
    row_tags=() row_tag_kinds=() row_tag_ixs=() row_tag_paths=()
    deny_write=("${seats_real}/.sandbox")
    # The hook shims under .claude/hooks import their code from .claude/contextdb, run by sessions outside the seat.
    project_files=(.claude/settings.json .claude/settings.local.json .claude/hooks .claude/contextdb .omp .codex .envrc .mcp.json)
    # The project-file rows under the seat's own directory are refinements inside its write root (srt keeps the
    # deeper deny), so the slot and the cwd contain them by construction: each is tagged at its position.
    for path in "${project_files[@]}"; do
        tag_row slot denyWrite ${#deny_write[@]} "${dir_real}/${path}"
        deny_write+=("${dir_real}/${path}")
    done
    # The shared Claude Code directory is a write root of every seat (the child's login, `.claude.json`, state and
    # sessions live there, regime-cutover U318), and these rows under it are what a seat must not change: the
    # settings, rules, hooks, plugins, skills, commands and agents that another seat's child, or the operator's login
    # command under that directory, would load (the U190 hole, closed among seats). The bridge child loads none of
    # them (`settingSources: []`, `--strict-mcp-config`); the rows hold whatever a child loads. Tagged like the
    # project-file rows: the grant at write row 2 contains them by construction.
    for path in settings.json settings.local.json rules hooks plugins skills commands agents; do
        tag_row slot denyWrite ${#deny_write[@]} "${claude_config_real}/${path}"
        deny_write+=("${claude_config_real}/${path}")
    done
    for path in "${project_files[@]}"; do deny_write+=("${checkout}/${path}"); done
    # The git state host git reads for any worktree of this repository (regime-cutover U85): a seat that could write
    # it could make a later host git command run a program of its choosing (`core.fsmonitor`, `core.hooksPath`,
    # filter and textconv drivers, includes). git_state_check refuses a launch over such state and creates the files
    # that are absent, so each deny below names an existing path (srt on Linux binds only existing paths).
    git_state_check "${common_real}" "${dir_real}"
    deny_write+=("${git_state[@]}")
    # A worktree created after this launch gets its files denied on macOS by pattern; on Linux srt takes literal
    # write denies only, and the next launch's git_state_check covers it.
    # The patterns are the one place a settings entry is not a clean path: a clean prefix and a fixed suffix.
    deny_write_patterns=''
    if [[ ${os} == Darwin ]]; then
        require_clean_path 'the git common directory' "${common_real}"
        for path in config.worktree info commondir gitdir; do
            # srt reads `*` as `[^/]*` (glob-pattern.js:179-180, globToRegex :208-209), so dot-named ids match too.
            deny_write_patterns+=",\"${common_real}/worktrees/*/${path}\""
        done
    fi
    for path in config.toml env config.env .tmp/launch scripts integrations shell_env.json; do
        deny_write+=("${hcom_real}/${path}")
    done
    deny_read=("${h}/.ssh" "${h}/.gnupg" "${h}/.aws" "${h}/.netrc" "${h}/.docker" "${h}/.kube" "${h}/.config/gcloud"
        "${h}/.codex" "${h}/.omp/agent")
    # The profiles deny: the seat's own omp profile is the one row re-opened under it (the dsh case below tags that
    # row; settings_judge pairs the two tags).
    tag_row profile denyRead ${#deny_read[@]} "${h}/.omp/profiles"
    deny_read+=("${h}/.omp/profiles" "${h}/.hcom" "${h}/.local/state/hcom"
        "${h}/.local/share/chezmoi" "${h}/.local/share/chezmoi-private" "${h}/.config/chezmoi"
        "${h}/.config/chezmoi-private" "${h}/Workspace" "${seats_real}/.sandbox")
    # Every program's seats root is unreadable but this seat's own paths: the whole ~/.local/state/omp-seats tree
    # and every configured seats root. srt keeps a deeper deny under an allow (measured, 0.0.81), so each
    # `.sandbox` stays unreadable inside an allowed root. These rows exist to be re-opened by the own slot alone.
    for path in "${h}/.local/state/omp-seats" "${seats_real}"; do
        tag_row slot denyRead ${#deny_read[@]} "${path}"
        deny_read+=("${path}")
    done
    if [[ -n ${REGIME_SEATS_ROOT:-} ]]; then
        root=$(physical_path "${REGIME_SEATS_ROOT}") || refuse "cannot resolve the seats root ${REGIME_SEATS_ROOT}"
        tag_row slot denyRead ${#deny_read[@]} "${root}"
        deny_read+=("${root}")
    fi
    operator_claude_paths
    deny_write+=("${operator_claude[@]}")
    deny_read+=("${operator_claude[@]}")
    # The role table's read-grant row (U272c): denyRead is broad and every allowRead entry re-opens a path under it,
    # so the list is the role's own. The omp roles re-open their directory, the repository's git directory (the
    # worktree's objects and refs), the hcom store, their omp profile, their state slot, the shared Claude Code
    # directory (U318), the coordinator's records under the main checkout (briefs, verdict files), read by absolute
    # path, and the program store's root (regime-cutover U219: the held physical `store_root_phys`, last; where the
    # records live once U221 has moved them; made by this launch when absent, U219c); the main checkout itself is unreadable
    # to a worker wherever it lives, and the orchestrator also reads the worker clones of its own program, which it
    # reviews. The dsh role has no worktree, no bus and no store: it re-opens its scratch cwd and state slot, the
    # shared Claude Code directory, DSH_HOME, its own omp profile, the skills it loads and the pinned tool directory
    # on its PATH, and no git, hcom, record or store-root path.
    # The omp roles' rows of the Router's credential root (regime-cutover U353b, verdict U353-8791100f P1 `:430`; U353d,
    # verdict U353-318f268d P1 `:2383` and P2 `:2393`): srt allows reads by default, and the U353 head denied the root
    # to the dsh row alone, so a worker or orchestrator seat read `router-credentials/gh/hosts.yml` once the login was
    # there; U353b's row named the kit's root whether or not it existed, which srt's Linux backend mounts nothing for,
    # and denied it for read alone, so a worker under `DSH_HOME=HCOM_DIR` held the root under a write root. The rows
    # are the held physical root (cred_root_hold, under the home router-gh resolves; made by cred_root_make before this
    # render): one denyRead row before the read grants, one denyWrite row after the operator's Claude Code paths.
    case ${role} in
    orchestrator)
        deny_read+=("${cred_root_phys}")
        deny_write+=("${cred_root_phys}")
        allow_read=("${dir_real}" "${common_real}" "${hcom_real}" "${h}/.omp/profiles/${role}" "${sandbox_state}"
            "${claude_config_real}" "${checkout}/.orchestration/orchestrate" "${seats_real}" ${store_root_phys:+"${store_root_phys}"})
        # The held store root is write row 7 (seat_write_roots), the one grant store_root_judge exempts, by this tag.
        if [[ -n ${store_root_phys} ]]; then tag_row store allowWrite 7 "${store_root_phys}"; fi
        ;;
    worker)
        deny_read+=("${checkout}" "${cred_root_phys}")
        deny_write+=("${cred_root_phys}")
        # The program store's root (regime-cutover U219c, verdict U219-985b7c04 P1 `:1981`): the orchestrator's write
        # root is the worker's deny, in the credential root's shape (the held physical path, tagged; made by
        # store_root_make before this launch's settings are written, so srt's Linux backend binds it), so a worker
        # grant a link folds onto the root (`~/.omp/run -> <root>`) is denied by srt as well as refused by
        # store_root_judge.
        if [[ -n ${store_root_phys} ]]; then
            tag_row store denyWrite ${#deny_write[@]} "${store_root_phys}"
            deny_write+=("${store_root_phys}")
        fi
        allow_read=("${dir_real}" "${common_real}" "${hcom_real}" "${h}/.omp/profiles/${role}" "${sandbox_state}"
            "${claude_config_real}" "${checkout}/.orchestration/orchestrate" ${store_root_phys:+"${store_root_phys}"})
        ;;
    dsh | router)
        # The deny row (U272d): the role's own denies for read and for write, after the worker's. The credential root
        # (U353, `cred_root_grant`) stands before them: the dsh row denies it for read, both rows for write, and each of
        # its rows carries the `credential` tag that pairs it with the DSH_HOME grant it lies inside by construction.
        deny_read+=("${checkout}")
        if [[ ${cred_root_grant} == deny ]]; then # lint-comparisons: allow a cell word of the role table (read, deny), not a path
            tag_row credential denyRead ${#deny_read[@]} "${cred_root_phys}"
            deny_read+=("${cred_root_phys}")
        fi
        deny_read+=(${dsh_deny[@]+"${dsh_deny[@]}"})
        # The program store's root (U219c): denied for write by the dsh and router rows as by the worker, right before
        # the credential root's row; the rows carry no grant of it, for read or for write.
        if [[ -n ${store_root_phys} ]]; then
            tag_row store denyWrite ${#deny_write[@]} "${store_root_phys}"
            deny_write+=("${store_root_phys}")
        fi
        tag_row credential denyWrite ${#deny_write[@]} "${cred_root_phys}"
        deny_write+=("${cred_root_phys}" ${dsh_deny[@]+"${dsh_deny[@]}"})
        allow_read=("${dir_real}" "${sandbox_state}" "${claude_config_real}" "${dsh_home_phys}" "${h}/.omp/profiles/${omp_profile}"
            "${h}/.agents/skills" "${tools_dir}")
        # The router row's credential root (U353): allowRead row 7, after the tool directory, so every position the dsh
        # row tags stays; tagged `credential` like its denyWrite row, which it is by construction.
        if [[ ${cred_root_grant} == read ]]; then # lint-comparisons: allow a cell word of the role table (read, deny), not a path
            tag_row credential allowRead ${#allow_read[@]} "${cred_root_phys}"
            allow_read+=("${cred_root_phys}")
        fi
        # The judge's exempted grants, each one row by its position (tag_row, regime-cutover U272g): the own cwd and
        # state slot, rows 0 and 1 of both grant lists, the shared Claude Code directory, row 2 of both (seat_write_roots
        # puts the three first; the directory sits under the seats-root denies and over its configuration denies, U318),
        # and the own omp profile, row 4 of both. DSH_HOME (row 3 of both) carries the `credential` tag (U353), which
        # pairs it with the credential-root rows alone (the denies it contains by construction, and the router row's
        # read grant against its own write deny); against every other deny it is judged like any row, as are
        # `~/.omp/run` (write row 5) and the router role's state root (write row 6), which carry no tag whatever they
        # are spelled, so a DSH_HOME at or inside the profiles directory, or a `~/.omp/run` linked there, is a hit.
        for kind in allowRead allowWrite; do
            tag_row slot "${kind}" 0 "${dir_real}"
            tag_row slot "${kind}" 1 "${sandbox_state}"
            tag_row slot "${kind}" 2 "${claude_config_real}"
            tag_row credential "${kind}" 3 "${dsh_home_phys}"
            tag_row profile "${kind}" 4 "${h}/.omp/profiles/${omp_profile}"
        done
        ;;
    esac
}

# @description Tag one rendered row, the one at position `$3` of the list `$2`, with the structural tag `$1`
#   (regime-cutover U272g): a tag names why that row may overlap another by construction, and settings_judge exempts a
#   (grant, deny) pair only when both rows carry the same tag. A tag is a reference to one row by its position, never
#   a pattern over spellings: round 5 keyed the tags by rendered spelling, so a `DSH_HOME` equal to the profiles
#   directory, or a `~/.omp/run` linked there, was rendered in that spelling and inherited the profile tag (verdict
#   U272f P1). `$4` is the path the lever rendered at that position; row_tag applies the tag only to a row byte-equal
#   to it, so a list that drifted from its tags exempts nothing.
# @arg $1 string The tag.
# @arg $2 string The list: allowRead, allowWrite, denyRead or denyWrite.
# @arg $3 string The row's position in that list.
# @arg $4 string The path rendered at that position.
# @set row_tags The tags so far; `row_tag_kinds` their lists, `row_tag_ixs` their positions and `row_tag_paths` their
#   paths, one entry per tagged row.
tag_row() {
    row_tags+=("$1") row_tag_kinds+=("$2") row_tag_ixs+=("$3") row_tag_paths+=("$4")
}

# @description Set `tag_of` to the structural tag of the row `$3` at position `$2` of the list `$1` (tag_row), or to
#   the empty string when no tag names that position or the row there is not byte-equal to the path the tag was
#   rendered with.
# @arg $1 string The list.
# @arg $2 string The position.
# @arg $3 string The row at it, as rendered.
# @set tag_of The tag or empty.
row_tag() {
    local i
    tag_of=''
    for ((i = 0; i < ${#row_tags[@]}; i++)); do
        [[ ${row_tag_kinds[i]} == "$1" && ${row_tag_ixs[i]} == "$2" && ${row_tag_paths[i]} == "$3" ]] || continue # lint-comparisons: allow a list name, a position, and one rendered row against the path rendered at that position, both from seat_settings_render
        tag_of=${row_tags[i]}
    done
}

# @description Judge the rendered `allowWrite` rows against the program store's root (regime-cutover U219c, verdict
#   U219-985b7c04 P1 `:1981`: round 2 judged `HCOM_DIR` alone, so a worker whose `~/.omp/run` was a link to the root
#   launched with the records in its write grants). The root is the held `store_root_phys`, taken as held and never
#   resolved again (the overlap check's form); the rows are the `write` list seat_settings_render set, resolved in
#   one subshell (physical_each); both are judged by identity for what exists and by the absent components below
#   one shared ancestor otherwise (identity_table, within_ix). A row
#   that is, contains or lies inside the root is a hit, whatever role renders it, unless it is the orchestrator's own
#   store-root row: the row at the position tag_row tagged `store` (row 7, seat_write_roots), byte-equal to the held
#   path and lying where it is rendered (its physical path is its rendered path), so a profile directory or a
#   `~/.omp/run` linked to the root, a seats root inside it, or the held row itself once a link has moved it, is a hit.
#   The first step of settings_judge for the dsh and router rows; the omp roles run it alone after their render, since
#   their grants contain their denies by design (the common directory over its `config` and `hooks`). Nothing to judge
#   without a root.
# @set judge_grant The first hit: `allowWrite row <path>` and, when it differs, its physical path in parentheses;
#   empty when every row is clear.
# @set judge_deny `the store root REGIME_STORE_ROOT <root>`; empty when clear.
# @exitcode 0 Every write row keeps clear of the root, the orchestrator's own row aside.
# @exitcode 1 A row hits; `judge_grant` and `judge_deny` name it.
store_root_judge() {
    local i n
    judge_grant='' judge_deny=''
    [[ -n ${store_root_phys} ]] || return 0
    n=${#write[@]}
    ((n)) || return 0
    physical_each "${write[@]}"
    phys_list+=("${store_root_phys}")
    identity_table "${phys_list[@]}"
    for ((i = 0; i < n; i++)); do
        within_ix "${n}" "${i}" || within_ix "${i}" "${n}" || continue
        row_tag allowWrite "${i}" "${write[i]}"
        if [[ ${tag_of} == store && ${phys_list[i]} == "${write[i]}" ]]; then continue; fi # lint-comparisons: allow a tag word, and one row's rendered and physical spellings from the same physical producers; the overlap was decided by identity above
        judge_grant="allowWrite row ${write[i]}"
        [[ ${phys_list[i]} == "${write[i]}" ]] || judge_grant+=" (${phys_list[i]})" # lint-comparisons: allow one row's rendered and physical spellings, both from physical producers, no decision rests on it
        judge_deny="the store root REGIME_STORE_ROOT ${store_root_phys}"
        return 1
    done
}

# @description Judge the rendered grants against the rendered denies (regime-cutover U272f): every row of the final
#   `allowRead` and `allowWrite` lists against every row of the final `denyRead` and `denyWrite` lists, and nothing
#   else is the boundary. Rounds 3 and 4 each judged a list of inputs (`DSH_HOME`, then the slot and the cwd too)
#   and each time a rendered grant was missing from that list (round 4: the profile root `~/.omp/profiles/dsh`,
#   linked to `~/.aws`, was granted write); the input list is gone and the lists seat_sandbox_write will write are
#   the judge's only source. Every row is resolved to its physical form first (physical_each, one subshell): a link
#   at the end of a rendered path hides its ancestry from the identity table, whose chains follow the spelled
#   parents. The decision is by identity for everything that exists, and by the absent components below one shared
#   deepest existing ancestor otherwise (identity_table, within_ix; one table, one stat). A grant that is, contains
#   or lies inside a deny is a hit unless the pair is structural: both rows carry the same tag, each tag naming its
#   one row by list and position (tag_row, regime-cutover U272g: the own cwd and state slot under the seats-root
#   denies and over the project-file denies, the own profile under the profiles deny), and the grant lies where it
#   is rendered (its physical path is its rendered path), so a tagged grant that a link moves elsewhere
#   (`~/.omp/profiles/dsh -> ~/.omp/profiles/orchestrator`) is judged like any row, and so is an untagged row of
#   an exempted row's spelling (`DSH_HOME=~/.omp/profiles/dsh`, `~/.omp/run -> ~/.omp/profiles`). The read grants
#   go first: they are spelled as rendered (the profile by its name), so the first hit names the row as the caller
#   knows it. The macOS write patterns are not rows (no grant of the role lies under the common directory).
#   The program store's root is judged first (store_root_judge, regime-cutover U219c): every allowWrite row against
#   the held root, the orchestrator's own tagged row excepted; the omp roles run that step alone after their render.
# @set judge_grant The first grant that hits: `<kind> row <path>` and, when it differs, its physical path in
#   parentheses; empty when every grant is clear.
# @set judge_deny The deny it hits: `<path>[ (<physical>)], a row of its <kind> list`; empty when clear.
# @exitcode 0 Every grant keeps clear of every deny it is not structurally paired with.
# @exitcode 1 A pair overlaps; `judge_grant` and `judge_deny` name it.
settings_judge() {
    local i j n m rows=() kinds=() ixs=() tags=()
    store_root_judge || return 1
    for ((i = 0; i < ${#allow_read[@]}; i++)); do rows+=("${allow_read[i]}") kinds+=(allowRead) ixs+=("${i}"); done
    for ((i = 0; i < ${#write[@]}; i++)); do rows+=("${write[i]}") kinds+=(allowWrite) ixs+=("${i}"); done
    n=${#rows[@]}
    for ((i = 0; i < ${#deny_read[@]}; i++)); do rows+=("${deny_read[i]}") kinds+=(denyRead) ixs+=("${i}"); done
    for ((i = 0; i < ${#deny_write[@]}; i++)); do rows+=("${deny_write[i]}") kinds+=(denyWrite) ixs+=("${i}"); done
    m=$((${#rows[@]} - n))
    judge_grant='' judge_deny=''
    ((n && m)) || return 0
    for ((i = 0; i < n + m; i++)); do
        row_tag "${kinds[i]}" "${ixs[i]}" "${rows[i]}"
        tags+=("${tag_of}")
    done
    physical_each "${rows[@]}"
    identity_table "${phys_list[@]}"
    for ((i = 0; i < n; i++)); do
        for ((j = n; j < n + m; j++)); do
            within_ix "${j}" "${i}" || within_ix "${i}" "${j}" || continue
            if [[ -n ${tags[i]} && ${tags[i]} == "${tags[j]}" && ${phys_list[i]} == "${rows[i]}" ]]; then continue; fi # lint-comparisons: allow two tag words, and one row's rendered and physical spellings from the same physical producers; the overlap was decided by identity above
            judge_grant="${kinds[i]} row ${rows[i]}"
            judge_deny=${rows[j]}
            # The same row in two spellings when the rendered one goes through a link; the reader needs both.
            [[ ${phys_list[i]} == "${rows[i]}" ]] || judge_grant+=" (${phys_list[i]})" # lint-comparisons: allow one row's rendered and physical spellings, both from physical producers, no decision rests on it
            [[ ${phys_list[j]} == "${rows[j]}" ]] || judge_deny+=" (${phys_list[j]})"  # lint-comparisons: allow one row's rendered and physical spellings, both from physical producers, no decision rests on it
            judge_deny+=", a row of its ${kinds[j]} list"
            return 1
        done
    done
}

# @description Refuse (exit 2) unless the final `allowWrite` list of one seat keeps clear of every protected path
#   (regime-cutover U85), one invariant instead of a list of cases: for every granted root R and every protected
#   path P, R must not be or contain P, and R must not lie inside P. The protected paths are defined once: the main
#   checkout, the seats root, its `.sandbox`, every other seat directory under the seats root, every other
#   worktree of this repository and the operator's Claude Code state (operator_claude_paths, regime-cutover U190b: a
#   `HCOM_DIR=~/.claude` or `--seats-root ~/.claude/seats` would grant that state whole); the seat's own directory
#   (same identity) is not protected for it. Exempt by
#   construction, not by comparing text: the seat's own slots under the seats root (the first two roots: a worker's
#   `<seats-root>/<name>`, and `<seats-root>/.state/<name>`) against the seats root and its `.sandbox`, and the git
#   common directory named `.git` whose parent is the main checkout (identity). A linked worktree inside R (Claude
#   Code keeps its worktrees under `<checkout>/.claude/worktrees`) refuses, present or absent, naming the worktree
#   and `git worktree move`, `remove` or `prune` (regime-cutover U95, operator decision U95-nested-refuse-decided:
#   a seat could rewrite its `.git` file and tracked files, which host git and host tools read). Containment is
#   decided by identity for everything that exists, and below one shared deepest existing ancestor by the absent
#   components (identity_table, within_ix), one table for every pair. Every path must be clean (clean_path) before
#   anything is created, so this runs in a dry run too.
# @arg $1 string The role.
# @arg $2 string The seat directory, physical.
# @arg $@ string The seat's allowWrite roots after them, physical, its own slots first (seat_write_roots).
seat_overlap_check() {
    local own_role=$1 own_dir=$2 r p i j k nroots seats_phys labels=() protected=() own=() roots=() seat_dirs=()
    shift 2
    roots=("$@")
    nroots=$#
    seats_phys=$(physical_path "${seats_root}") || refuse "cannot resolve the seats root ${seats_root}"
    labels+=("the main checkout" "the seats root" "the seats' sandbox directory")
    protected+=("${checkout}" "${seats_phys}" "${seats_phys}/.sandbox")
    # Every directory in the seats root, dot names included (dir_entries); `.state` and `.sandbox` are protected or
    # exempt by their own rules above. All resolved in one batch (physical_paths), so more seats start no process.
    dir_entries "${seats_phys}"
    seat_dirs=()
    for p in ${dir_list[@]+"${dir_list[@]}"}; do
        [[ -d ${p} ]] || continue
        case ${p##*/} in .state | .sandbox) continue ;; esac
        seat_dirs+=("${p}")
    done
    physical_paths ${seat_dirs[@]+"${seat_dirs[@]}"}
    ((${#phys_list[@]} == ${#seat_dirs[@]})) ||
        refuse "the seat directories in ${seats_phys} were not all resolved (${#phys_list[@]} of ${#seat_dirs[@]})"
    for p in ${phys_list[@]+"${phys_list[@]}"}; do
        labels+=("the seat directory")
        protected+=("${p}")
    done
    # One resolved path per linked worktree git records (physical_paths), or the check below could miss one.
    ((${#worktree_phys[@]} == ${#worktree_paths[@]} - 1)) ||
        refuse "the worktrees of ${repo} were not all resolved (${#worktree_phys[@]} of $((${#worktree_paths[@]} - 1)))"
    for p in ${worktree_phys[@]+"${worktree_phys[@]}"}; do
        labels+=("the worktree")
        protected+=("${p}")
    done
    operator_claude_paths
    for ((i = 0; i < ${#operator_claude[@]}; i++)); do
        labels+=("${operator_claude_labels[i]}")
        protected+=("${operator_claude[i]}")
    done
    for p in "${protected[@]}"; do
        require_clean_path 'a protected seat path' "${p}"
        # The seat's own directory is its to write.
        if [[ -e ${p} && ${p} -ef ${own_dir} ]]; then own+=(1); else own+=(0); fi
    done
    ((${#own[@]} == ${#protected[@]})) || refuse "the overlap table of the ${own_role} seat does not hold one entry per protected path"
    for r in "${roots[@]}"; do
        require_clean_path "a write root of the ${own_role} seat" "${r}"
    done
    identity_table "${roots[@]}" "${protected[@]}"
    for ((k = 0; k < nroots; k++)); do
        r=${roots[k]}
        for ((i = 0; i < ${#protected[@]}; i++)); do
            ((! own[i])) || continue
            # Its own slots under the seats root sit there by construction, as siblings of `.sandbox`: the state
            # directory of every seat, and a worker's directory (the orchestrator's is the launch checkout, checked);
            # so does the shared Claude Code directory, root 2 of every role, inside `.state` (U318).
            # own_slots_check has proved, before this runs, that they are what they claim (no link, right parent).
            if [[ (${k} == 1 || (${k} == 0 && ${own_role} != orchestrator)) && (${i} == 1 || ${i} == 2) ]]; then continue; fi
            if [[ ${k} == 2 && ${i} == 1 ]]; then continue; fi
            p=${protected[i]}
            j=$((nroots + i))
            if within_ix "${k}" "${j}"; then
                if [[ ${labels[i]} == 'the worktree' ]]; then # lint-comparisons: allow a fixed label, no path compare
                    refuse "the worktree ${p} lies inside the ${own_role} seat's write root ${r}, where the seat could rewrite its .git file and tracked files; move it out (\`git worktree move ${p} <a path outside>\`), remove it (\`git worktree remove ${p}\`), or prune it if its directory is gone (\`git worktree prune\`)"
                fi
                refuse "the ${own_role} seat's write root ${r} contains ${labels[i]} ${p}; seat write roots must not overlap (choose another --seats-root, HCOM_DIR or git directory)"
            fi
            if within_ix "${j}" "${k}"; then
                # The main checkout's own `.git`, by identity of the common directory and its parent.
                if ((i == 0)) && [[ -e ${r} && ${r} -ef ${common} && -d ${checkout}/.git && ! -L ${checkout}/.git && ${checkout}/.git -ef ${r} ]]; then continue; fi
                refuse "the ${own_role} seat's write root ${r} lies inside ${labels[i]} ${p}; seat write roots must not overlap (choose another --seats-root, HCOM_DIR or git directory)"
            fi
        done
    done
}

# @description Write the seat's srt settings (the lists seat_settings_render rendered) and its shim under
#   `<seats-root>/.sandbox/<name>` (regime-cutover U85), afresh on every launch, after the seat directory exists.
#   The shim runs a canary under those settings first, a write into the sandbox directory, reads of the settings
#   file and `~/.ssh`, and a write under the operator's `~/.claude/debug`, and refuses (exit 2) unless all four fail
#   inside; only then does it run the seat's command under srt, both by the physical argv `pin_exec` checked.
# @noargs
seat_sandbox_write() {
    local sandbox_real path settings shim json origin_url push_url srt_q cmd_q
    local write_json deny_write_json deny_read_json allow_read_json
    # srt on Linux grants writes only to paths that exist, so omp's own state directories are made first. The seat's
    # slots under the seats root were proved free of links (own_slots_check); they are made one component at a time,
    # and each is checked again to be a real directory.
    (umask 077 && mkdir -p "${seats_root}" "${HOME}/.omp/profiles/${omp_profile}" "${HOME}/.omp/run") ||
        refuse "cannot create the seats root ${seats_root} or omp's state directories"
    # The row's state root (U321b, U321c, U321d): held by state_root_hold from the held physical DSH_HOME and made by
    # state_root_make after the home's deny judgement, it is the held physical path the settings carry, whatever stands
    # at the spelled path now. Gone since, or no longer a real directory of this user, the launch refuses by name
    # before the settings are written; nothing is derived from the path.
    if [[ -n ${state_root_phys} ]]; then
        [[ -d ${state_root_phys} && ! -L ${state_root_phys} && -O ${state_root_phys} ]] ||
            refuse "the ${role} role's state root ${state_root_phys} is not a real directory of this user"
    fi
    # The credential root (U353, U353d): every role's must be the real directory of this user cred_root_make left, so
    # the deny or the grant that names it names a directory that exists when srt reads the settings.
    [[ -d ${cred_root_phys} && ! -L ${cred_root_phys} && -O ${cred_root_phys} ]] ||
        refuse "the ${role} role's credential root ${cred_root_phys} is not a real directory of this user"
    for path in "${seats_root}/.state" "${claude_config}" "${seats_root}/.state/${name}" \
        ${scratch_dir:+"${scratch_dir}"} "${seats_root}/.sandbox" "${sandbox}" "${sandbox}/bin"; do
        if [[ ! -e ${path} && ! -L ${path} ]]; then
            # Two launches at once (the dsh role's normal case) may both find a shared parent absent; the loser of
            # the mkdir race takes the directory the winner made, held to a real directory by the check below.
            (umask 077 && /bin/mkdir "${path}") || [[ -d ${path} && ! -L ${path} ]] || refuse "cannot create ${path}"
        fi
        [[ -d ${path} && ! -L ${path} ]] || refuse "${path} is not a real directory"
    done
    sandbox_real=$(cd "${sandbox}" && pwd -P) || refuse "cannot resolve the seat sandbox directory ${sandbox}"
    settings=${sandbox_real}/srt-settings.json
    write_json=$(json_paths 'a seat write root' "${write[@]}") || exit 2
    deny_write_json=$(json_paths 'a seat write deny' "${deny_write[@]}") || exit 2
    deny_write_json=${deny_write_json%]}${deny_write_patterns}]
    deny_read_json=$(json_paths 'a seat read deny' "${deny_read[@]}") || exit 2
    allow_read_json=$(json_paths 'a seat read root' "${allow_read[@]}") || exit 2
    # No unix socket for any seat: the herdr socket would let a seat open a pane outside every sandbox. Local binding
    # is the role table's `allow_local_binding` cell: false for every role but the router, whose Runtime needs its
    # loopback listener (U321); srt 0.0.81 grants it as bind and inbound on `*:*` (every interface), and the upstream
    # host check bounds what that listener answers. The one listener an omp seat runs, the hcom plugin's notify
    # server, falls back to polling every 5 s when its bind fails (hcom.ts `startNotifyServer`,
    # `FALLBACK_PENDING_POLL_MS`). The settings are written by the shell from clean paths only (json_paths), so no JSON
    # tool runs and none is needed on macOS.
    domains='"github.com","api.github.com","uploads.github.com","codeload.github.com","objects.githubusercontent.com"'
    domains+=',"raw.githubusercontent.com","release-assets.githubusercontent.com","pypi.org","files.pythonhosted.org"'
    domains+=',"api.anthropic.com","claude.ai","platform.claude.com","console.anthropic.com"'
    domains+=',"chatgpt.com","auth.openai.com","api.openai.com"'
    json="{\"network\":{\"allowedDomains\":[${domains}],\"deniedDomains\":[],\"allowUnixSockets\":[]"
    json+=",\"allowMachLookup\":[\"com.apple.trustd.agent\"],\"allowLocalBinding\":${allow_local_binding}}"
    json+=",\"filesystem\":{\"denyRead\":${deny_read_json},\"allowRead\":${allow_read_json}"
    json+=",\"allowWrite\":${write_json},\"denyWrite\":${deny_write_json}},\"allowPty\":true${linux_tools}}"
    if ! printf '%s\n' "${json}" > "${settings}.tmp" || ! mv -f "${settings}.tmp" "${settings}"; then
        refuse "cannot write ${settings}"
    fi
    # ~/.ssh is unreadable inside, so the seat pushes over HTTPS through the gh credential helper: an explicit
    # pushurl wins over a global `url.<ssh>.pushInsteadOf` rewrite. An origin that is neither HTTPS nor
    # git@github.com gets no override, and an SSH push from the seat fails.
    origin_url=$(git -C "${repo}" config --get remote.origin.url) || {
        (($? == 1)) || refuse "cannot read remote.origin.url in ${repo}"
        origin_url=''

# @description Write `<sandbox>/bin/$1`, a wrapper that execs the given physical argv with its own arguments.
# @arg $1 string The command name.
# @arg $@ string The physical argv after the name.
seat_wrapper_write() {
    local tool=$1 argv_q
    shift
    printf -v argv_q '%q ' "$@"
    printf '#!/bin/bash\n# Generated by hcom-seat (regime-cutover U85): %s by its checked physical argv.\nexec %s"$@"\n' \
        "${tool}" "${argv_q}" > "${sandbox}/bin/${tool}.tmp" || refuse "cannot write ${sandbox}/bin/${tool}.tmp"
    if ! chmod 700 "${sandbox}/bin/${tool}.tmp" || ! mv -f "${sandbox}/bin/${tool}.tmp" "${sandbox}/bin/${tool}"; then
        refuse "cannot install ${sandbox}/bin/${tool}"
    fi
}

# @description Make sure the hcom store `HCOM_DIR` is a real directory before anything else is created (regime-cutover
#   U85): it is already clean (require_clean_path) and clear of every protected root by the identity of its deepest
#   existing ancestor (seat_overlap_check, a write root of every seat). An existing store must be a directory and no
#   symbolic link. A missing one is made 0700 one component at a time below its deepest existing ancestor, which must
#   be a real directory, not a symbolic link; each made component is checked again. A dry run creates nothing and
#   says what it would make.
# @arg $1 int 1 for a dry run.
hcom_store_ensure() {
    local top=${HCOM_DIR} rest=() path part
    if [[ -e ${HCOM_DIR} || -L ${HCOM_DIR} ]]; then
        [[ -d ${HCOM_DIR} && ! -L ${HCOM_DIR} ]] || refuse "the hcom store ${HCOM_DIR} is not a real directory"
        return 0
    fi
    while [[ ! -e ${top} && ! -L ${top} ]]; do
        # bash 3.2 reads an empty array as unset under `set -u`, so the expansion is guarded.
        rest=("${top##*/}" ${rest[@]+"${rest[@]}"})
        top=${top%/*}
        [[ -n ${top} ]] || top=/
    done
    [[ -d ${top} && ! -L ${top} ]] ||
        refuse "the hcom store ${HCOM_DIR} would be made under ${top}, which is not a real directory (a symbolic link or a file)"
    if (($1)); then
        echo "hcom-seat: the hcom store ${HCOM_DIR} does not exist; a launch creates it (0700)" >&2
        return 0
    fi
    path=${top%/}
    for part in "${rest[@]}"; do
        path=${path}/${part}
        (umask 077 && /bin/mkdir "${path}") || refuse "cannot create the hcom store ${path}"
        [[ -d ${path} && ! -L ${path} ]] || refuse "${path} is not a real directory"
    done
}

# @description Set `slot_present` to 1 when the path `$1` exists (a symbolic link counted by itself, not by its target)
#   and to 0 when it is absent, from one `/usr/bin/stat` whose status and message are read (regime-cutover U272g,
#   standing order 21): `[[ -e ]]` and `[[ -L ]]` are false for an absent path and for one whose parent cannot be
#   searched alike, so a `.state` of mode 000 made the cleanup read its slot as gone and the launch exit 0 with the
#   slot behind (verdict U272f P2). Only the documented "No such file or directory" (ENOENT) is an absence; every
#   other failure (EACCES, ENOTDIR, EPERM, a stat that cannot run) refuses (exit 2) naming the path and the message.
# @arg $1 string An absolute path.
# @set slot_present 1 or 0.
path_presence() {
    local err
    if err=$(/usr/bin/stat "${lstat_args[@]}" -- "$1" 2>&1 > /dev/null); then
        slot_present=1
        return 0
    fi
    slot_present=0
    case ${err} in
    *'No such file or directory'*) return 0 ;;
    esac
    refuse "cannot read whether the per-launch slot $1 exists (${err}); it may remain: restore the mode of its parent and remove it by hand"
}
# @description Remove the dsh role's per-launch slots, the sandbox and the state slot (regime-cutover U272): both were
#   absent before this launch and made by it (seat_sandbox_write), and neither chmod nor rm follows a link inside
#   them. A directory dsh left without its owner's read or write bit (mode 000) keeps rm out, so the mode is reset
#   first (U272d's finding); the removal fails closed: a slot that remains is named and the function fails, so the
#   launch never ends 0 with a slot behind (regime-cutover U272e). Each existence read is path_presence, so a slot
#   that cannot be read is a refusal, never an absence (regime-cutover U272g). The normal exit and the signal trap
#   run this one function.
# @exitcode 0 Both slots are gone.
# @exitcode 1 A slot remains, named on stderr.
slots_remove() {
    local path remaining=()
    for path in "${sandbox}" "${seats_root%/}/.state/${name}"; do
        path_presence "${path}"
        ((slot_present)) || continue
        # Links in the tree are not followed (the traversal default of both chmods); a failure here shows below. No
        # `--`: BSD chmod reads everything after the mode as a file. The paths are absolute.
        /bin/chmod -R u+rwX "${path}" || :
        /bin/rm -rf -- "${path}" || :
        path_presence "${path}"
        ((! slot_present)) || remaining+=("${path}")
    done
    ((${#remaining[@]} == 0)) || {
        echo "hcom-seat: the per-launch slot ${remaining[*]} remains after its removal (chmod -R u+rwX, rm -rf); remove it by hand" >&2
        return 1
    }
}
# @description The dsh role's signal trap (regime-cutover U272d): a hangup, interrupt or termination removes the slots
#   and then ends this process by the same signal, its disposition restored, so the caller's status names the
#   signal. bash runs the trap once the foreground child (the shim, srt, dsh) has ended; a signal to the process
#   group, a terminal hangup included, ends the child first. The subshell the child runs in resets the trapped
#   signals to their defaults, so dsh keeps its own disposition. The removal's status is read (regime-cutover U272f):
#   under `set -e` a failed removal ended the handler before the signal was restored, and the launch exited 1 with
#   the slot behind; a slot that remains is named (slots_remove) and the exit is 2 whatever the signal, as on the
#   normal exit, so the caller never reads a leftover slot as the signal's own status.
# @arg $1 string The signal name.
foreground_signal() {
    local removed=0
    trap - HUP INT TERM
    helper_copy_remove
    slots_remove || removed=$?
    ((removed == 0)) || {
        echo "hcom-seat: ended by SIG$1; the launch exits 2 because a per-launch slot remains" >&2
        exit 2
    }
    kill -s "$1" $$
    exit 2
}
