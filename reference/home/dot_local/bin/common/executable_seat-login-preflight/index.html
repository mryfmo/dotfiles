# @file seat-login-preflight
# @brief Report each omp seat profile's login on this host, and before a seat starts on a remote host, get its route logged in.
# @description
#   regime-cutover U37 (docs/remote-host-logins.md). A seat's model route is the provider of
#   `modelRoles.default` in its deployed overlay `~/.agents/omp/profiles/<profile>.yml`: `openai-siwc`
#   (SIWC, the audit side) or `claude-bridge` (the Claude Code child). A login is per host, so a seat on
#   the Ubuntu host reached through `herdr --remote` needs that host's own login, and the browser for it
#   is on the laptop.
#
#   `--check [<profile>...]` prints one line per profile (all overlays when none is named) from metadata
#   only, never a token: SIWC is `registration.json` (host id and issued client id, which carry no token),
#   held to the extension's record schema (one JSON document), plus the mtime of the profile's `agent.db`; Claude is
#   the one claude.ai login of the profile's login group directory `<seats-root>/.state/claude-<group>` (regime-cutover
#   U318, per group since U498: the group is the one table `login_group_of_role`, copied as text from hcom-seat, the
#   worker, orchestrator and audit roles each their own group and the dsh and router roles the `router` group, so every
#   seat's bridge child and the dsh gateway child run under their group's directory as `CLAUDE_CONFIG_DIR`), read by
#   one call, `CLAUDE_CONFIG_DIR=<dir> claude auth status`, whose exit status and JSON `authMethod` decide (`login
#   present (claude.ai, <dir>)`, else absent naming the method or the missing directory); the line prints the directory
#   and the method, never a credential. A profile with a seat login route (SIWC included) outside the table refuses
#   the lever (exit 2) naming the profile, the route and the table, never a line (regime-cutover U498b). A record that
#   exists but cannot be read or breaks its schema, and a producer (`uname`, `stat`, `date`, `claude`, `jq`) that
#   fails, are reported as unreadable, never as absent, and make the exit status 1.
#
#   `<profile>` (a seat profile of the manifest's `omp.roles`: orchestrator, worker or audit; `hcom-seat`
#   calls it with the seat's role before it creates or starts anything) checks that a seat can use the login,
#   which is more than `--check` shows. For the openai-siwc route a local host keeps its own browser and login,
#   so nothing happens there; on a remote host (`SSH_CONNECTION` set, or a Linux host without a display, which a
#   herdr pane on the seat host can be even when its server did not inherit `SSH_CONNECTION`) SIWC needs an
#   active `openai-siwc` login in `agent.db`, counted by the extension's `src/credentials.ts` without reading a
#   token: the issued client is saved before the token exchange, so a record proves only that a sign-in began.
#   The Claude route is checked on every host (regime-cutover U190b), local included, since the seat's child logs
#   in by its group directory's login wherever it runs: it needs `authMethod` `claude.ai` there (an `oauth_token` or
#   `api_key` method, an exit 1 of `claude auth status` or an absent directory counts as absent; the operator's
#   `~/.claude`, the Keychain item of the default directory and a variable in this environment are no input, regime-
#   cutover U312, U318). An absent login is logged in here only in the operator's own terminal (stdin and stdout a
#   TTY, not inside a seat): SIWC through `omp --profile <profile> login openai-siwc` with
#   `OPENAI_SIWC_CALLBACK_PORT=1455`, which the `seat-host` SSH entry forwards back from the laptop, and
#   `xdg-open`/`open` pointed at `regime-open-url` for that command only. Claude has no login to run here: the
#   operator's one step per group is the printed command `CLAUDE_CONFIG_DIR=<dir> claude auth login` (with
#   `BROWSER=regime-open-url` in an SSH session, where the page shows a code to paste at the prompt,
#   docs/remote-host-logins.md), shell-quoted so a seats root with a space pastes whole, which Claude Code stores under
#   that directory and refreshes itself; when the legacy shared directory `.state/claude` (U318) exists and the group's
#   directory did not before this run, the refusal names it as the directory the operator may remove once every
#   running group is logged in (the kit reads, copies and removes no login, standing order 54). Both modes hold the
#   seats root, its `.state` and `claude-<group>` to real directories of this user (a link, a file or another user's
#   directory refuses, exit 2, naming the component), on one normalised spelling of the root (no empty, `.` or `..`
#   component, no trailing slash; regime-cutover U318c: `<link>//` made `-L` follow the link) and only under a parent
#   this user can search (a component that cannot be judged refuses naming it, never reads as absent); the profile mode
#   makes the chain 0700 first when absent, as hcom-seat does at a launch, so the login lands in a directory this kit
#   made. The consent click is the human step. Anywhere else (a seat, a script) it prints the command and refuses,
#   since a login is the operator's step (standing order 4).
# @arg $1 string `--check`, or the profile.
# @arg $@ string With `--check`: profile names (default: every deployed overlay).
# @env SSH_CONNECTION Set by sshd: this host is remote to the operator's terminal.
# @env DISPLAY With WAYLAND_DISPLAY: a Linux host with neither has no local browser, so it counts as remote.
# @env HCOM_LAUNCHED Set by hcom inside a seat: never run a login there.
# @env REGIME_SEATS_ROOT The seats root whose `.state/claude-<group>` directories are the login groups' Claude Code
#   directories (hcom-seat passes its resolved one), an absolute path judged on its normalised spelling; unset,
#   `~/.local/state/omp-seats/<slug>` of the checkout this runs in (regime-env's slug).
# @stdout With `--check`: one line per profile.
# @stderr The profile mode's report and refusals.
# @exitcode 0 Checked, or the profile's route is usable (or the host is local and the route is openai-siwc).
# @exitcode 1 A record or producer is unreadable, or a login ran and the route is still not usable.
# @exitcode 2 A usage error, a deployed profile with a seat login route outside the login group table (U498b), a
#   component of the login group's Claude Code directory path that is a link, a file or another user's directory or
#   that cannot be judged (a parent this user cannot search), a failed read of the operator's login command, or a seat
#   without a login outside the operator's terminal (a remote host, or any host on the claude-bridge route, whose login
#   is the operator's printed command).
# @example
#   seat-login-preflight --check
#   seat-login-preflight audit

# @description Refuse to run unless this file's sha256 equals its pin in the manifest beside it (regime-cutover U31):
#   `~/.agents/agent-config.yaml` for the installed copy under ~/.local/bin/common, which a sandboxed session cannot
#   write, else the checkout's home/dot_agents/agent-config.yaml. Every read is checked; a failure exits 2 naming the
#   file. The pin is the `claude.levers.sha256.<name>` line, which `scripts/generate-agent-configs.py` refreshes.
# @set LEVER_MANIFEST The manifest the pin came from.
lever_self_check() {
    local src dir self name pin digest home
    # The directory is split from the path in the shell, so no external producer (dirname) can fail unseen.
    src=${BASH_SOURCE[0]}
    case ${src} in
    */*) dir=${src%/*} ;;
    *) dir=. ;;
    esac
    [[ -n ${dir} ]] || dir=/
    dir=$(cd "${dir}" && pwd -P) || {
        echo "${src##*/}: refused: cannot resolve the script directory of ${src}" >&2
        exit 2
    }
    self=${dir}/${BASH_SOURCE[0]##*/}
    # shellcheck disable=SC2034 # read by the sourced regime-env helper's caller below
    LEVER_DIR=${dir}
    name=${self##*/}
    home=$(cd "${HOME}" 2> /dev/null && pwd -P) || home=''
    if [[ -n ${home} && ${dir} == "${home}/.local/bin/common" ]]; then # lint-comparisons: allow both sides are pwd -P forms
        LEVER_MANIFEST=${HOME}/.agents/agent-config.yaml
    else
        LEVER_MANIFEST=${dir}/../../home/dot_agents/agent-config.yaml
    fi
    [[ -r ${LEVER_MANIFEST} ]] || {
        echo "${name}: refused: manifest unreadable: ${LEVER_MANIFEST}" >&2
        exit 2
    }
    pin=$(sed -n -E "s/^      ${name//./\\.}: ([0-9a-f]{64})\$/\\1/p" "${LEVER_MANIFEST}") || {
        echo "${name}: refused: cannot read ${LEVER_MANIFEST}" >&2
        exit 2
    }
    [[ ${pin} =~ ^[0-9a-f]{64}$ ]] || {
        echo "${name}: refused: no single sha256 pin for ${name} in ${LEVER_MANIFEST}" >&2
        exit 2
    }
    if command -v sha256sum > /dev/null; then
        digest=$(sha256sum < "${self}") || digest=''
    else
        digest=$(shasum -a 256 < "${self}") || digest=''
    fi
    digest=${digest%% *}
    [[ ${digest} =~ ^[0-9a-f]{64}$ ]] || {
        echo "${name}: refused: cannot hash ${self}" >&2
        exit 2
    }
    [[ ${digest} == "${pin}" ]] || {
        echo "${name}: refused: sha256 ${digest} of ${self} differs from the pin in ${LEVER_MANIFEST}" >&2
        exit 2
    }
}

# openai-siwc `src/store.ts`: `JSON.parse` of the whole file, so exactly one top-level document (jq reads a stream, so
# `-s` gathers every document and the filter requires one), then `isRegistration`, with the issued client id held to
# the charset `src/seed.ts` accepts, so nothing else reaches the terminal. \A and \z anchor the whole string.
# shellcheck disable=SC2016 # jq source, not shell
registration_filter='
if length != 1 then error("not exactly one JSON document")
else .[0]
    | if type == "object"
        and (.hostId | type == "string"
            and test("\\Aurn:uuid:[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}\\z"))
        and ((has("clientId") | not) or (.clientId | type == "string" and test("\\A[A-Za-z0-9_.:-]{1,200}\\z")))
        and ((has("accountId") | not) or (.accountId | type == "string" and length > 0))
    then [.hostId, (.clientId // "")] | @tsv
    else error("not a registration record")
    end
end'

end'

# @description Print a file's mtime in UTC; GNU and BSD `date -r <file>` agree on this form.
# @arg $1 path File.
# @exitcode 2 `date` failed or printed nothing.
stamp() {
    local value
    value=$(date -u -r "$1" +%Y-%m-%dT%H:%M:%SZ) || return 2
    [[ -n ${value} ]] || return 2
    printf '%s\n' "${value}"
}

# @description Print a file's permission bits in octal.
# @arg $1 path File.
# @exitcode 2 `stat` failed or printed no mode.
mode_of() {
    local value
    if [[ ${os} == Darwin ]]; then
        value=$(stat -f %Lp "$1") || return 2
    else
        value=$(stat -c %a "$1") || return 2
    fi
    [[ ${value} =~ ^[0-7]{3,4}$ ]] || return 2
    printf '%s\n' "${value}"
}

# @description Print the provider of a profile's `modelRoles.default` (openai-siwc, claude-bridge, ...).
# @arg $1 string Profile name.
# @exitcode 2 The overlay exists but cannot be read.
# @exitcode 3 The overlay is absent or names no default model with a provider.
route_of() {
    local overlay=${profiles_dir}/$1.yml model
    [[ -f ${overlay} ]] || return 3
    model=$(awk '/^modelRoles:/ { in_roles = 1; next } /^[^ ]/ { in_roles = 0 } in_roles && $1 == "default:" { print $2; exit }' "${overlay}") || return 2
    # A model id without a provider prefix leaves the prefix strip unchanged.
    [[ -n ${model} && ${model%%/*} != "${model}" ]] || return 3
    printf '%s\n' "${model%%/*}"
}

# @description Print the SIWC login line of a profile.
# @arg $1 string Profile name.
# @arg $2 int 1 to also require an active login in agent.db (launch readiness), else metadata only.
# @exitcode 0 Registered with an issued client and an agent.db (and, with $2=1, a login in it). 1 Absent. 2 Unreadable.
siwc_state() {
    local profile=$1 ready=${2:-0} agent reg fields host client db mtime count
    agent=${HOME}/.omp/profiles/${profile}/agent
    reg=${agent}/openai-siwc/registration.json
    db=${agent}/agent.db
    if [[ ! -e ${reg} ]]; then
        printf 'absent (no %s)\n' "${reg}"
        return 1
    fi
    if ! command -v jq > /dev/null; then
        printf 'unreadable (no jq on PATH to read %s)\n' "${reg}"
        return 2
    fi
    if ! fields=$(jq -ers "${registration_filter}" "${reg}" 2> /dev/null); then
        printf 'unreadable (%s)\n' "${reg}"
        return 2
    fi
    IFS=$'\t' read -r host client <<< "${fields}"
    if [[ -z ${client} ]]; then
        printf 'absent (registration started, no issued client yet: host %s)\n' "${host}"
        return 1
    fi
    if [[ ! -f ${db} ]]; then
        printf 'absent (registered: host %s, client %s; no %s)\n' "${host}" "${client}" "${db}"
        return 1
    fi
    if ! mtime=$(stamp "${db}"); then
        printf 'unreadable (cannot read the mtime of %s)\n' "${db}"
        return 2
    fi
    if ((ready)); then
        if ! count=$(bun "${siwc_ext}/src/credentials.ts" --profile "${profile}") || [[ ! ${count} =~ ^[0-9]+$ ]]; then
            printf 'unreadable (cannot count the openai-siwc logins in %s)\n' "${db}"
            return 2
        fi
        if ((count == 0)); then
            printf 'absent (registered: host %s, client %s; no openai-siwc login in %s)\n' "${host}" "${client}" "${db}"
            return 1
        fi
    fi
    printf 'registered (host %s, client %s), agent.db mtime %s\n' "${host}" "${client}" "${mtime}"
}

# @description Set `claude_seats_root` to the one spelling of the absolute path `$1` (regime-cutover U318c): every
#   run of `/` is one `/`, a `.` component is dropped, a `..` component takes the component before it (none at the
#   root), and no `/` ends it (a bare `/` stays `/`). Lexical, by parameter expansion alone: `realpath` or `pwd -P`
#   would follow the link the component tests must catch, and `${root%/}` stripped one slash, so `<link>//` kept a
#   trailing slash that made `-L` follow the link.
# @arg $1 string An absolute path.
# @set claude_seats_root The normalised spelling.
seats_root_normalise() {
    local rest=$1 part n
    local -a parts=()
    while [[ -n ${rest} ]]; do
        part=${rest%%/*}
        if [[ ${rest} == */* ]]; then rest=${rest#*/}; else rest=''; fi # lint-comparisons: allow a split of one path into its components, no path compare
        case ${part} in
        '' | .) ;;
        ..)
            n=${#parts[@]}
            ((n == 0)) || unset "parts[n - 1]"
            ;;
        *) parts+=("${part}") ;;
        esac
    done
    claude_seats_root=''
    for part in ${parts[@]+"${parts[@]}"}; do
        claude_seats_root+=/${part}
    done
    [[ -n ${claude_seats_root} ]] || claude_seats_root=/
}

# @description Print the login group of the role `$1` (regime-cutover U498): the one table both this lever and
#   hcom-seat hold as the same text (each lever's tests assert the table and their equality). Every seat
#   of a role shares its group's Claude Code directory `<seats-root>/.state/claude-<group>` and no other group's:
#   the omp roles worker, orchestrator and audit are each their own group; the dsh and router roles are the `router`
#   group, since the dsh gateway child is the Router's. Any other name is no role of the table (status 1, nothing
#   printed), so a caller that reads the status refuses instead of deriving a directory.
# @arg $1 string The role.
# @stdout The group.
# @exitcode 1 The role is not in the table.
login_group_of_role() {
    case $1 in
    worker) printf 'worker\n' ;;
    orchestrator) printf 'orchestrator\n' ;;
    audit) printf 'audit\n' ;;
    dsh | router) printf 'router\n' ;;
    *) return 1 ;;
    esac
}

# @description Set `claude_config` to the Claude Code directory of the profile `$1`'s login group under this host's
#   seats root, `<seats-root>/.state/claude-<group>` (regime-cutover U318, per group since U498; hcom-seat's
#   `claude_config` row, the group from the one table login_group_of_role), `claude_legacy` to the legacy shared
#   directory `<seats-root>/.state/claude` (U318; named, never read or made) and `claude_seats_root` to that root:
#   `REGIME_SEATS_ROOT` when set (hcom-seat passes its resolved one; it must be absolute), else
#   `~/.local/state/omp-seats/<slug>` of the checkout this runs in (regime-env's toplevel and slug readers; the store
#   binding is hcom-seat's concern), with HOME in `pwd -P` form. Either form is normalised to one spelling
#   (seats_root_normalise) before any test reads it, so every component test and every printed path use that spelling.
#   A failure sets `claude_config_error` and returns 2.
# @arg $1 string The profile (a role of the table).
# @set claude_config The directory.
# @set claude_legacy The legacy shared directory.
# @set claude_seats_root The seats root, normalised.
# @set claude_config_error The reason, when none can be derived.
# @exitcode 2 No seats root can be derived, REGIME_SEATS_ROOT is not an absolute path, or the profile is outside the
#   login group table.
claude_config_dir() {
    local root=${REGIME_SEATS_ROOT:-} top slug home group
    claude_config='' claude_legacy='' claude_seats_root='' claude_config_error=''
    if ! group=$(login_group_of_role "$1"); then
        claude_config_error="no login group for the profile $1; the table names orchestrator, worker, audit, dsh and router"
        return 2
    fi
    if [[ -z ${root} ]]; then
        if ! top=$(regime_toplevel); then
            claude_config_error='no seats root: set REGIME_SEATS_ROOT or run inside a checkout'
            return 2
        fi
        if ! slug=$(regime_slug "${top}"); then
            claude_config_error="no seats root: cannot derive a repository slug from ${top}"
            return 2
        fi
        if ! home=$(cd "${HOME}" && pwd -P); then
            claude_config_error="no seats root: cannot resolve HOME ${HOME}"
            return 2
        fi
        root=${home}/.local/state/omp-seats/${slug}
    fi
    if [[ ${root} != /* ]]; then # lint-comparisons: allow an absolute-path test on one path, no path compare
        claude_config_error="no seats root: REGIME_SEATS_ROOT ${root} is not an absolute path"
        return 2
    fi
    seats_root_normalise "${root}"
    claude_config=${claude_seats_root%/}/.state/claude-${group}
    claude_legacy=${claude_seats_root%/}/.state/claude
}

# @description Set `claude_legacy_note` for the profile mode's refusal (regime-cutover U498): when the legacy shared
#   directory `claude_legacy` (U318) is a real directory and the group's directory `claude_config` does not exist yet,
#   the note names the legacy directory as the one the operator may remove once every running group is logged in;
#   otherwise the note is empty. Called after claude_config_dir and before claude_config_ensure makes the group's
#   directory, by `-d` and `-L` alone: nothing under either directory is read, copied or removed (standing order 54).
# @set claude_legacy_note The note, or empty.
legacy_note_hold() {
    claude_legacy_note=''
    if [[ -d ${claude_legacy} && ! -L ${claude_legacy} && ! -e ${claude_config} && ! -L ${claude_config} ]]; then
        claude_legacy_note="; the legacy shared directory ${claude_legacy} (one login per seats root, U318) is read by no seat: remove it once every running group is logged in"
    fi
}

# @description Print the operator's one Claude step for the group: `CLAUDE_CONFIG_DIR=<dir> claude auth login`, after
#   `BROWSER=regime-open-url` in an SSH session, where the laptop's browser opens the page and shows a code to paste at
#   the prompt (docs/remote-host-logins.md). The directory is shell-quoted (`%q`), so a seats root holding a space, a
#   quote or a `$` pastes as one assignment of the same directory (regime-cutover U318b).
# @stdout The command, one line.
claude_login_command() {
    local browser=''
    [[ -z ${SSH_CONNECTION:-} ]] || browser='BROWSER=regime-open-url '
    printf '%sCLAUDE_CONFIG_DIR=%q claude auth login\n' "${browser}" "${claude_config}"
}

# @description Refuse the Claude route's absent login after its state line, naming the operator's one step: the
#   command claude_login_command prints, whose status is read (standing order 21; regime-cutover U318b: unread, a
#   failed producer printed an ordinary absence with an empty command), so a failed producer refuses naming it instead;
#   then the legacy note legacy_note_hold set, when it set one (U498; empty when the caller held none).
# @arg $1 string The profile line of the absent state.
# @exitcode 2 Always: the login is the operator's step, or its command could not be produced (the command dies).
claude_login_refuse() {
    local step
    step=$(claude_login_command) || die "$1; cannot name the operator's login step: claude_login_command failed"
    die "$1; log in once: ${step}; a login is the operator's step: run that command in your own terminal on this host, then start the seat again${claude_legacy_note:-}"
}

# @description Hold the login group's Claude Code directory path to its three components, the seats root, its `.state`
#   and `claude-<group>` (claude_config_dir, on the normalised spelling), each absent or a directory of this user that is no
#   symbolic link; both modes call it before anything reads or makes the directory, and it writes nothing. A file test
#   (`-L`, `-e`, `-d`, `-O`) answers false both for "not so" and for "could not look", so a component is judged only
#   under a parent this user can search: the nearest ancestor this user can see is found first (`-e` true needs its
#   own parent searchable; `/` is always seen), a directory there that this user cannot search refuses naming the
#   component and the directory (regime-cutover U318c: an owned root of mode 000 hid a linked `.state`, which read as
#   absent), and an absent entry under a searchable directory is absent, as is everything below a file or a dangling
#   link (the profile mode's mkdir names that). A link, a file or another user's directory refuses naming the
#   component, since a login under it would land outside what this kit made (regime-cutover U318b: `--check` judged the
#   leaf alone, so a linked `.state` reached another directory and a file there read as absent).
# @exitcode 2 A component is a symbolic link, not a directory, a directory of another user, or cannot be judged (the
#   command dies).
claude_config_validate() {
    local path seen above kind
    for path in "${claude_seats_root}" "${claude_seats_root%/}/.state" "${claude_config}"; do
        seen=${path%/*}
        [[ -n ${seen} ]] || seen=/
        above=0
        while [[ ! -e ${seen} && ! -L ${seen} ]] && ((${#seen} > 1)); do
            seen=${seen%/*}
            [[ -n ${seen} ]] || seen=/
            above=1
        done
        [[ -d ${seen} ]] || return 0
        [[ -x ${seen} ]] ||
            die "refused: cannot read the login group's Claude Code directory path component ${path} (permission denied: ${seen} is not searchable by this user); fix its mode before a seat starts"
        ((above == 0)) || return 0
        if [[ -L ${path} ]]; then
            kind='a symbolic link'
        elif [[ ! -e ${path} ]]; then
            return 0
        elif [[ ! -d ${path} ]]; then
            kind='not a directory'
        elif [[ ! -O ${path} ]]; then
            kind='a directory of another user'
        else
            continue
        fi
        die "refused: the login group's Claude Code directory path component ${path} is ${kind}; move it aside before a seat starts"
    done
}

# @description Make the login group's Claude Code directory 0700, with its `.state` parent and the seats root, when
#   absent (regime-cutover U318, U498), as hcom-seat makes them at a launch, so the operator's login lands in a directory this kit
#   made, after claude_config_validate has held the three to real directories of this user; nothing else is written.
#   Runs in the profile mode alone (`--check` reports an absent directory as absent).
# @exitcode 1 The mkdir failed (the command dies). 2 A component refuses (claude_config_validate).
claude_config_ensure() {
    claude_config_validate
    [[ -d ${claude_config} ]] || (umask 077 && mkdir -p "${claude_config}") ||
        die "cannot create the login group's Claude Code directory ${claude_config}" 1
}

# @description Print the Claude Code login line of this host (regime-cutover U318, U498): the one claude.ai login of
#   the group directory `claude_config`, which the caller derived (claude_config_dir) and held to a real directory chain
#   of this user (claude_config_validate) in its own shell, so a refusal there exits the lever naming the component;
#   every seat of the group's roles runs its bridge child, or the dsh gateway child, under it. The login is read by one call,
#   `CLAUDE_CONFIG_DIR=<dir> claude auth status`, with its status and its JSON (one document, read by jq as the SIWC
#   record is; `authMethod` a string held to a charset, the one field that reaches the terminal). Present when
#   `authMethod` is `claude.ai`; absent when the call exits 1 (not logged in), names another method (`oauth_token`,
#   `api_key`: a token or key the seat never gets) or the directory is absent; unreadable, never absent, when claude or
#   jq is missing, the call exits otherwise or prints no auth status record (standing order 21). A
#   CLAUDE_CODE_OAUTH_TOKEN in this environment is no input (regime-cutover U312): the call runs without it, as the
#   seat shim clears it. The operator's step for an absent login is the caller's (claude_login_refuse).
# @exitcode 0 Present. 1 Absent. 2 Unreadable.
claude_state() {
    local body status=0 method tool
    if [[ ! -d ${claude_config} ]]; then
        printf 'absent (no %s)\n' "${claude_config}"
        return 1
    fi
    for tool in claude jq; do
        if ! command -v "${tool}" > /dev/null; then
            printf 'unreadable (no %s on PATH to read the login of %s)\n' "${tool}" "${claude_config}"
            return 2
        fi
    done
    # The one call, under the group's directory and without a caller's token name; its stderr is dropped, its stdout
    # goes to jq alone, so no field but the method is ever printed.
    body=$(unset CLAUDE_CODE_OAUTH_TOKEN && CLAUDE_CONFIG_DIR=${claude_config} claude auth status 2> /dev/null) || status=$?
    case ${status} in
    0) ;;
    1)
        printf 'absent (not logged in under %s)\n' "${claude_config}"
        return 1
        ;;
    *)
        printf 'unreadable (claude auth status exited %s under %s)\n' "${status}" "${claude_config}"
        return 2
        ;;
    esac
    if ! method=$(jq -ers "${auth_status_filter}" <<< "${body}" 2> /dev/null); then
        printf 'unreadable (claude auth status printed no auth status record under %s)\n' "${claude_config}"
        return 2
    fi
    if [[ ${method} == claude.ai ]]; then
        printf 'login present (claude.ai, %s)\n' "${claude_config}"
        return 0
    fi
    printf 'absent (authMethod %s under %s, not claude.ai)\n' "${method}" "${claude_config}"
    return 1
}

# @description Print `<profile> <route>: <state>` for one profile.
# @arg $1 string Profile name.
# @arg $2 int 1 for launch readiness (the profile mode), else metadata only (`--check`).
# @exitcode 0 Logged in. 1 Absent. 2 Unreadable. 3 No seat login route, so nothing to log in.
profile_line() {
    local route state status=0 ready=${2:-0}
    route=$(route_of "$1") || status=$?
    case ${status} in
    0) ;;
    2)
        printf '%s: unreadable (%s)\n' "$1" "${profiles_dir}/$1.yml"
        return 2
        ;;
    *)
        printf '%s: no route (overlay %s absent or without modelRoles.default)\n' "$1" "${profiles_dir}/$1.yml"
        return 3
        ;;
    esac
    # The login group table covers every seat login route (regime-cutover U498b; verdict U498-e08ce84c P2 `:525`: until
    # this head the table ran for the Claude route alone, so an SIWC overlay outside it read as `absent` with exit 0).
    # A profile with a route and no group refuses the lever naming the profile, the route and the table; no line is
    # printed for it and nothing is read or made (standing order 21: the status of the one table decides).
    case ${route} in
    openai-siwc | claude-bridge)
        login_group_of_role "$1" > /dev/null ||
            die "refused: the profile $1 (${route}) is outside the login group table login_group_of_role, which names orchestrator, worker, audit, dsh and router; it has no login group, so no line is printed for it"
        ;;
    esac
    case ${route} in
    openai-siwc) state=$(siwc_state "$1" "${ready}") || status=$? ;;
    claude-bridge)
        # The directory is derived per login group and its chain judged in this shell, so a bad component refuses the
        # lever naming it (claude_config_validate), where a subshell's exit would read as one unreadable line (regime-cutover U318b).
        if claude_config_dir "$1"; then
            claude_config_validate
            state=$(claude_state) || status=$?
        else
            state="unreadable (${claude_config_error})" status=2
        fi
        ;;
    *) state="not a seat login route" status=3 ;;
    esac
    printf '%s %s: %s\n' "$1" "${route}" "${state}"
    return "${status}"
}

# @description `--check`: one line per profile, exit 1 when any record is unreadable.
check() {
    local profile overlay failed=0 status
    local -a profiles=("$@")
    if ((${#profiles[@]} == 0)); then
        for overlay in "${profiles_dir}"/*.yml; do
            # Parameter expansion, so no external producer (basename) can fail unseen.
            [[ -f ${overlay} ]] || continue
            overlay=${overlay##*/}
            profiles+=("${overlay%.yml}")
        done
    fi
    if ((${#profiles[@]} == 0)); then
        printf 'not applicable: no omp seat profiles under %s\n' "${profiles_dir}"
        return 0
    fi
    for profile in "${profiles[@]}"; do
        status=0
        profile_line "${profile}" || status=$?
        ((status == 2)) && failed=1
    done
    return "${failed}"
}

# @description Name the laptop this SSH session comes from, from the tailnet when it knows the address.
peer_name() {
    local client=${SSH_CONNECTION%% *} name=""
    if [[ -n ${client} ]] && command -v tailscale > /dev/null 2>&1; then
        name=$(tailscale status --json 2> /dev/null | jq -r --arg ip "${client}" \
            'first(.Peer[]? | select(any(.TailscaleIPs[]?; . == $ip)) | .DNSName) // empty' 2> /dev/null) || name=""
    fi
    printf '%s\n' "${name:-${client:-the laptop of the seat-host SSH session}}"
}

# @description Run the role's login in the operator's terminal, then report whether it took. The Claude route never
#   reaches here: its login is the operator's printed command (U318), so the caller refuses before this runs.
# @arg $1 string Role (its profile has the same name).
# @arg $2 string Route.
login() {
    local role=$1 route=$2 status=0 peer
    scratch=$(mktemp -d "${TMPDIR:-/tmp}/seat-login.XXXXXX") || die "cannot create a scratch directory" 1
    peer=$(peer_name) || die "cannot name the host whose browser opens the sign-in" 1
    printf 'seat-login-preflight: %s needs a %s login on this host; the sign-in opens in the browser of %s\n' "${role}" "${route}" "${peer}" >&2
    # The CLI login loads extensions from settings only, so a one-command overlay names it.
    printf 'extensions:\n  - %s\n' "${siwc_ext}" > "${scratch}/siwc.yml"
    for opener in xdg-open open; do
        printf '#!/bin/sh\nexec regime-open-url "$@"\n' > "${scratch}/${opener}"
        chmod 700 "${scratch}/${opener}"
    done
    PATH="${scratch}:${PATH}" PI_CONFIG_FILES="${scratch}/siwc.yml" OPENAI_SIWC_CALLBACK_PORT=${callback_port} \
        omp --profile "${role}" login openai-siwc || status=$?
    ((status == 0)) || die "the ${route} login exited ${status}" 1
}

usage='usage: seat-login-preflight --check [<profile>...] | seat-login-preflight <orchestrator|worker|audit>'
(($# > 0)) || die "${usage}"
if [[ $1 == --check ]]; then
    shift
    check "$@"
    exit $?
fi
(($# == 1)) || die "${usage}"
role=$1
known=0
for profile in "${seat_profiles[@]}"; do
    if [[ ${role} == "${profile}" ]]; then known=1; fi
done
((known)) || die "unknown seat profile '${role}'; expected one of: ${seat_profiles[*]}"
# A local host keeps its own browser and SIWC login, so nothing new happens there for that route. The Claude route's
# rule holds on every host (regime-cutover U190b): the seat's bridge child logs in by the token alone wherever it runs,
# so a local host with a host login only would start a seat whose first bridge turn ends `Not logged in`.
route_status=0
route=$(route_of "${role}") || route_status=$?
if ((route_status == 0)) && [[ ${route} == openai-siwc && -z ${SSH_CONNECTION:-} ]] &&
    ! [[ ${os} == Linux && -z ${DISPLAY:-} && -z ${WAYLAND_DISPLAY:-} ]]; then
    exit 0
fi
# The Claude route's login lives in the role's login group directory of this seats root (U318, U498): derived here, its
# chain held to real directories of this user and made 0700 when absent, before the one status call, so the operator's
# login lands in a directory this kit made; the legacy note is held before the group's directory is made.
claude_legacy_note=''
if ((route_status == 0)) && [[ ${route} == claude-bridge ]]; then
    claude_config_dir "${role}" || die "${role} ${route}: unreadable (${claude_config_error}); fix it before a seat starts" 1
    legacy_note_hold
    claude_config_ensure
fi

status=0
line=$(profile_line "${role}" 1) || status=$?
case ${status} in
0)
    printf 'seat-login-preflight: %s\n' "${line}" >&2
    exit 0
    ;;
2) die "${line}; fix or move the record aside before a seat starts" 1 ;;
3)
    printf 'seat-login-preflight: %s; nothing to log in\n' "${line}" >&2
    exit 0
    ;;
esac
route=$(route_of "${role}") || die "${line}" 1
# The Claude route has no login to run here: the operator's one command follows the line (U318, standing order 48).
if [[ ${route} == claude-bridge ]]; then
    claude_login_refuse "${line}"
fi
if [[ ! -t 0 || ! -t 1 || -n ${HCOM_LAUNCHED:-} ]]; then
    die "${line}; a login is the operator's step: run \`seat-login-preflight ${role}\` in your own terminal on this host, then start the seat again"
fi
login "${role}" "${route}"
status=0
line=$(profile_line "${role}" 1) || status=$?
((status == 0)) || die "${line} after the login" 1
printf 'seat-login-preflight: %s\n' "${line}" >&2
