    scripts/orchestrator/dispatch.sh¶

    Plan 007 T718 (C-20). Reads exactly one physical line from a file (a second line, blank or not, or a NUL byte is refused). Every <name>_sha256=<64 hex> token is recomputed from the file its sibling token names, <name>_file= or else <name>= (task_sha256 from task_file=, design_sha256 from design=, amended_task_sha256 from amended_task=; a line naming the file both ways, or repeating one of these keys, is refused), except a previous_<name>_sha256= reference to an earlier version, which is checked as 64 lowercase hex only; every line must carry exactly one non-empty task_id=, and an AGMSG-TASK line must carry task_file= and task_sha256=. Tokens are separated by any run of spaces and tabs, and every token after v1 is <key>=<value> (exit 2 otherwise, so a repeated prefix or a value split by a space is refused); the recorder takes task_id from that one parse (thread 4255272793). A relative path is read from the root of the checkout this script lives in (git rev-parse --show-toplevel there, under the allowlisted environment), never from the caller's directory. A missing field or file, a malformed value or a mismatch exits 1 naming the field, and nothing is sent. Otherwise the line goes to agmsg-dispatch as one argument, byte for byte. With an acceptance record, the record is checked before the send and, once the line is on the bus, <the line> read_at=<read|unread> is appended to the dispatch list of the record's JSON block, the object between its first two --- lines. The block is read and written with Python's standard json (malformed JSON, a duplicate key, NaN or Infinity, a block that is not an object or a dispatch that is not a list is refused; sort_keys, indent=2); the key is created when absent, and a record without a block gets a block holding only dispatch. The prose after the block is kept byte for byte, CRLF included (thread 4256987087), and the record is replaced atomically (a temporary file in its directory, fsync, rename) under an exclusive flock of that directory, so two dispatches to one record never lose an entry (thread 4255272797). A record that is not an existing regular file writable in a writable directory, or whose task is not the line's task_id, is refused before the send, and nothing is sent. An AGMSG-TASK line whose task_file= fails task-consistency-check.py (beside this script, run as python -I through uv run --offline, PyYAML from the pinned cache only, with --no-config, --no-project and a pinned --python, from the root, under env -i with only PATH, HOME (the script owner's passwd home), UV_CACHE_DIR (under it), LANG, LC_ALL and the AGMSG_* variables) is refused with the checker's output, and nothing is sent (C-52). Only a review brief is exempt: a front matter (the text between the first two --- lines) that PyYAML parses, refusing a duplicate key, to a mapping whose kind is the string review; every other outcome runs the checker. Only a bus row this send created is recorded. Both reads of the team-wide history.sh <team> "" <BUS_READ_WINDOW> take the newest rows (C-53: a whole-bus read took 56 minutes on a 1385-row team), and the recorder aligns them as two views of one bus: the pre-send window (each row's timestamp, sender, recipient and text) goes to a private mktemp file removed on exit; after the send every shift j from 0 to m-1 of the m post-send rows is tried, and exactly one may leave the post-send window, without its j newest rows, equal to the pre-send window without the rows that left it (all m new rows when the pre-send window was empty). This send is the last of those j new rows equal to the line, sender and recipient. No fit, several fits (a periodic bus), j = 0 or no equal new row leaves the record unchanged and exits 1. The read state is the marker history.sh prints for that row (● unread, ○ read): agmsg's scripts expose no read_at time, this script never reads the message database, and it never passes an agent to history.sh, whose agent argument renames the caller's pane after it.

# Modes: `check` parses the record and writes the pre-send window to the window file; `append` aligns
# history.sh's post-send window on stdin with it, takes the sent row's read marker (● unread, ○ read) and appends it.

import fcntl, json, os, re, shutil, sys, tempfile
from pathlib import Path

mode, path, line, sender, to, window, task = sys.argv[1:8]
record = Path(path)
rows = [r for r in sys.stdin.read().splitlines() if r]

def refuse(pairs):
    keys = [k for k, _ in pairs]
    dup = next((k for k in keys if keys.count(k) > 1), None)
    if dup is not None:
        sys.exit(f"dispatch: {path}: duplicate key {dup}")
    return dict(pairs)

def constant(name):
    sys.exit(f"dispatch: {path}: non-finite number {name}")

def load():
    # newline="": a CRLF record keeps its line endings (thread 4256987087).
    with open(record, newline="") as f:
        text = f.read()
    block, rest = {}, text
    if re.match(r"---\r?\n", text):
        m = re.match(r"---\r?\n(.*?)\r?\n---\r?\n", text, re.S)
        if not m:
            sys.exit(f"dispatch: {path}: the block between the first two --- lines is not closed")
        try:
            block = json.loads(m.group(1), object_pairs_hook=refuse, parse_constant=constant)
        except json.JSONDecodeError as e:
            sys.exit(f"dispatch: {path}: the block is not valid JSON: {e}")
        rest = text[m.end():]
        if not isinstance(block, dict):
            sys.exit(f"dispatch: {path}: the block is not a JSON object")
    if not isinstance(block.setdefault("dispatch", []), list):
        sys.exit(f"dispatch: {path}: dispatch is not a list")
    # Thread 4254844587: another task's record never takes this task's dispatch.
    if "task" in block and block["task"] != task:
        sys.exit(f"dispatch: {path} is the record of task {block['task']}, the line is task {task}")
    return block, rest
