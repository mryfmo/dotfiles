# archive/ について

このディレクトリは `references/` に取り込んだドキュメントキットの**配布物アーカイブ**であり、
参照専用の履歴です。**正本（canonical）は `references/` 直下のツリー**（`00_README.md` 以下）で
あり、このアーカイブの中身を直接編集・参照して作業してはいけません。

## 収録物と由来

| ファイル                               | 由来                                                                                                                                                                   |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PRD_ADR_BDD_Kit_v2_20260919.zip`      | ドキュメントキット **v2.0.0**（PRD/ADR/BDD の一式）。                                                                                                                  |
| `PRD_ADR_BDD_TEST_Kit_v3_20260919.zip` | ドキュメントキット **v3.0.0**（v2 に UT/CT/ST/UAT・`tools/`・`evidence/` 等を追加した後継版）。`references/` 直下のツリーはこの v3 を展開したもの。                    |
| `PRD_ADR_BDD.zip`                      | v2 の**平坦化された配布物**。直下に v2 の loose Markdown 13 本と、上記 `PRD_ADR_BDD_Kit_v2_20260919.zip` を**そのまま**内包する（入れ子 zip）。                        |
| `TestSuite.zip`                        | v3 の**平坦化された配布物**。直下に v3 系テスト設計書などの loose Markdown 15 本と、上記 `PRD_ADR_BDD_TEST_Kit_v3_20260919.zip` を**そのまま**内包する（入れ子 zip）。 |

入れ子 zip（`PRD_ADR_BDD.zip` 内の v2 kit zip、`TestSuite.zip` 内の v3 kit zip）は、
単体で配布されている同名 zip と **SHA-256 が一致するバイト同一のコピー**であることを確認済み。
つまり実体は 2 種類（v2 kit、v3 kit）だけで、4 ファイルは同じ内容の重複配布形態にすぎない。

## 観測されたタイムスタンプ

- v2 kit zip 内エントリの更新時刻: **JST 16:40**（2026-09-19）。
- v3 kit zip 内エントリの更新時刻: **JST 17:24〜17:25**（2026-09-19）。
- 外側の平坦化 zip（`PRD_ADR_BDD.zip` / `TestSuite.zip`）自体の作成時刻: **2026-09-23**。
  中身の日付（2026-09-19）とは別物であり、後日あらためて固められた配布パッケージであることを示す。

## 位置づけ

`SHA256SUMS.txt` はこのディレクトリ直下の 4 zip のみを対象とする完全性アンカーであり、
`references/` ツリー本体の検証（`references/SHA256SUMS.txt`）とは別物。ここは**履歴の保存**が
目的であり、今後のキット是正作業（v4 化）はすべて `references/` 直下のツリーに対して行う。
