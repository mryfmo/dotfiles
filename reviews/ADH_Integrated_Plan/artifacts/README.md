# 文書種別の索引 — L1〜L10

順番に必ず10工程を実行する定義ではない。C4との1対1対応も置かない。CHGとEVALは最初から横断する。グラフは依存・正本・根拠の索引であり実行済みの証明ではない。詳細は[文書契約](../spec/08_DOCUMENT_GRAPH.md)。
