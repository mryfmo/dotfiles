# adh-knowledge-context

TaskPacketに必要な規範closureを正本から確認し、関連資料だけを資格済み知識adapterへ照会する。sourceの場所・範囲・hashを取得し、推定や過去記憶を承認にしない。

必要な詳細は[workflow](references/workflow.md)を参照する。無関係な全graph再構築や外部LLM起動、モデル/権限/検査基準の変更は行わない。未実装入口を実行できたと報告しない。
